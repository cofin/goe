# Task 1.2: Consolidate cli_hdfs.py and web_hdfs.py into hdfs_client.py and update goe_dfs.py adapter without MapRFS

## Objective

1. Create `src/goe/filesystem/hdfs_client.py` consolidating on-premises Hadoop `hdfs://` operations from `src/goe/filesystem/cli_hdfs.py` and `src/goe/filesystem/web_hdfs.py` with zero MapRFS references.
2. Delete `src/goe/filesystem/cli_hdfs.py` and `src/goe/filesystem/web_hdfs.py`.
3. Update `src/goe/filesystem/goe_dfs.py` to remove `OFFLOAD_FS_SCHEME_MAPRFS` and provide `CloudStorageDfsAdapter(GOEDfs)` delegating cloud and local operations to `StagingStorageService`.

## Context

- `src/goe/filesystem/cli_hdfs.py:1-265` and `src/goe/filesystem/web_hdfs.py:1-260` implement SSH CLI (`hdfs dfs -...`) and WebHDFS REST operations for on-premises Hadoop `hdfs://` clusters.
- `src/goe/filesystem/goe_dfs.py:49-62` includes `OFFLOAD_FS_SCHEME_MAPRFS = "maprfs"` in `VALID_OFFLOAD_FS_SCHEMES`, which is retired across the repository.
- Existing callers of `GOEDfs` expect `stat`, `ls`, `delete`, `mkdir`, `chmod`, `chown`, `rmdir`, `copy_from_local`, `copy_to_local`, `read`, `write`, `gen_uri`, and `wait_for_files` methods.

## Steps

- [ ] 1. Write failing behavioral unit tests in `tests/unit/filesystem/test_hdfs_client.py` testing:
  - `HdfsClient` in both `cli` and `webhdfs` transport modes for `hdfs://` URI generation, `stat`, `list_dir`, `delete`, `mkdir`, `copy_from_local`, and `dry_run=True` behavior.
  - `uri_component_split` in `goe.filesystem.goe_dfs` rejecting `maprfs://` URIs with `GOEDfsException("Unsupported URI scheme: maprfs")`.
  - `CloudStorageDfsAdapter` delegating `read`, `write`, `stat`, `ls_dir`, and `delete` calls to `StagingStorageService`.
- [ ] 2. Create `src/goe/filesystem/hdfs_client.py` implementing `HdfsClient(GOEDfs)` for on-premises `hdfs://` clusters (supporting both SSH CLI and WebHDFS modes with lazy optional imports via `goe.util.module_loader.import_optional` when WebHDFS is used).
- [ ] 3. Update `src/goe/filesystem/goe_dfs.py` to remove `OFFLOAD_FS_SCHEME_MAPRFS` and add `CloudStorageDfsAdapter(GOEDfs)` backed by `StagingStorageService`.
- [ ] 4. Delete `src/goe/filesystem/cli_hdfs.py` and `src/goe/filesystem/web_hdfs.py`.
- [ ] 5. Run the verification block.
