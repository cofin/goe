# Task 1.1: Configure Ruff CPY001 rule in pyproject.toml

## Objective
Enable Ruff's `flake8-copyright` rule (`CPY001`) in `pyproject.toml` and configure `notice-rgx` to validate the standard 2-line SPDX header format:
`# SPDX-FileCopyrightText: <year> The GOE Authors`
`# SPDX-License-Identifier: Apache-2.0`

## Context
Ruff checks the first 4096 bytes of each Python file. When `CPY` is selected, it matches against the regex pattern specified in `[tool.ruff.lint.flake8-copyright].notice-rgx`.

## Steps
1. In [pyproject.toml](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/pyproject.toml#L222-L230):
   - Add `"CPY"` to `[tool.ruff.lint.select]`.
2. In [pyproject.toml](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/pyproject.toml):
   - Add a new section `[tool.ruff.lint.flake8-copyright]` with:
     ```toml
     [tool.ruff.lint.flake8-copyright]
     notice-rgx = "(?i)# SPDX-FileCopyrightText: [^\\r\\n]+\\r?\\n# SPDX-License-Identifier: Apache-2.0"
     min-file-size = 10
     ```
3. Update the header of `pyproject.toml` itself to use the 2-line SPDX format.

## Verification
- Run `uv run ruff check pyproject.toml` to verify configuration syntax.
- Run `uv run ruff check src/goe/cli/main.py --select CPY` to verify that Ruff produces `CPY001` diagnostic on an unmigrated file.

## Acceptance Criteria
- [x] `pyproject.toml` contains `select = [..., "CPY"]`.
- [x] `pyproject.toml` contains `[tool.ruff.lint.flake8-copyright]` with CRLF-safe SPDX `notice-rgx`.
- [x] Ruff correctly parses configuration without errors.
