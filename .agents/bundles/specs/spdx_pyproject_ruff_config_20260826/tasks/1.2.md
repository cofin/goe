# Task 1.2: Implement automated SPDX header migration script & core unit tests

## Objective

## Context
Hundreds of files across `src/`, `tests/`, `tools/`, `sql/`, `bin/`, `templates/`, and `docs/` require header updates. An automated script avoids manual editing errors and guarantees consistent formatting.

## Steps

     - Preserves extracted copyright `<year>`.
     - Formats replacement SPDX header based on file comment syntax (`#`, `--`, `/* */`, `<!-- -->`).
   - CLI flags: `--dry-run`, `--check`, `--path <path>`, `--ext <ext>`.
3. Run `uv run pytest tests/unit/test_migrate_spdx_headers.py` to confirm all tests pass.
