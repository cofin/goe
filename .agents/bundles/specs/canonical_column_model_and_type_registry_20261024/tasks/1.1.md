# Task 1.1: Pin every column mapping, trait, and format with golden tables

## Objective

1. Create `tests/unit/offload/schema/type_mapping_cases.py`, a class-agnostic data module holding golden inputs (plain tuples) and golden expected outputs captured from the current column classes and mapping owners.
2. Add strict golden tests to `tests/unit/offload/test_data_type_mappings.py` (mappings and overrides) and `tests/unit/offload/test_columns.py` (traits, formatting, constructor normalization, synthetic partition names) that pass against the current code.
