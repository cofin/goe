  ```python
  class MappingTarget(StrEnum):
      """Dialect and variant a canonical column is mapped to."""

      ORACLE = "oracle"
      MSSQL = "mssql"
      BIGQUERY = "bigquery"
      SNOWFLAKE = "snowflake"
      SYNAPSE = "synapse"
      HIVE = "hive"
      IMPALA = "impala"
      PARQUET = "parquet"
      AVRO = "avro"
      AVRO_IMPALA = "avro_impala"


  class TypeMappingLimits(FrozenBaseStruct, kw_only=True):
      """Owner limits consulted by mapping rules."""

      max_datetime_scale: int | None = None
      max_decimal_precision: int | None = None
      max_decimal_scale: int | None = None
      max_decimal_integral_magnitude: int | None = None
      canonical_date_supported: bool = True
      canonical_time_supported: bool = True
      supported_data_types: frozenset[str] = frozenset()


  class MappingContext(FrozenBaseStruct, kw_only=True):
      """Per-call inputs for a mapping rule."""

      limits: TypeMappingLimits
      decimal_padding_digits: int = 0
      binary_as_base64: bool = False
      use_staging_file_name: bool = False
      log: Callable[[str, int], None] | None = None


  type ColumnGuard = Callable[[ColumnSpec, MappingContext], bool]
  type ColumnTransform = Callable[[ColumnSpec, MappingContext], ColumnSpec]


  class MappingRule(FrozenBaseStruct):
      """One ordered mapping rule: when the source type and guard match, apply the transform."""

      source_types: frozenset[str]
      transform: ColumnTransform
      guard: ColumnGuard | None = None


  class OverrideRule(FrozenBaseStruct):
      """One ordered override rule: when the predicate matches, the allowed canonical types decide."""

      matches: ColumnGuard
      allowed: frozenset[str]
  ```

  Rule tables are module constants, defined after the transform helpers they reference: `TO_CANONICAL_RULES: dict[ColumnDialect, tuple[MappingRule, ...]]`, `FROM_CANONICAL_RULES: dict[MappingTarget, tuple[MappingRule, ...]]`, `OVERRIDE_RULES: dict[ColumnDialect, tuple[OverrideRule, ...]]`. Because module constants must reference functions defined above them while the module ordering rule puts public functions before private ones, implement every guard and transform as a `@staticmethod` on a private class per dialect (`class _OracleRules`, `class _MssqlRules`, `class _BigQueryRules`, `class _SnowflakeRules`, `class _SynapseRules`, `class _HadoopRules`, `class _StagingRules`, `class _PrecisionGuards`), place those classes before the table constants, and keep no module-level functions. Guards encode the precision, scale, and byte-length conditions of the source branches (for example `_PrecisionGuards.integral_at_most(29)`, `_PrecisionGuards.scale_at_most(9)`, `_OracleRules.char_length_exceeds(2000)`); transforms build results with `ColumnSpec(target_dialect, ...)` or `source.replace(...)` and apply `is_safe_mapping`.

  ```python
  class CanonicalTypeRegistry:
      """Table-driven canonical-to-physical and physical-to-canonical type mapping."""

      def __init__(
          self,
          to_canonical_rules: Mapping[ColumnDialect, tuple[MappingRule, ...]] = TO_CANONICAL_RULES,
          from_canonical_rules: Mapping[MappingTarget, tuple[MappingRule, ...]] = FROM_CANONICAL_RULES,
          override_rules: Mapping[ColumnDialect, tuple[OverrideRule, ...]] = OVERRIDE_RULES,
      ) -> None: ...

      def to_canonical(self, column: ColumnSpec, context: MappingContext) -> ColumnSpec: ...
      def staging_to_canonical(self, column: ColumnSpec, context: MappingContext) -> ColumnSpec: ...
      def from_canonical(self, column: ColumnSpec, target: MappingTarget, context: MappingContext) -> ColumnSpec: ...
      def valid_canonical_override(self, column: ColumnSpec, canonical_type: str, context: MappingContext) -> bool: ...
      def default_numeric_column(
          self, name: str, target: MappingTarget, context: MappingContext, data_scale: int | None = None
      ) -> ColumnSpec: ...
      def synthetic_partition_column(
          self, canonical_column: ColumnSpec, synthetic_name: str, target: MappingTarget
      ) -> ColumnSpec: ...


  TYPE_REGISTRY = CanonicalTypeRegistry()
  ```

  `to_canonical` and `from_canonical` evaluate the table for the column's dialect or target in order and return the first matching transform's result; no match raises `ColumnSpecError` with the old message text (`"Unsupported Oracle data type: <type>"`, `"Unsupported backend data type: <type>"`, `"Unsupported GOE data type: <type>"`, `"MSSQL from_canonical_column() not implemented."`, `"Unsupported Parquet data type: <type>"`). `valid_canonical_override` evaluates `OVERRIDE_RULES` in order, returns `canonical_type in rule.allowed` for the first matching rule, logs `"Unknown canonical type in mapping: <type>"` at `VVERBOSE` when the type is not in `ALL_CANONICAL_TYPES` and no earlier rule matched, and returns `False` when nothing matches.
