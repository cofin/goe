# Task 1.3: Migrate the offload entrypoint, delete core optparse builders, and share listener constants

## Objective

Make `goe offload` build `OffloadOperationOptions` directly, delete the remaining `optparse` builders in `src/goe/goe.py` and `src/goe/offload/offload.py`, import `EXPECTED_OFFLOAD_ARGS` and `OptionValueError` from their new homes, make the listener `OffloadOptions.to_params_dict()` use the shared alias tables, and reach zero `optparse` references under `src/goe/`.

## Context

- **Why `characterization`**: behavior-preserving swap of option construction and deletion of dead builders. Baseline: `tests/unit/cli/test_offload_command.py`, `tests/unit/listener/test_offload_options_schema.py`, and the PRD 1 golden suite `tests/unit/characterization/test_offload_bigquery_golden.py` (created by `oracle_ci_and_bigquery_test_harness_20261010:1.3`) pass before and after.
- **Baseline**: `46890a8`. `src/goe/goe.py` is edited first by PRD 1 Chapter 1.1 Task 1.2 (removes the `RedisClient` import at L24, `redis_execution_id`/`redis_in_error` at L248-249, the `redis_publish` branch of `log()` at L256-283, and `init_redis_execution_id` at L1107-1109). Line numbers after L247 shift by roughly 25; locate symbols by name.
- **Callers after Task 1.2**: `get_options` is used only by `src/goe/cli/commands/offload.py:522` and `get_offload_options` only by `src/goe/cli/commands/offload.py:523`; `get_common_options`, `get_options_from_list`, `check_posint`, `GOEOptionTypes`, and `get_oracle_options` have no remaining callers.
- **`offload()` precedence at baseline** (`src/goe/cli/commands/offload.py:518-547`): parser defaults, then `common_opts`, then the derived flags (`no_modify_hybrid_view`, `no_verify`, `verify`), then non-`None` kwargs (tuples become lists when non-empty). Struct defaults reproduce the parser defaults, so the replacement keeps this precedence.
- **`OFFLOAD_OP_NAME` in the CLI** exists only to call `get_options(operation_name=...)`; `offload_by_cli` sets `options.operation_name` itself (`src/goe/orchestration/cli_entry_points.py:42`), so the CLI no longer needs it.
- **Listener schema (`D-2.1-A` — RESOLVED)**: keep the REST wire defaults on `OffloadOptions` in `src/goe/listener/schemas.py:160-258` (`execute: bool = True` so API/MCP calls execute by default unless `"execute": false` is passed, and `None` for optional fields so `to_params_dict()` preserves alias precedence and records only caller-supplied overrides in `COMMAND_EXECUTION.COMMAND_INPUT`); replace the inline `alias_map` (L264-271) and `csv_alias_map` (L278-282) with `LISTENER_OFFLOAD_RENAME_ALIASES` and `LISTENER_OFFLOAD_CSV_ALIASES` from `goe.config.options`; add `to_operation_options(self) -> OffloadOperationOptions` (`return OffloadOperationOptions.from_mapping(self.to_params_dict())`) to hydrate all omitted fields from the canonical `OffloadOperationOptions` defaults (`orchestration_defaults.*_default()` and safe `False` destructive flags); and add a drift + default hydration test so REST fields cannot diverge from `EXPECTED_OFFLOAD_ARGS`.
