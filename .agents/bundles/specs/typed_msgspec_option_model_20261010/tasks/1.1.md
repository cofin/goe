# Task 1.1: Core msgspec.Struct Option Hierarchy & Exception Unification

## Objective

Establish `src/goe/config/options.py` with `BaseOptionStruct` and all 6 canonical option struct models (`CommonOptions`, `OffloadOperationOptions`, `ConnectOptions`, `StatusReportOptions`, `SchemaSyncOptions`, `AggValidateOptions`) guaranteeing 100% feature parity across all 84 `EXPECTED_OFFLOAD_ARGS`, all 12 CLI/API option aliases, all environment variable fallbacks (`orchestration_defaults.py`), and all option normalization rules (`option_validation.py`), alias `OptionValueError = OffloadOptionError` in `src/goe/exceptions.py`, and migrate all validation and predicate modules (`option_validation.py`, `partition_controls.py`, `oracle_predicate.py`, `predicate_offload.py`, `teradata_predicate.py`) off `from optparse import OptionValueError`.

## Context

- `src/goe/exceptions.py:1-15` defines `OffloadException` and `OffloadOptionError`. However, 7 production files (`src/goe/goe.py:13`, `src/goe/connect/connect.py:41`, `src/goe/offload/operation/partition_controls.py:7`, `src/goe/offload/option_validation.py:5`, `src/goe/offload/oracle/oracle_predicate.py:8`, `src/goe/offload/predicate_offload.py:83`, `src/goe/offload/teradata/teradata_predicate.py:8`) and `tests/unit/offload/test_predicate_offload.py:8` still import `OptionValueError` from `optparse`.
- Exporting `OptionValueError = OffloadOptionError` from `src/goe/exceptions.py` provides a single exception type for invalid option values while preserving backward compatibility for callers and tests catching either symbol.
- `BaseOptionStruct` in `src/goe/config/options.py` must subclass `BaseStruct` (`src/goe/lib/schemas.py:19`) with `dict=True, kw_only=True, omit_defaults=False` so that:
  1. `options.__dict__` is populated with all struct fields upon initialization and stays synchronized when attributes are mutated via `setattr(options, name, val)` or `options[name] = val`.
  2. Dynamic runtime attributes attached by orchestration classes (`options.target_owner_name`, `options.schema_offload_type`, `options.original_hadoop_host`, etc.) can be assigned and read via both attribute access and `options.__dict__`.
  3. Environment-dependent defaults from `src/goe/config/orchestration_defaults.py` are evaluated dynamically at instantiation time via `msgspec.field(default_factory=...)`.
  4. `EXPECTED_OFFLOAD_ARGS` (all 84 canonical keys from `src/goe/goe.py:154-240`) and all 12 CLI/API option aliases (`OFFLOAD_OPTION_ALIASES`: `Verify` -> `verify_row_count`, `verify` -> `verify_row_count`, `sort_columns` -> `sort_columns_csv`, `not_null_columns` -> `not_null_columns_csv`, `older_than_days` -> `offload_by_subpartition_age`, `equal_to_values` -> `offload_by_subpartition_values`, `less_than_value` -> `offload_by_subpartition_high_value`, `older_than_date` -> `less_than_value`, `reset_hybrid_view` -> `reset_backend_table`, `impala_insert_hint` -> `hive_insert_hint`, `offload_predicate_type` -> `offload_type`, `partition_names` -> `partition_names_csv`, `subpartition_names` -> `subpartition_names_csv`) live in `src/goe/config/options.py` with zero imports of `goe.goe`, eliminating the circular import hazard between `goe.listener.schemas` and `goe.goe`.

### Step 2: Unify `OptionValueError` with `OffloadOptionError` in `src/goe/exceptions.py`

Update `src/goe/exceptions.py:1-15` to export `OptionValueError = OffloadOptionError` with full type annotations:

```python
# SPDX-FileCopyrightText: 2024 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

"""Core exception hierarchy for GOE."""

__all__ = (
    "OffloadException",
    "OffloadOptionError",
    "OptionValueError",
)


class OffloadException(Exception):
    """Base exception for GOE offload operations."""


class OffloadOptionError(Exception):
    """Exception raised when an option value or combination is invalid."""

    def __init__(self, detail: object = "") -> None:
        super().__init__(detail)
        self.detail = detail

    def __str__(self) -> str:
        return repr(self.detail)


OptionValueError = OffloadOptionError
```
