# Task 1.1: Typed option structs, shared offload constants & exception unification

## Objective

Create `src/goe/config/options.py` with `BaseOptionStruct` and the seven option structs whose fields and defaults match the legacy `optparse` builders exactly, move `EXPECTED_OFFLOAD_ARGS` and the listener alias tables into it, export `OptionValueError = OffloadOptionError` from `src/goe/exceptions.py`, and switch five production modules plus one test from `optparse.OptionValueError` to `goe.exceptions.OptionValueError`. Legacy builders remain in place in this task; Tasks 1.2 and 1.3 delete them.

## Context

- **Why `behavior_tdd`**: `goe.config.options` and the `OptionValueError` export are new observable behavior. The initial failing symptom is a collection error: `ModuleNotFoundError: No module named 'goe.config.options'`.
- **Baseline**: `46890a8`. PRD 1 Chapter 1.1 Task 1.5 (lark migration) runs `tests/unit/offload/test_predicate_offload.py` but edits neither it nor `src/goe/offload/predicate_offload.py`; the cited import lines are unchanged at task start.
- **Field inventory**: [../research/option_inventory.md](../research/option_inventory.md) is the single source for field names, annotations, and default sources. Every row becomes exactly one struct field.
- **Current exception module** (`src/goe/exceptions.py:1-14`): `OffloadException(Exception)` and `OffloadOptionError(Exception)` with `__init__(self, detail)` storing `self.detail` and `__str__` returning `repr(self.detail)`; no module docstring, no `__all__`.
- **msgspec facts** (verified with msgspec 0.21.1 in this repo): `BaseStruct` (`src/goe/lib/schemas.py:19-20`) is a plain `msgspec.Struct` with no config; `kw_only=True` must be declared on every subclass; fields live in slots, so undeclared attribute assignment raises `AttributeError`; `cls(**mapping)` raises `TypeError("Unexpected keyword argument ...")` for unknown keys; a subclass may redeclare an inherited field to change its default.
- **Defaults that are not `orchestration_defaults` calls**:
  - `StatusReportOptions`: `output_format="text"`, `output_level="summary"`, `report_name="Offload_Status_Report"`, `report_directory` via `default_report_directory()` (`"%s/log" % os.environ.get("OFFLOAD_HOME", ".")`, matching `src/goe/offload/offload_status_report.py:74`), `csv_delimiter=","`, `csv_enclosure='"'`, `demo_mode=False` (constants at `offload_status_report.py:71-77`).
  - `AggValidateOptions`: `selects` default `[5]` and `aggregate_functions` default `("min", "max", "count")`, matching `DEFAULT_SELECT_COLS`/`DEFAULT_AGGS` at `src/goe/offload/offload_validation.py:58,60`. `options.py` must not import `goe.offload.offload_validation` or `goe.offload.offload_status_report` (both import backend factories); the drift test below guards the literal copies.
- **Derived fields** (default `None`): `TableOperationOptions` declares `owner`, `table_name`, `base_owner_name`, `target_owner`, `target_name`, `base_owner`, `base_name` (assigned by `normalise_owner_table_options`, `src/goe/goe.py:761-778`); `OffloadOperationOptions` declares `operation_name` (assigned by `offload_by_cli`, `src/goe/orchestration/cli_entry_points.py:42`); `ConnectOptions` declares `original_offload_transport_spark_thrift_host` and `original_hadoop_host` (assigned by `connect`, `src/goe/connect/connect.py:486-489`).
- **Annotation widening required by normalisers and callers**: `skip: str | list[str]`, `include: str | None`, `less_than_value: str | int | None`, `older_than_days: str | int | None`, `max_offload_chunk_size: str | int`, `max_offload_chunk_count: str | int`, `offload_partition_lower_value: str | int | None`, `offload_partition_upper_value: str | int | None`, `offload_predicate: Any`, `data_sample_pct: str | int | float`, `data_sample_parallelism: int | str`, `offload_transport_consistent_read: str | bool`, `offload_transport_fetch_size: str | int`, `offload_transport_parallelism: str | int`, `offload_transport_small_table_threshold: str | int | float`, `offload_transport_snapshot: str | int | None`, `offload_transport_spark_properties: str | dict[str, Any] | None`, `offload_transport_validation_polling_interval: str | int | float`, `sqoop_mapreduce_map_memory_mb: str | int | None`, `verify_row_count: str | bool | None`, `verify_parallelism: int | str | None`, `selects: list[str | int] | str | int`, `aggregate_functions: tuple[str, ...] | list[str] | str`, `filters: str | list[tuple[str, str, object]] | None`, `group_bys: str | list[str] | None`, `frontend_parallelism: int | str | None`. """Core exception hierarchy for GOE."""

__all__ = (
    "OffloadException",
    "OffloadOptionError",
    "OptionValueError",
)


class OffloadException(Exception):
    """Base exception for GOE offload operations."""


class OffloadOptionError(Exception):
    """Raised when an option value or option combination is invalid."""

    def __init__(self, detail: object) -> None:
        super().__init__(detail)
        self.detail = detail

    def __str__(self) -> str:
        return repr(self.detail)


OptionValueError = OffloadOptionError

class BaseOptionStruct(BaseStruct, kw_only=True):
    """Mutable typed option model shared by all GOE entrypoints."""

    @classmethod
    def from_mapping(cls, mapping: Mapping[str, Any]) -> Self:
        """Build an instance from a mapping; unknown keys raise TypeError."""
        return cls(**dict(mapping))

    def to_dict(self) -> dict[str, Any]:
        """Return every field value in a new dictionary."""
        return msgspec.structs.asdict(self)
