# Task 1.2: Delete Legacy optparse Parsers in Core Operations

## Objective

Delete all `optparse` imports and superseded `OptionParser`, `OptionGroup`, `Option`, and `SUPPRESS_HELP` parser builders across `src/goe/goe.py`, `src/goe/offload/offload.py`, `src/goe/connect/connect.py`, `src/goe/offload/offload_status_report.py`, `src/goe/schema_sync/schema_sync.py`, and `src/goe/scripts/agg_validate.py`, replacing all option construction call sites with `CommonOptions`, `OffloadOperationOptions`, `ConnectOptions`, `StatusReportOptions`, `SchemaSyncOptions`, and `AggValidateOptions` from `src/goe/config/options.py` while preserving 100% of option normalization rules (`normalise_options`, `normalise_offload_status_report_options`, `normalise_schema_sync_options`, `post_process_args`).

## Context

- **Mandatory Engineering Rule**: Do not leave dead wrappers or unused `optparse` functions behind. Any superseded `optparse` builder function or `Option` subclass must be deleted outright, and its callers updated to instantiate the typed `msgspec.Struct` models from `src/goe/config/options.py`:
  - `src/goe/goe.py:13`: Delete `from optparse import SUPPRESS_HELP, Option, OptionParser, OptionValueError`.
  - `src/goe/goe.py:154-240`: Replace inline `EXPECTED_OFFLOAD_ARGS` set definition with `from goe.config.options import EXPECTED_OFFLOAD_ARGS`.
  - `src/goe/goe.py:2666-3127`: **Delete** `check_posint` (`L2666-2671`), `GOEOptionTypes` (`L2674-2683`), `get_common_options` (`L2685-2772`), `get_oracle_options` (`L2775-2824`), `get_options` (`L2827-3106`), and `get_options_from_list` (`L3109-3127`) (as well as any legacy `get_offload_option_parser`, `init_common_options`, or `offload_options` helpers).
  - `src/goe/offload/offload.py:10, 379-655`: Delete `from optparse import SUPPRESS_HELP` and **delete** `get_offload_options(opt)` (`L379-655`).
  - `src/goe/connect/connect.py:10, 441-475`: Delete `from optparse import SUPPRESS_HELP` and **delete** `get_connect_opts()` (`L441-461`); update `connect()` (`L464-506`) to accept `options: ConnectOptions | None = None` (instantiating `ConnectOptions()` when `None`).
  - `src/goe/offload/offload_status_report.py:11, 3602-3674`: Delete `from optparse import SUPPRESS_HELP, OptionGroup` and **delete** `get_offload_status_report_opts()` (`L3602-3674`); keep `normalise_offload_status_report_options(options)` (`L3676-3698`) operating on `StatusReportOptions`.
  - `src/goe/schema_sync/schema_sync.py:6, 29-48`: Remove `get_common_options` import (`L6`) and **delete** `get_schema_sync_opts()` (`L29-48`); keep `normalise_schema_sync_options(options)` (`L51-59`) operating on `SchemaSyncOptions`.
  - `src/goe/scripts/agg_validate.py:21, 64-78, 179-235`: Remove `get_options_from_list` import (`L21`) and **delete** `GOE_OPTIONS` (`L64-78`), `get_agg_validate_options()` (`L179-228`), and `parse_args()` (`L230-235`); keep `post_process_args(args)` (`L146-177`) operating on `AggValidateOptions`.
