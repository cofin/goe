# Task 1.2: Migrate connect/report/sync/validate entrypoints to option structs and delete their builders

## Objective

Make `goe connect`, `goe report`, `goe sync`, and `goe validate` build `ConnectOptions`, `StatusReportOptions`, `SchemaSyncOptions`, and `AggValidateOptions` directly, remove the `sys.argv` parsing paths from `connect()`, `offload_status_report_run()`, and `agg_validate`, and delete `get_connect_opts`, `get_offload_status_report_opts`, `get_schema_sync_opts`, `GOE_OPTIONS`, `get_agg_validate_options`, `parse_args`, and `main` together with the `optparse` imports in these modules. `goe.goe` builders stay until Task 1.3 because `goe offload` still uses them.

## Context

- **Why `characterization`**: behavior-preserving replacement of option construction. Baseline: the CLI tests below pass before any edit and must pass unchanged afterwards (`tests/unit/cli/test_validate_command.py` loses only the test of the deleted `main()`).
- **Baseline**: `46890a8`. `src/goe/connect/connect.py` is edited first by PRD 1 Chapter 1.1 Task 1.2 (deletes lines 52 and 55, `test_listener` at L227-277, and its call at L405); every `connect.py` line number below L226 shifts up by 54, so locate `get_connect_opts` (about L387) and `connect` (about L410) by name.
- **Field parity** was proven by Task 1.1's parity heredoc; re-run it before deleting builders (Step 1).
- **CLI tests assert attributes, not types** (`options.schema`, `options.include`, `options.selects`, `mock_connect.call_args.args[0]`), so structs satisfy them unchanged.
- **Removed entrypoint paths**: after PRD 1 deletes `bin/*`, `goe` is the only CLI. Nothing in `src/`, `tests/`, or `tools/` calls `connect()` without arguments, `offload_status_report_run()` without arguments, `agg_validate.parse_args()`, or `agg_validate.main()` except `tests/unit/cli/test_validate_command.py::test_agg_validate_main_loads_env_before_check_config_path` (L107-124), which is deleted with `main()`.
- **Help output on option errors**: `offload_status_report_run` calls `opt.print_help()` (optparse help) in its `except OffloadOptionError` block; Click owns help output now, so that call is deleted.
