# Task 1.4: Add goe connect Google Cloud credential preflight and Managed Spark identity report

## Objective

Make `goe connect` verify GCP credentials before testing BigQuery connectivity:
- **Credential check.** When the config uses BigQuery or Cloud Storage staging, a "Google Cloud credentials" check resolves the shared bundle, mints a token (proving ADC and any impersonation work), and reports the credential type, principal, impersonated service account, project, and quota project. It fails with an actionable hint on missing ADC or a denied token. It warns on a service account key or an unresolved project.
- **Managed Spark identity report.** The gcloud check reports the gcloud caller impersonation and the serverless runtime service account. It warns when a permanent cluster is configured with `GOOGLE_DATAPROC_SERVICE_ACCOUNT` but no caller impersonation.
