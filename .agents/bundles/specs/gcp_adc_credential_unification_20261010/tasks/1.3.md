# Task 1.3: Separate Dataproc runtime SA vs caller impersonation, upgrade `gcs-connector` to `3.0.x`, and add `goe connect` ADC preflight checks

## Objective
Decouple Dataproc serverless batch runtime service account (`--service-account` from `google_dataproc_service_account`) from control-plane caller impersonation (`--impersonate-service-account` / `CLOUDSDK_AUTH_IMPERSONATE_SERVICE_ACCOUNT` from `google_dataproc_impersonate_service_account` or `google_impersonate_service_account`) in `src/goe/offload/spark/dataproc_offload_transport.py`, upgrade `gcs-connector-hadoop3` from `2.2.11` to `3.0.2` in `tools/transport/Makefile`, and add ADC principal/project preflight diagnostics and JSON-key deprecation warnings to `goe connect` and `src/goe/config/config_validation_functions.py`.

## Context
- `src/goe/offload/spark/dataproc_offload_transport.py`:
  - `OffloadTransportSparkBatchesGcloud.__init__` (`dataproc_offload_transport.py:66-74`) and `_gcloud_dataproc_submit_command` (`dataproc_offload_transport.py:108-130`) pass `--service-account` from `self._google_dataproc_service_account`, but do not pass `--impersonate-service-account` when `google_impersonate_service_account` or `google_dataproc_impersonate_service_account` is set.
  - `OffloadTransportSparkDataprocGcloud._gcloud_dataproc_submit_command` (`dataproc_offload_transport.py:453-470`) passes `--impersonate-service-account` using `self._google_dataproc_service_account`, conflating cluster job caller impersonation with the serverless batch worker runtime SA.
  - Canary subclasses `OffloadTransportSparkBatchesGcloudCanary` (`dataproc_offload_transport.py:421-431`) and `OffloadTransportSparkDataprocGcloudCanary` (`dataproc_offload_transport.py:522-528`) mirror these attributes.
- `tools/transport/Makefile:12-13,41-42` pins `gcs-connector-hadoop3-2.2.11-shaded.jar`, which lacks `fs.gs.auth.type=APPLICATION_DEFAULT` and `fs.gs.auth.impersonation.service.account`.
- `src/goe/config/config_validation_functions.py:111-122` (`normalise_bigquery_options`) and `src/goe/connect/connect_backend.py:67-80` / `src/goe/connect/connect_transport.py:235-263` lack ADC credential preflight checks and JSON key file deprecation warnings.

## Steps

### Step 1: Decouple runtime SA vs caller impersonation in `src/goe/offload/spark/dataproc_offload_transport.py`
1. In `OffloadTransportSparkBatchesGcloud.__init__` (`dataproc_offload_transport.py:66-74`), `OffloadTransportSparkBatchesGcloudCanary.__init__` (`dataproc_offload_transport.py:421-431`), `OffloadTransportSparkDataprocGcloud.__init__` (`dataproc_offload_transport.py:443-451`), and `OffloadTransportSparkDataprocGcloudCanary.__init__` (`dataproc_offload_transport.py:522-528`), initialize:
```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

        self._google_dataproc_impersonate_service_account = (
            getattr(offload_options, "google_dataproc_impersonate_service_account", None)
            or getattr(offload_options, "google_impersonate_service_account", None)
        )
```
2. In `OffloadTransportSparkBatchesGcloud._gcloud_dataproc_describe_command` (`dataproc_offload_transport.py:93-106`) and `_gcloud_dataproc_submit_command` (`dataproc_offload_transport.py:108-130`):
   - Keep `--service-account={self._google_dataproc_service_account}` for serverless batch worker identity on `batches submit`.
   - Append `--impersonate-service-account={self._google_dataproc_impersonate_service_account}` to both `batches describe` and `batches submit` when `self._google_dataproc_impersonate_service_account` is set.
3. In `OffloadTransportSparkDataprocGcloud._gcloud_dataproc_submit_command` (`dataproc_offload_transport.py:453-470`):
   - Use `self._google_dataproc_impersonate_service_account` for `--impersonate-service-account=...` on cluster job submission.
   - If `self._google_dataproc_service_account` is set without `self._google_dataproc_impersonate_service_account`, log a deprecation notice via `self._messages.warning(...)` explaining that `GOOGLE_DATAPROC_SERVICE_ACCOUNT` is the serverless batch runtime SA and `GOOGLE_IMPERSONATE_SERVICE_ACCOUNT` (or `GOOGLE_DATAPROC_IMPERSONATE_SERVICE_ACCOUNT`) should be used for caller impersonation on Dataproc clusters.

### Step 2: Upgrade `gcs-connector-hadoop3` to `3.0.2` in `tools/transport/Makefile`
In `tools/transport/Makefile:12-13,41-42`, replace `gcs-connector-hadoop3-2.2.11-shaded.jar` with `gcs-connector-hadoop3-3.0.2-shaded.jar`:
```makefile
GCS_CONNECTOR_VERSION=3.0.2
GCS_CONNECTOR_JAR=gcs-connector-hadoop3-$(GCS_CONNECTOR_VERSION)-shaded.jar
```

### Step 3: Add ADC preflight check and JSON-key deprecation warning to `config_validation_functions.py` and `goe connect`
1. In `src/goe/config/config_validation_functions.py:111-122` (`normalise_bigquery_options`), inspect `os.environ.get("GOOGLE_APPLICATION_CREDENTIALS")`; if it points to a `"type": "service_account"` JSON private key file (via `resolve_gcp_credentials`), emit a deprecation/security warning recommending keyless ADC (`GOOGLE_IMPERSONATE_SERVICE_ACCOUNT` or Workload Identity Federation).
2. In `src/goe/connect/connect_backend.py:67-80` and `src/goe/connect/connect_transport.py:235-263`, add `test_gcp_credentials(orchestration_config, messages)` that calls `resolve_gcp_credentials(orchestration_config)` and logs:
   - Active credential type (`authorized_user`, `impersonated_service_account`, `workload_identity_federation`, etc.)
   - Resolved principal and target impersonated service account
   - Resolved project (`bundle.project`) and quota project (`bundle.quota_project`)
   - Actionable remediation message when `DefaultCredentialsError` or impersonation `RefreshError` (`roles/iam.serviceAccountTokenCreator`) occurs.

### Step 4: Update and add unit tests
1. Update `tests/unit/offload/test_offload_transport.py` to verify:
   - Serverless batches (`OffloadTransportSparkBatchesGcloud`) pass `--service-account=<runtime_sa>` and `--impersonate-service-account=<caller_sa>` independently.
   - Cluster jobs (`OffloadTransportSparkDataprocGcloud`) pass `--impersonate-service-account=<caller_sa>`.
2. Create `tests/unit/connect/test_connect_gcp.py` testing the `goe connect` GCP ADC preflight check and JSON key file warning.
