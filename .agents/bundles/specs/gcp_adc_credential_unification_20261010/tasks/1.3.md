# Task 1.3: Separate the Managed Spark runtime service account from gcloud caller impersonation

## Objective

Make every `gcloud dataproc` command GOE builds pass `--impersonate-service-account=<caller>`, where `<caller>` comes from `resolve_gcloud_impersonation_principal` (Task 1.1): `GOOGLE_DATAPROC_IMPERSONATE_SERVICE_ACCOUNT`, otherwise `GOOGLE_IMPERSONATE_SERVICE_ACCOUNT`.
- Serverless batches keep `--service-account=GOOGLE_DATAPROC_SERVICE_ACCOUNT` as the runtime service account.
- Permanent-cluster jobs stop impersonating `GOOGLE_DATAPROC_SERVICE_ACCOUNT` and log a warning when only that variable is set.

SSH does not forward environment variables, so the per-command `--impersonate-service-account` flag replaces `CLOUDSDK_AUTH_IMPERSONATE_SERVICE_ACCOUNT` env propagation.
- Primary sources:
  - gcloud keeps credentials distinct from ADC: <https://cloud.google.com/docs/authentication/application-default-credentials#personal>.
  - `--impersonate-service-account` is a global gcloud flag: <https://cloud.google.com/docs/authentication/use-service-account-impersonation#gcloud>.
  - Serverless batches run as the `--service-account` runtime SA: <https://cloud.google.com/sdk/gcloud/reference/dataproc/batches/submit/pyspark>.
  - Cluster jobs run as the cluster VM SA fixed at cluster creation: <https://cloud.google.com/dataproc/docs/concepts/configuring-clusters/service-accounts>.
  - GOE submits `batches submit pyspark`, not `batches submit spark`.
- PRD invariant "Separation of Control-Plane Impersonation and Data-Plane Runtime SA" mandates this behavior change for permanent clusters. Operators who relied on `GOOGLE_DATAPROC_SERVICE_ACCOUNT` for cluster impersonation must set `GOOGLE_DATAPROC_IMPERSONATE_SERVICE_ACCOUNT`. Task 1.6 documents this.
- Existing tests: `tests/unit/offload/test_offload_transport.py` defines fixtures `config`, `messages`, `oracle_table`, and `fake_operation` (L45-73), plus `test_dataproc_cmd` (L146) and `test_dataproc_batches_cmd` (L174). `OffloadMessages.warning` records each message in `messages.messages["warnings"]` (baseline `src/goe/offload/offload_messages.py:345-348`; Chapter 1.1 Task 1.2 removes earlier lines of that file, so locate the method by name). This task does not edit that file.
