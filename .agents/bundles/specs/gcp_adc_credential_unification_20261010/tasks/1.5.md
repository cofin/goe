# Task 1.5: Upgrade the bundled Cloud Storage Hadoop connector to 3.0.20 with ADC authentication

## Objective

Replace the GCS Hadoop connector `gcs-connector-hadoop3-2.2.11-shaded.jar` downloaded by `tools/transport/Makefile` with `gcs-connector-3.0.20-shaded.jar` (latest 3.0.x patch). The bundled standalone Spark configuration then authenticates to Cloud Storage with Application Default Credentials (`spark.hadoop.fs.gs.auth.type APPLICATION_DEFAULT`) instead of the 3.x default `COMPUTE_ENGINE`.

## Context

- Baseline commit `46890a8`. No Chapter 1.1 task edits either file. Chapter 1.1 Task 1.1 edits only the root `Makefile` (baseline L174-175), not `tools/transport/Makefile`.
- `tools/transport/Makefile`:
  - L12 `GCS_HADOOP_VER=hadoop3-2`.
  - L13 `GCS_JAR=gcs-connector-$(GCS_HADOOP_VER).2.11-shaded.jar`.
  - L32 `spark-jars: $(JAR_DIR)/$(GCS_JAR) $(JAR_DIR)/$(AVRO_JAR)`.
  - L41-42 download rule `.../gcs-connector/$(GCS_HADOOP_VER).2.11/$(GCS_JAR)`.
  - The jar is installed into the Spark 3.2.4 `bin-hadoop3.2` distribution (L5-9; Hadoop 3.3.x client), copied by `make spark-target` (root `Makefile:160`).
- `templates/spark/spark-standalone-defaults.conf` (22 lines) is copied to `spark/conf/spark-defaults.conf` by `tools/transport/Makefile:20`. It sets no `fs.gs.*` property today.
- Primary sources:
  - Maven Central lists 3.0.0 to 3.0.20, then 3.1.x and 4.0.x: <https://repo1.maven.org/maven2/com/google/cloud/bigdataoss/gcs-connector/maven-metadata.xml>.
  - From 3.0.0 the artifact version has no `hadoop3-` prefix, and the shaded jar is `gcs-connector-3.0.20-shaded.jar`: <https://repo1.maven.org/maven2/com/google/cloud/bigdataoss/gcs-connector/3.0.20/>.
  - 3.0.x authentication properties: `fs.gs.auth.type` (`COMPUTE_ENGINE` default, `APPLICATION_DEFAULT`, `SERVICE_ACCOUNT_JSON_KEYFILE`, `USER_CREDENTIALS`, `ACCESS_TOKEN_PROVIDER`, `UNAUTHENTICATED`) and `fs.gs.auth.impersonation.service.account`: <https://github.com/GoogleCloudDataproc/hadoop-connectors/blob/branch-3.0.x/gcs/CONFIGURATION.md#authentication>.
  - 3.0.0 removed the 2.x key properties `fs.gs.auth.service.account.enable/.email/.keyfile/.private.key/.private.key.id`.
  - 3.0.x requires Java 11+.
- `src/goe/offload/offload_transport.py:1422-1434` keeps redacting `spark.hadoop.fs.gs.auth.service.account.private.key(.id)` in logged Spark properties for back-compat. That file is not changed.
- Strategy `static_validation`: the native baseline is `make -n` output, which shows the 2.2.11 URL at `46890a8` and fails the 3.0.20 check (`! grep -F "gcs-connector-3.0.20-shaded.jar" <(make -C tools/transport -n spark-jars)`). After the change, the 3.0.20 URL is present and the 2.2.11 URL is absent.
