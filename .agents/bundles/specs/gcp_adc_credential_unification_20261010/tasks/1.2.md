# Task 1.2: Wire `resolve_gcp_credentials` into BigQuery, KMS, `GOEGcs`, and `GOELogFileHandle`

## Objective
Update `BackendBigQueryApi` (`src/goe/offload/bigquery/bigquery_backend_api.py`), `GOEGcs` (`src/goe/filesystem/goe_gcs.py`), and `GOELogFileHandle` (`src/goe/util/goe_log_fh.py`) to pass explicit credentials and project from `resolve_gcp_credentials` into `bigquery.Client`, `kms.KeyManagementServiceClient`, `storage.Client`, and `fsspec.filesystem("gs", ...)`.

## Context
- `src/goe/offload/bigquery/bigquery_backend_api.py:441-449`:
  - `_get_bq_client(self)` calls `bigquery.Client(default_query_job_config=job_config, location=self._bigquery_dataset_location)` without `credentials` or `project`.
  - `_get_kms_client(self)` calls `kms.KeyManagementServiceClient()` without `credentials`.
  - `_backend_project_name(self)` (`bigquery_backend_api.py:203-209`) checks `self._orchestration_config.bigquery_dataset_project` and falls back to `self._client.project`.
- `src/goe/filesystem/goe_gcs.py:58-68`: `GOEGcs.__init__` calls `self._client = storage.Client()` when `not self._dry_run`.
- `src/goe/util/goe_log_fh.py:42-56`: `GOELogFileHandle._get_fs(self, scheme)` calls `fsspec.filesystem(scheme, **kwargs)` for `scheme == "gs"` without `token` or `project`, causing `gcsfs` to silently fall back to anonymous (`anon`) access when ambient ADC fails or when `GOOGLE_IMPERSONATE_SERVICE_ACCOUNT` is configured.

## Steps

### Step 1: Update `src/goe/offload/bigquery/bigquery_backend_api.py`

```python
from goe.util.gcp_credentials import resolve_gcp_credentials
```
2. Update `_backend_project_name` (`src/goe/offload/bigquery/bigquery_backend_api.py:203-209`) and `_get_bq_client` / `_get_kms_client` (`src/goe/offload/bigquery/bigquery_backend_api.py:441-449`):
```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def _backend_project_name(self):
        """Return the target BigQuery dataset project name, falling back to google_cloud_project or client project."""
        if self._orchestration_config.bigquery_dataset_project:
            return self._orchestration_config.bigquery_dataset_project
        if getattr(self._orchestration_config, "google_cloud_project", None):
            return self._orchestration_config.google_cloud_project
        return self._client.project

    def _get_bq_client(self):
        """Construct a BigQuery Client bound to the resolved ADC/impersonated credentials and project."""
        if self._dry_run:
            return None
        bundle = resolve_gcp_credentials(self._orchestration_config)
        job_config = bigquery.QueryJobConfig(use_legacy_sql=False)
        return bigquery.Client(
            project=bundle.project,
            credentials=bundle.credentials,
            default_query_job_config=job_config,
            location=self._bigquery_dataset_location,
        )

    def _get_kms_client(self):
        """Construct a Cloud KMS Client bound to the resolved ADC/impersonated credentials."""
        if self._dry_run:
            return None
        bundle = resolve_gcp_credentials(self._orchestration_config)
        return kms.KeyManagementServiceClient(credentials=bundle.credentials)
```

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def _get_fs(self, scheme: str):
        """Construct an fsspec filesystem for the log URI scheme using explicit GCP credentials for gs://."""
        kwargs: dict[str, object] = {}
        if scheme in ("gs", "s3", "abfs", "abfss", "adl"):
            kwargs["block_size"] = 4 * 1024 * 1024
        if scheme == "gs":
            bundle = resolve_gcp_credentials(getattr(self, "_config", None))
            kwargs["token"] = bundle.credentials
            if bundle.project:
                kwargs["project"] = bundle.project
        return fsspec.filesystem(scheme, **kwargs)
```
