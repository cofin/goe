# Task 1.2: Wire the shared credential bundle into BigQuery, Cloud KMS, GOEGcs, and GOELogFileHandle

## Objective

Every Python Google Cloud client must take its credentials and job project from `resolve_gcp_credentials` (Task 1.1) instead of implicit ADC lookup:
- `bigquery.Client`, `kms.KeyManagementServiceClient`, and `storage.Client`.
- The gcsfs filesystem behind `gs://` log files. It gets an explicit `token=<Credentials>`, which removes gcsfs's silent anonymous fallback.
