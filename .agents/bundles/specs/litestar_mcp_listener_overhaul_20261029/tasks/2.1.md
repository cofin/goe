## Objective

Upgrade `SystemController`, `SchemasController`, and `TablesController` with structured `@mcp_tool(...)` declarations and read-only `ToolAnnotations` while preserving every existing live REST route path and public health probe (`GET`/`HEAD /api/system/status/`), mount a dedicated `GOEResourcesController` (`include_in_schema=False`) publishing static `goe://...` MCP Resources and RFC 6570 Resource Templates, and add persisted table `OffloadMetadata` and multi-table `StatusReportEnvelope` endpoints.

## Context

- In `litestar-mcp 0.16.0` (`litestar_mcp.mcp.plugin._discover_mcp_routes`), route discovery branches with `if metadata: self._register_from_metadata(...) elif handler.opt: self._register_from_opt(...)`, and `MCPHandlerService.tools_list` reads `annotations`, `output_schema`, and `task_support` only from `MetadataRegistry` (`@mcp_tool`). Separating `@mcp_tool(...)` on public REST controllers from `GOEResourcesController` (`src/goe/listener/controllers/resources.py`, `path = "/api/_mcp/resources"`, `include_in_schema = False`, `auth = required("console-key")`) guarantees that BOTH structured tools (with `annotations`) AND `goe://...` resources/templates are simultaneously discovered and served.
- Live routes on `090941a` that must be preserved identically:
  - `GET /api/system/status/` and `HEAD /api/system/status/` (`auth = public()` liveness probes returning `schemas.HealthCheck(status="OK")`; must remain unmarked on `SystemController` so unauthenticated probes are not exposed as tools, while `goe://system/status` on `GOEResourcesController` requires `console-key`).
  - `GET /api/system/connectivity/` (`check_connectivity`) and `GET /api/system/config/` (`get_listener_config`).
  - `GET /api/system/schemas/` (`get_offloadable_schemas`) and `GET /api/system/schemas/{schema_name:str}/` (`get_offloadable_tables`).
- `SystemService` (`src/goe/listener/services/system.py`) accesses repository metadata via `self.get_repo(self.config, self.messages).get_offload_metadata(schema_name.upper(), table_name.upper())`. `StatusReportService` (`src/goe/report/service.py`) requires `source_fetcher` and `target_fetcher` callbacks (or `StatusReportService.load_demo_envelope(...)` when `demo=True` or `self.config is None`) so live multi-table status reports populate real source/target partition metrics rather than returning `total_tables=0`.
- Strategy justification (`behavior_tdd`): simultaneous `@mcp_tool` + `goe://` resource/template discovery and reads, `OffloadMetadata` lookup, and `StatusReportEnvelope` endpoints are observable API and MCP behaviors verified red-first in canonical `tests/unit/listener/{test_system_controllers,test_listener_cache_and_controllers,test_system_service}.py`.

## Steps

1. Add failing behavioral tests in `tests/unit/listener/test_system_controllers.py`, `tests/unit/listener/test_listener_cache_and_controllers.py`, and `tests/unit/listener/test_system_service.py` covering:
   - Simultaneous MCP discovery over `POST /mcp`: `tools/list` exposes `check_connectivity`, `get_listener_config`, `generate_status_report`, `get_offloadable_schemas`, `get_offloadable_tables`, `get_table_columns`, `get_table_partitions`, `get_table_offload_status`, `preview_schema_drift`, and `get_table_offload_metadata` with `annotations.readOnlyHint == True` (while `health_check` is absent from `tools/list`), AND `resources/list` + `resources/templates/list` simultaneously expose static `goe://system/status`, `goe://system/connectivity`, `goe://system/config`, `goe://reports/status`, `goe://schemas` (plus `litestar://openapi`) and templated `goe://schemas/{schema_name}/tables`, `goe://schemas/{schema_name}/{table_name}/columns`, `goe://schemas/{schema_name}/{table_name}/partitions`, `goe://schemas/{schema_name}/{table_name}/status`, `goe://schemas/{schema_name}/{table_name}/drift`, and `goe://schemas/{schema_name}/{table_name}/metadata`.
   - `resources/read` resolves both static (`goe://system/config`, `goe://schemas`) and templated (`goe://schemas/SH/tables`, `goe://schemas/SH/SALES/columns`, `goe://schemas/SH/SALES/metadata`) URIs with `application/json` text content, and `/api/_mcp/resources/*` is omitted from `/schema/openapi.json`.
   - `GET /api/system/status/` and `HEAD /api/system/status/` remain `auth=public()` (`200` without `x-goe-console-key`).
   - `GET /api/system/schemas/{schema_name}/{table_name}/metadata/` returns `TableOffloadMetadataResponse` (`200`) when offloaded and `TableMetadataNotFound` (`404`) when not offloaded.
   - `GET /api/system/reports/status/` (`schema_name`, `table_name`, and `demo` optional query parameters) returns `StatusReportEnvelope` (`200`), exercising both `demo=True` and wired `source_fetcher`/`target_fetcher` callbacks in `SystemService.get_status_report`.
2. Update `src/goe/listener/exceptions/handlers.py`, `src/goe/listener/exceptions/__init__.py`, and `src/goe/listener/schemas.py`:
   - Add `TableMetadataNotFound(ApplicationError)` (`status_code=404`, `message=f"Offload metadata not found for {owner}.{table_name}."`) and export it.
   - Add `TableOffloadMetadataResponse(FrozenBaseStruct, frozen=True)` with `@classmethod def from_metadata(cls, metadata: OffloadMetadata) -> TableOffloadMetadataResponse` converting `command_execution` (`ExecutionId | str | None`) to `str | None` for clean OpenAPI and MCP `structuredContent` serialization.
3. Extend `SystemService` (`src/goe/listener/services/system.py`):
   - Add `get_table_offload_metadata(self, schema_name: str, table_name: str) -> OffloadMetadata | None` calling `self.get_repo(self.config, self.messages).get_offload_metadata(schema_name.upper(), table_name.upper())`.
   - Add `get_status_report(self, *, schema_name: str | None = None, table_name: str | None = None, demo: bool = False, report_service: StatusReportService | None = None) -> StatusReportEnvelope`: when `demo=True` or (`self.config is None` and `report_service is None`), return `StatusReportService.load_demo_envelope(schema=schema_name, table=table_name)`; otherwise wire `StatusReportService(source_fetcher=self._fetch_source_partition_metrics, target_fetcher=self._fetch_target_partition_metrics)` backed by `self.get_repo(self.config, self.messages)` and `create_backend_table(..., dry_run=True)` and invoke `collect_report(schema=schema_name, table=table_name, database_name=self.get_db_unique_name(), demo_mode=False)`.
4. Decorate public REST controllers with `@mcp_tool(..., annotations=READ_ONLY_TOOL_ANNOTATIONS)` (preserving exact existing paths and tool names) and create `src/goe/listener/controllers/resources.py` (`GOEResourcesController`, exported in `src/goe/listener/controllers/__init__.py`, `include_in_schema=False`, `auth = required("console-key")`):
   - `SystemController`: keep `GET`/`HEAD /status/` unmarked (`auth=public()`); `@mcp_tool(name="check_connectivity", ...)` on `GET /connectivity/`; `@mcp_tool(name="get_listener_config", ...)` on `GET /config/`; add `GET /reports/status/` with `@mcp_tool(name="generate_status_report", annotations=READ_ONLY_TOOL_ANNOTATIONS, task_support="optional", ...)`.
   - `SchemasController`: `@mcp_tool(name="get_offloadable_schemas", ...)` on `GET /`; `@mcp_tool(name="get_offloadable_tables", ...)` on `GET /{schema_name:str}/`.
   - `TablesController`: `@mcp_tool` on `/columns/` (`get_table_columns`), `/partitions/` (`get_table_partitions`), `/status/` (`get_table_offload_status`), `/drift/` (`preview_schema_drift`), and new `GET /metadata/` (`get_table_offload_metadata`).
   - `GOEResourcesController`: ensure every handler method carries a Litestar `@get("/...")` HTTP route decorator (because `Controller.get_route_handlers()` ignores methods lacking an HTTP route decorator), stacking `@get("/...")` above `@mcp_resource(uri="goe://...", name="...", description="...", mime_type="application/json")` for static `goe://system/status`, `goe://system/connectivity`, `goe://system/config`, `goe://reports/status`, and `goe://schemas`, and using `@get("/...", mcp_resource="<name>", mcp_resource_template="goe://...", mcp_resource_description="...", mcp_resource_mime_type="application/json")` (without `@mcp_tool`) for templated `goe://schemas/{schema_name}/tables` and `goe://schemas/{schema_name}/{table_name}/{columns,partitions,status,drift,metadata}` delegating to shared async service/cache helpers.
