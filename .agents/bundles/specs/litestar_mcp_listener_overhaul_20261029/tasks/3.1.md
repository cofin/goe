## Objective

Create `ListenerOperationsService` (`src/goe/listener/services/operations.py`) with read-only gateway adapters driving `OffloadPipeline.plan(...)` (`execute=False`) and expose `POST /api/orchestration/offload/preview/` (`preview_offload_plan`) returning a typed `OffloadPlanPreview` blueprint (`partition_names`, `chunk_count`, `estimated_row_count`, `estimated_size_bytes`, `transport_method`, `staging_format`, `ingest_strategy`, `create_table_ddl`, `alter_table_ddl`, `frontend_where_clause`) together with a pre-minted `ConfirmationChallenge` bound directly to `execute_offload` (`execute=True`).

## Context

- `POST /api/orchestration/offload/` enqueues a background job even when `execute=False`, giving AI agents and DBAs no synchronous dry-run plan preview over HTTP or MCP.
- `OffloadPipeline.plan(options, execution_id="dry-run")` (`src/goe/orchestration/pipeline.py` and `src/goe/orchestration/models.py`) produces an immutable `OffloadPlan` without executing DDL or data transport. Note two critical codebase contracts:
  1. `OffloadOperation` (`src/goe/orchestration/stages/plan_resolution.py`) validates kwargs against `EXPECTED_OFFLOAD_ARGS`, which does NOT include `"dry_run"` — dry-run mode is controlled strictly by `"execute": False` (`options_for_preview = msgspec.structs.replace(options, execute=False).to_operation_options()`, with `dry_run=True` passed only to `create_source_table`, `create_repository_client`, and `get_offload_target_table`).
  2. `OffloadPipeline` accepts protocol gateways (`FrontendDiscoveryGateway`, `MetadataRepositoryGateway`, `BackendCatalogGateway`, `BackendPlannerGateway`, `TransportPlannerGateway`); `src/goe/listener/services/operations.py` provides private read-only gateway classes (`_LiveFrontendDiscoveryGateway`, `_LiveMetadataRepositoryGateway`, `_LiveBackendCatalogGateway`, `_LiveBackendPlannerGateway`, `_LiveTransportPlannerGateway`) wrapping `create_source_table(..., dry_run=True)`, `create_repository_client(..., dry_run=True)`, and `get_offload_target_table(...)` (plus an injectable `plan_builder` hook for hermetic unit testing).
- Issuing a `ConfirmationChallenge` inside `preview_offload_plan` bound to `tool_name="execute_offload"` and the normalized `{**options.to_params_dict(), "execute": True}` payload allows MCP clients either to pass `confirmation_token` straight to `execute_offload` in one call or to complete a two-call MRTR `requestState` + `inputResponses={"confirm": True}` flow (`task_input_before_start=True`).
- Strategy justification (`behavior_tdd`): dry-run planning, `OffloadPlan` -> `OffloadPlanPreview` projection, and preview-to-execute `confirmation_token` + MRTR round-trip execution are new observable behaviors verified first with failing tests in `tests/unit/listener/test_operations_service.py` and `tests/unit/listener/test_orchestration_controllers.py`.

## Steps

1. Write failing behavioral tests in `tests/unit/listener/test_operations_service.py` and `tests/unit/listener/test_orchestration_controllers.py` covering:
   - `ListenerOperationsService.preview_offload` forces `execute=False` without injecting `"dry_run"` into `OffloadOperation` kwargs, projects `OffloadPlan` into `OffloadPlanPreview`, and mints a `ConfirmationChallenge` whose `confirmation_token` validates against `ConfirmationGate.verify_token(tool_name="execute_offload", owner_table=..., payload={**options.to_params_dict(), "execute": True})`.
   - `nothing_to_offload=True` plans return `OffloadPlanPreview(nothing_to_offload=True, confirmation_challenge=None, ...)`.
   - Missing source table or invalid offload option raises structured `404` / `400` `ApplicationError` (mapped cleanly to `isError: True` in MCP `tools/call`).
   - End-to-end MCP `tools/call` flows in `test_orchestration_controllers.py`:
     - Preview token path: call `preview_offload_plan` -> extract `confirmation_challenge.confirmation_token` -> call `execute_offload` with `execute=True` and `confirmation_token` -> succeeds (`schemas.CommandScheduled` in `structuredContent`) without triggering `input_required`.
     - MRTR two-call path (`task_input_before_start=True`): call `execute_offload` with `execute=True` -> receives synchronous `input_required` (`requestState`) with zero `TaskRecord` created -> call `execute_offload` a second time with `requestState` and `inputResponses={"confirm": True}` -> enqueues job and returns `schemas.CommandScheduled`.
2. Add `OffloadPlanPreview(FrozenBaseStruct, frozen=True)` in `src/goe/listener/schemas.py`:
   - Fields: `owner_table: str`, `target_owner: str`, `target_table: str`, `offload_mode: str`, `offload_type: str | None`, `nothing_to_offload: bool`, `partition_names: list[str]`, `chunk_count: int`, `estimated_row_count: int | None`, `estimated_size_bytes: int | None`, `transport_method: str | None`, `staging_format: str | None`, `ingest_strategy: str | None`, `create_backend_table: bool`, `create_table_ddl: list[str]`, `alter_table_ddl: list[str]`, `frontend_where_clause: str | None`, `notices: list[str]`, and `confirmation_challenge: ConfirmationChallenge | None = None`.
   - Provide `@classmethod def from_offload_plan(cls, plan: OffloadPlan, *, owner_table: str, notices: Sequence[str] = (), confirmation_challenge: ConfirmationChallenge | None = None) -> OffloadPlanPreview`.
3. Create `src/goe/listener/services/operations.py` (`ListenerOperationsService`, plus `get_operations_service` zero-arg DI provider) and export from `src/goe/listener/services/__init__.py`:
   - Implement `preview_offload(self, options: schemas.OffloadOptions) -> schemas.OffloadPlanPreview` using read-only gateway adapters (`_LiveFrontendDiscoveryGateway`, `_LiveMetadataRepositoryGateway`, `_LiveBackendCatalogGateway`, `_LiveBackendPlannerGateway`, `_LiveTransportPlannerGateway` placed strictly below public classes/functions) when `plan_builder` is not overridden, translating `OffloadOptionError` / `OptionValueError` to `400` and missing source tables to `404` `ApplicationError`.
4. Wire `"operations_service": Provide(get_operations_service, sync_to_thread=False)` in `src/goe/listener/app.py` and mount `POST /api/orchestration/offload/preview/` (`preview_offload_plan`) on `OrchestrationController` (`src/goe/listener/controllers/orchestration.py`) with `@mcp_tool(name="preview_offload_plan", annotations=READ_ONLY_TOOL_ANNOTATIONS, ...)` running `await async_(operations_service.preview_offload)(data)`.
