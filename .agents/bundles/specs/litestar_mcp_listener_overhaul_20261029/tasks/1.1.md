## Objective

Align `pyproject.toml` dependency lower bounds with the `litestar-mcp 0.16.0`, `litestar 2.25.0`, `litestar-security 0.6.0`, `litestar-autowire 0.2.0`, and `msgspec 0.22.0` versions already resolved in `uv.lock` (preserving the Vertebra ASGI runtime without reintroducing `litestar-granian`), declare `httpx2>=2.16.0` explicitly for Listener CLI HTTP probes and MCP Streamable HTTP bridging, harden whitespace/blank numeric environment variable parsing in `src/goe/config/orchestration_defaults.py` and `src/goe/listener/config/application.py`, and remove unused scaffold fields from `ListenerSettings` while adding loopback-normalized URL and MCP settings properties.

## Context

- `uv.lock` on `090941a` resolves `litestar==2.25.0`, `litestar-mcp==0.16.0`, `litestar-security==0.6.0`, `litestar-autowire==0.2.0`, `msgspec==0.22.0`, and `httpx2==2.16.0`, whereas `pyproject.toml` `[project.dependencies]` still specifies stale lower bounds (`msgspec>=0.19.0`, `litestar>=2.8.0`, `litestar-security>=0.1.0`, `litestar-autowire>=0.1.0`, `litestar-mcp>=0.1.0`) and omits `httpx2`. The Listener ASGI server runs on Vertebra (`vertebra.extensions.litestar.LitestarPlugin`, `goe.listener.asgi:app`).
- `listener_port_default` and `listener_heartbeat_interval_default` in `src/goe/config/orchestration_defaults.py` call `int(os.environ.get(...) or <default>)`, which raises `ValueError` when `OFFLOAD_LISTENER_PORT` or `OFFLOAD_LISTENER_HEARTBEAT_INTERVAL` is whitespace-only (`"   "`).
- `ListenerSettings` (`src/goe/listener/config/application.py`) carries unused `FRONTEND_DIR`, `static_url`, `static_path`, and `background_workers` attributes and lacks `client_host`, `base_url` (derived from `self.ssl_enabled`), `confirmation_ttl_seconds`, `mcp_skills_enabled`, and `mcp_task_ttl_seconds`.
- Strategy justification (`behavior_tdd`): blank/whitespace numeric environment variable parsing across `orchestration_defaults.py` and `ListenerSettings`, `client_host` / `base_url` loopback and TLS normalization, and removal of unused scaffold attributes are observable runtime behaviors verified first with failing tests in `tests/unit/listener/test_settings.py`.

## Steps

1. Write failing behavioral tests in `tests/unit/listener/test_settings.py` covering:
   - Empty and whitespace-only (`""`, `"   "`) handling on `OFFLOAD_LISTENER_PORT` and `OFFLOAD_LISTENER_HEARTBEAT_INTERVAL` in `listener_port_default()` / `listener_heartbeat_interval_default()` (`src/goe/config/orchestration_defaults.py`) and `ListenerSettings()`, plus `OFFLOAD_LISTENER_HTTP_WORKERS`, `OFFLOAD_LISTENER_MAX_LOG_BYTES`, `OFFLOAD_LISTENER_THREADS`, `OFFLOAD_LISTENER_DRAIN_TIMEOUT`, `OFFLOAD_LISTENER_CONFIRMATION_TTL_SECONDS`, and `OFFLOAD_LISTENER_MCP_TASK_TTL_SECONDS`.
   - `ListenerSettings.client_host` and `ListenerSettings.base_url` normalization across `""`, `"0.0.0.0"`, `"::"` (`"127.0.0.1"`), `"::1"` (`"[::1]"`), `"127.0.0.1"`, custom hostnames, HTTP (`ssl_enabled=False`), and HTTPS (`ssl_enabled=True`).
   - Default and environment-overridden `confirmation_ttl_seconds` (`300`), `mcp_skills_enabled` (`True`), and `mcp_task_ttl_seconds` (`3600`).
   - Absence of removed `FRONTEND_DIR`, `static_url`, `static_path`, and `background_workers` symbols/attributes.
2. Update `[project.dependencies]` in `pyproject.toml`:
   - Bump `msgspec>=0.22.0`, `litestar>=2.25.0`, `litestar-security>=0.6.0`, `litestar-autowire>=0.2.0`, and `litestar-mcp>=0.16.0`, and add `httpx2>=2.16.0` (never reintroduce `litestar-granian`).
   - Ensure `uv.lock` remains locked cleanly against `https://pypi.org/simple` (`uv lock --offline`, or with a temporary gitignored `uv.toml` pointing to `https://pypi.org/simple` if resolution refresh is needed; never commit internal proxy URLs in `uv.lock`).
3. Harden listener defaults in `src/goe/config/orchestration_defaults.py`:
   - Strip whitespace in `listener_host_default` (`(os.environ.get("OFFLOAD_LISTENER_HOST") or "").strip() or None`), `listener_port_default` (`int((os.environ.get("OFFLOAD_LISTENER_PORT") or "").strip() or 8000)`), and `listener_heartbeat_interval_default` (`int((os.environ.get("OFFLOAD_LISTENER_HEARTBEAT_INTERVAL") or "").strip() or 60)`).
4. Clean up `src/goe/listener/config/application.py` (`ListenerSettings`):
   - Remove `FRONTEND_DIR` (and remove `"FRONTEND_DIR"` from `__all__`), `static_url`, `static_path` (including the `static_path` assignment in `__post_init__`), and `background_workers`.
   - Add fields `confirmation_ttl_seconds: int = 300`, `mcp_skills_enabled: bool = True`, and `mcp_task_ttl_seconds: int = 3600` on `ListenerSettings(FrozenBaseStruct, frozen=True)`.
   - Add private module-level helpers `_parse_int_env(name: str, default: int, *, minimum: int | None = None) -> int` and `_parse_bool_env(name: str, default: bool) -> bool` strictly below all public classes/functions, and apply them in `__post_init__` for `OFFLOAD_LISTENER_HTTP_WORKERS`, `OFFLOAD_LISTENER_MAX_LOG_BYTES`, `OFFLOAD_LISTENER_THREADS` / `VERTEBRA_THREADS`, `OFFLOAD_LISTENER_DRAIN_TIMEOUT` / `VERTEBRA_DRAIN_TIMEOUT`, `VERTEBRA_SHUTDOWN_TIMEOUT`, `OFFLOAD_LISTENER_CONFIRMATION_TTL_SECONDS`, `OFFLOAD_LISTENER_MCP_SKILLS_ENABLED`, and `OFFLOAD_LISTENER_MCP_TASK_TTL_SECONDS`.
   - Add `@property def client_host(self) -> str` and `@property def base_url(self) -> str` (using `"https"` when `self.ssl_enabled` is `True`, else `"http"`) on `ListenerSettings`.
