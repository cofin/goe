## Objective

Rebuild `src/goe/listener/mcp.py` onto native `litestar-mcp 0.16.0` primitives: return an exact `MCPConfig` instance wired with `litestar-security` route policy (`AUTH_POLICY_OPT_KEY: required("console-key")`), move `ConfirmationChallenge` into `src/goe/listener/schemas.py`, replace static fallback secrets and `before_tool_call` enforcement in `ConfirmationGate` with a handler-level `MCPInputRequiredResult` (MRTR) + preview-issued HMAC `confirmation_token` verifier guarded by `RuntimeError` outside `/mcp`, keep `before_mcp_tool_call` and `after_mcp_tool_call` purely observational for OpenTelemetry, delete `build_mcp_plugin` and all imperative `plugin.register_tool(...)` wrappers (`get_connectivity_report`, `get_table_status_report`, `list_offloaded_tables`, `preview_offload_plan`, `get_job_status`), and migrate `tests/unit/listener/test_mcp.py` in lockstep.

## Context

- `LitestarMCP` injects `MCPConfig` via `msgspec.convert(..., strict=False)` which checks `type(cfg) is MCPConfig`; `build_mcp_config()` must return an exact `MCPConfig` instance, never a subclass.
- `MCPConfig.before_tool_call` and `after_tool_call` swallow callback exceptions on non-abort paths and must not enforce authorization or business confirmation.
- In `litestar_mcp 0.16.0`, `get_mcp_request_context()` returns the active `MCPRequestContext` inside `/mcp` requests and raises `RuntimeError` during direct REST HTTP calls. Guarding with `try: ctx = get_mcp_request_context() except RuntimeError: ctx = None` allows mutating route handlers to enforce MRTR / `confirmation_token` gating for MCP callers while keeping direct REST `POST` callers 100% backward-compatible.
- `tests/unit/listener/test_mcp.py` is the canonical MCP unit test module and currently imports legacy symbols (`build_mcp_plugin`, `ConfirmationRequiredError`, `get_connectivity_report`, `get_table_status_report`, `list_offloaded_tables`, `preview_offload_plan`, `get_job_status`) from `goe.listener.mcp`; migrating `test_mcp.py` in lockstep avoids orphaned test files and keeps the entire `tests/unit/listener/` suite import-clean.
- Strategy justification (`behavior_tdd`): handler-level MRTR / HMAC confirmation behavior, `RuntimeError` non-MCP bypass, ephemeral secret generation, pure OTel hook lifecycle, and removal of duplicate imperative `register_tool` shims are observable runtime behaviors verified red-first in `tests/unit/listener/test_mcp.py`.

     ```python
     # SPDX-FileCopyrightText: 2026 The GOE Authors
     # SPDX-License-Identifier: Apache-2.0

     class ConfirmationGate:
         """HMAC-SHA256 and MRTR confirmation gate for mutating MCP tool calls."""

         def __init__(
             self,
             active_settings: ListenerSettings | None = None,
             *,
             secret: str | None = None,
             ttl_seconds: int | None = None,
         ) -> None:
             cfg = active_settings or default_settings
             raw_secret = secret or cfg.shared_token or _EPHEMERAL_CONFIRMATION_SECRET
             self._secret_bytes = raw_secret.encode("utf-8")
             self._ttl_seconds = max(30, ttl_seconds if ttl_seconds is not None else cfg.confirmation_ttl_seconds)
     ```
