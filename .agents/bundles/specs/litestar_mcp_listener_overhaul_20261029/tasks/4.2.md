## Objective

Extend `src/goe/cli/commands/listener.py` and `src/goe/cli/config.py` with a `goe listener mcp` subgroup (`stdio`, `bridge`, `inspect`) powered by `litestar-mcp 0.16.0` (`run_stdio`, `MCPStdioContext`, `run_stdio_streamable_http_bridge`) while preserving `_LAZY_IMPORTS` (`bind_lazy_imports`), and harden `goe listener status` to use `httpx2`, `settings.base_url` loopback/TLS normalization, `x-goe-console-key` header forwarding, and non-zero exit codes on unreachable or unhealthy endpoints.

## Context

- `src/goe/cli/commands/listener.py` uses `bind_lazy_imports(__name__, _LAZY_IMPORTS)` so CLI startup (`goe --help`, `goe listener --help`) never eagerly imports Litestar or Listener runtime modules. Currently `_LAZY_IMPORTS` references undeclared `httpx` (`"httpx": ("httpx", None)`), which is a separate top-level distribution from `httpx2`.
- In `litestar_mcp 0.16.0`, both `run_stdio` (`litestar_mcp.mcp.stdio`) and `run_stdio_streamable_http_bridge` (`litestar_mcp.mcp.bridge`) default to `header_name="Authorization"` and `token_prefix="Bearer "`. Because `ConsoleKeyAuthenticator` compares `x-goe-console-key` directly via `secrets.compare_digest` without a `"Bearer "` prefix, both `goe listener mcp stdio` and `goe listener mcp bridge` must pass `header_name="x-goe-console-key"` and `token_prefix=""` whenever `OFFLOAD_LISTENER_SHARED_TOKEN` is configured.
- `goe listener mcp stdio` and `goe listener mcp bridge` must emit strictly newline-delimited JSON-RPC frames on `stdout`, routing any diagnostics or stdlib log handlers to `stderr`.
- Strategy justification (`behavior_tdd`): lazy CLI startup isolation, `goe listener status` loopback/TLS/auth probing and exit codes, `stdio`/`bridge` `x-goe-console-key` forwarding and stdout frame purity, and `inspect` Rich/JSON catalog output are observable CLI behaviors verified red-first in canonical `tests/unit/cli/test_listener_command.py`.

## Steps

1. Add failing behavioral tests in `tests/unit/cli/test_listener_command.py` covering:
   - `goe listener status` probes `f"{settings.base_url}/api/system/status/"` via `httpx2.get`, sends `x-goe-console-key` to `/api/system/config/` when `settings.shared_token` is set, returns exit code `0` when healthy, and exits `1` when unreachable or returning non-`200` (explicitly migrating existing `@patch("goe.cli.commands.listener.httpx.get")` mocks in `tests/unit/cli/test_listener_command.py` to `@patch("goe.cli.commands.listener.httpx2.get")`, updating `test_listener_status_unreachable` from `assert result.exit_code == 0` to `assert result.exit_code == 1`, and adding a non-`200` exit-code `1` test).
   - `goe listener mcp stdio` constructs `MCPStdioContext(client_id=..., owner_id=..., auth=...)`, redirects `sys.stdout` logging handlers to `sys.stderr`, and invokes `run_stdio` with `header_name="x-goe-console-key"` and `token_prefix=""`.
   - `goe listener mcp bridge` invokes `run_stdio_streamable_http_bridge` defaulting `--endpoint` to `f"{settings.base_url}/mcp"`, `--header-name` to `"x-goe-console-key"`, `--token-prefix` to `""`, and `--bearer-env` to `"OFFLOAD_LISTENER_SHARED_TOKEN"`.
   - `goe listener mcp inspect` (`--json` and Rich borderless table modes) lists registered MCP tools, resources, resource templates, prompts, and skills via `goe.serializers.encode_json`.
   - Subprocess `sys.modules` lazy-import test proving `goe --help` and `goe listener --help` never import `goe.listener.app`, `litestar`, or `litestar_mcp`.
2. Update `src/goe/cli/commands/listener.py` and `src/goe/cli/config.py`:
   - Replace `"httpx": ("httpx", None)` with `"httpx2": ("httpx2", None)` in `_LAZY_IMPORTS` (and `import httpx2` under `if TYPE_CHECKING:`), and add lazy mappings for `create_app`, `encode_json`, `MCPStdioContext`, `run_stdio`, and `run_stdio_streamable_http_bridge`.
   - Update `status` to probe `f"{settings.base_url}/api/system/status/"` (and `f"{settings.base_url}/api/system/config/"` with `headers={"x-goe-console-key": settings.shared_token}` when `settings.shared_token` is set) via `httpx2.get(..., timeout=2.0)` and invoke `ctx.exit(1)` on non-`200` or transport errors.
   - Add `@listener.group(name="mcp", ...)` with subcommands `stdio`, `bridge`, and `inspect`, and register `OPTION_GROUPS` entries for `goe listener mcp stdio`, `goe listener mcp bridge`, and `goe listener mcp inspect` in `src/goe/cli/config.py`.
