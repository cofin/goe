## Objective

Expose guided DBA workflow prompts via `GOEPromptController` (`src/goe/listener/controllers/prompts.py` subclassing `PromptController` with `opt = {AUTH_POLICY_OPT_KEY: required("console-key")}`) and ship deterministic, SHA-256-verified GOE operational `SKILL.md` runbooks under `src/goe/listener/skills/` wired through `MCPSkillsConfig` (`io.modelcontextprotocol/skills`) and verified inside built Hatch wheels.

## Context

- `PromptController` (`litestar_mcp`) inherits from `litestar.Controller` rather than `SecureController`; declaring `opt = {AUTH_POLICY_OPT_KEY: required("console-key")}` as a plain class attribute (without `ClassVar`, matching `Controller.opt` typing in `mypy`) satisfies `SecurityPlugin`'s route compilation when `"console-key"` is registered.
- `AutowirePlugin` (`domain_packages=("goe.listener.controllers",)`) automatically mounts `GOEPromptController`, and `LitestarMCP` recursively discovers `PromptController` subclasses inside nested routers.
- `MCPSkillsConfig(paths=[SKILLS_DIR], directory_read=True)` scans immediate child folders `<name>/SKILL.md` (requiring regular files whose YAML frontmatter `name` matches `<name>` and includes a non-empty `description`) and serves `skills/list`, `skills/get`, `resources/directory/read`, and `skill://<name>/...` reads with SHA-256 digest verification. Hatch's wheel target (`packages = ["src/goe"]`) packages git-tracked non-Python files under `src/goe/` automatically without unlisted `__init__.py` files (matching `src/goe/persistence/oracle/ddl/sql/`); resolving `SKILLS_DIR` via `importlib.resources.files("goe.listener").joinpath("skills")` locates packaged `SKILL.md` assets cleanly in both editable and wheel installs.
- Strategy justification (`behavior_tdd`): prompt discovery/rendering, auth enforcement on synthesized prompt routes, `io.modelcontextprotocol/skills` catalog listing, SHA-256-verified reads, and packaged resource resolution are observable runtime behaviors verified red-first in canonical `tests/unit/listener/test_mcp.py`.

## Steps

1. Add failing behavioral tests in `tests/unit/listener/test_mcp.py` covering:
   - Application startup succeeds under `SecurityPlugin` both when `shared_token` is set and when `shared_token` is unset (`clear_autowire_cache()` between test apps).
   - `prompts/list` over `POST /mcp` lists `plan_table_offload`, `diagnose_failed_execution`, `reconcile_schema_drift`, and `audit_schema_readiness` with typed argument schemas; `prompts/get` renders structured DBA workflow instructions referencing exact `goe://` URIs and GOE tool names (`check_connectivity`, `get_listener_config`, `get_offloadable_schemas`, `get_offloadable_tables`, `preview_offload_plan`, `execute_offload`, `preview_schema_drift`, `apply_schema_sync`, `validate_table`, `cancel_offload_job`).
   - `server/discover` advertises `"io.modelcontextprotocol/skills": {"directoryRead": True}` when `settings.mcp_skills_enabled` is `True` and omits it when `False`.
   - `skills/list`, `skills/get`, `resources/directory/read`, and `resources/read` (`skill://goe-offload-operations/SKILL.md`, `skill://goe-diagnostics-and-recovery/SKILL.md`, `skill://goe-schema-drift-and-validation/SKILL.md`) return valid `sha256:` digests and markdown contents, and `importlib.resources.files("goe.listener").joinpath("skills")` resolves each `SKILL.md` file cleanly.
2. Create `src/goe/listener/controllers/prompts.py` and export `GOEPromptController` in `src/goe/listener/controllers/__init__.py`:
   - Subclass `PromptController` with `path = "/api/prompts"`, `tags = ["MCP Prompts"]`, `include_in_schema = False`, and `opt = {AUTH_POLICY_OPT_KEY: required("console-key")}`.
   - Implement `@prompt(...)` methods:
     - `plan_table_offload(self, schema_name: str, table_name: str, offload_goal: str = "incremental") -> str`
     - `diagnose_failed_execution(self, execution_id: str) -> str`
     - `reconcile_schema_drift(self, schema_name: str, table_name: str) -> str`
     - `audit_schema_readiness(self, schema_name: str) -> str`
3. Create packaged operational skills under `src/goe/listener/skills/`:
   - `src/goe/listener/skills/goe-offload-operations/SKILL.md`: pre-flight checks (`goe://system/connectivity`), partition/status/metadata inspection, `preview_offload_plan` dry-run verification, MRTR / `confirmation_token` execution, job monitoring (`goe://jobs/{execution_id}`), and post-offload `validate_table`.
   - `src/goe/listener/skills/goe-diagnostics-and-recovery/SKILL.md`: triaging failed or stalled jobs (`goe://jobs`, `goe://executions/{execution_id}`, `get_execution_log_link`), `OrchestrationLockTimeout` (`409`) diagnosis, cooperative `cancel_offload_job`, and safe retry procedures.
   - `src/goe/listener/skills/goe-schema-drift-and-validation/SKILL.md`: inspecting `goe://schemas/{schema_name}/{table_name}/drift`, evaluating additive vs incompatible column changes, applying `apply_schema_sync` safely under confirmation, and running `validate_table` with Flashback SCN or row-level DuckDB diffing.
4. Wire `SKILLS_DIR = Path(str(importlib.resources.files("goe.listener").joinpath("skills")))` and `skills=MCPSkillsConfig(paths=[SKILLS_DIR], directory_read=True) if cfg.mcp_skills_enabled else None` in `build_mcp_config()` (`src/goe/listener/mcp.py`).
