# Task 1.1: Build DialectSqlEngine on native sqlglot generation

## Objective

1. New package `goe.offload.sql_ast` with module `dialect_engine.py` exposing `SqlDialect`, `TableRef`, `DialectNotSupportedError`, `DialectSqlEngine`, and `get_dialect_engine`.
2. `DialectSqlEngine` ports every `OracleSqlEngine` and `BigQuerySqlEngine` method with byte-identical output, without any `sqlglot` global mutation or private `sqlspec` import.
3. New multi-dialect builders `alter_add_columns`, `alter_column_set_data_type`, and `alter_column_drop_not_null` with explicit dialect support and `DialectNotSupportedError` elsewhere.
4. Native Oracle `PARTITION`, `SUBPARTITION`, `AS OF SCN`, and `AS OF TIMESTAMP` round trips pinned by exact-string tests.

This task adds the new module only. Call sites keep using the old engines until task 1.2.

        """Render ALTER TABLE ... ADD for one or more (name, type) pairs in this dialect."""
        self._require("alter_add_columns", *_ALTER_DIALECTS)
        if if_not_exists and self._dialect not in _IF_NOT_EXISTS_DIALECTS:

                f"alter_add_columns with if_not_exists is not supported for dialect {self._dialect}"

            )
