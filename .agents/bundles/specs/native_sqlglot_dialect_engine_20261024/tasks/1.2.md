# Task 1.2: Move engine call sites to DialectSqlEngine and delete the Oracle monkey patch

## Objective

1. Every BigQuery and Oracle engine call site uses `goe.offload.sql_ast.dialect_engine.get_dialect_engine`.
2. `src/goe/offload/oracle/oracle_dialect.py` (with `register_oracle_dialect_extensions()`, `_parse_oracle_version()`, `_oracle_version_sql()`, and the private `sqlspec.builder._generation` import) and `src/goe/offload/bigquery/bigquery_sql.py` are deleted, together with their test modules.
3. `src/goe/offload/sql_engine.py` replaces `BigQueryDialectEngineProtocol` and `OracleExtractionQueryProtocol` with `DialectSqlEngineProtocol`; it still imports no `sqlglot` symbol.
4. Generated SQL is unchanged: the golden suite and all existing transport, backend, predicate, and validation tests pass without expectation edits.
