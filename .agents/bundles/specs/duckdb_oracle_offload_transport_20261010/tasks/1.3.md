# Task 1.3: Add comprehensive unit test suite for `OffloadTransportDuckDB` and `duckdb-gcs` streaming

## Objective

Create the full unit test suite in `tests/unit/offload/transport/test_duckdb_transport.py` verifying every requirement R1–R8 from [`research/duckdb_integration.md`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/.agents/bundles/specs/duckdb_oracle_offload_transport_20261010/research/duckdb_integration.md), including direct `gcss://` C++ streaming via `northpolesec/duckdb-gcs`, performance pragmas, and dual-mode `goe_gcs` ADC secret provisioning (`PROVIDER credential_chain` with `PROJECT_ID` vs `PROVIDER access_token` with 10-minute token refresh margin).

## Context

The unit test suite in `tests/unit/offload/transport/test_duckdb_transport.py` must cover:
1. **All 5 Oracle split types (`_build_batch_oracle_queries`):**
   - `SPLIT_TYPE_BY_PARTITION`, `SPLIT_TYPE_BY_SUBPARTITION`, `SPLIT_TYPE_BY_EXTENT`, `SPLIT_TYPE_BY_MOD`, and `SPLIT_TYPE_BY_ID_RANGE` (verifying `_get_id_range()` is called to supply `id_col_min` and `id_col_max`).
2. **`AS OF SCN` Presence in Every Batch (R5):**
   - Every generated batch query contains `AS OF SCN <snapshot_scn>` and `WHERE goe_offload_batch = <idx>` when `parallelism > 1`.
   - Missing `AS OF SCN` when `offload_transport_consistent_read=True` raises `ValueError` before any DuckDB query runs.
3. **Canonical Parquet Cast Projection (`parquet_staging_file.py:132-181`):**
   - Every canonical type staged in Parquet (`PARQUET_TYPE_STRING`, `PARQUET_TYPE_INT32`, `PARQUET_TYPE_INT64`, `PARQUET_TYPE_FLOAT`, `PARQUET_TYPE_DOUBLE`, `PARQUET_TYPE_BINARY`, `PARQUET_TYPE_BOOLEAN`, and `base64` binary-to-string) produces the exact expected DuckDB `CAST(...)` or `base64(CAST(... AS BLOB))` expression.
4. **Community `gcs` Extension (`northpolesec/duckdb-gcs`) & Dual-Mode ADC Secret Provisioning:**
   - `LOAD gcs` fast path and thread-locked `INSTALL gcs FROM community` + `LOAD gcs` fallback.
   - `SET gcs_enable_metadata_cache = true`, `SET gcs_metadata_cache_ttl = 3600`, `SET gcs_list_cache_ttl = 3600`, and `SET gcs_transfer_concurrency = <threads>`.
   - Direct streaming `COPY (...) TO 'gcss://my-bucket/stage/sales/part-0000N.parquet' (FORMAT PARQUET, COMPRESSION SNAPPY)` without calling `_dfs_client.copy_from_local` on GCS staging paths.
   - Local file + `_dfs_client.copy_from_local` fallback when staging scheme is non-GCS (e.g., `hdfs://` or `s3a://`).
   - Dual-mode `goe_gcs` secret provisioning:
     - `PROVIDER credential_chain` with `PROJECT_ID` on GCE/Cloud Run/direct Service Account (and skipping DDL when `goe_gcs` is already in `duckdb_secrets()`).
     - `PROVIDER access_token` with 10-minute expiry refresh margin on user ADC (`authorized_user`) or impersonated credentials.
5. **Availability Gate Rejection Reasons (R2), Dry-Run, Secret Redaction (R7), and Temp Cleanup:**
   - Rejects `FILE_STORAGE_FORMAT_AVRO`, `target != DBTYPE_BIGQUERY`, version mismatch, oversized tables, wallet without U3, LOB/LONG without U4, and failed extension load.
   - Never logs raw `rdbms_app_pass` or OAuth2 `access_token` values in `messages.log`, and removes temporary spill directories in a `finally:` block.

from pathlib import Path
from typing import Any
from unittest.mock import MagicMock, patch

import pytest

def _build_duckdb_transport_stub(
    tmp_path: Path,
    dry_run: bool = False,
    parallelism: int = 2,
    split_type: str = SPLIT_TYPE_BY_MOD,
    snapshot_scn: int = 123456789,
    staging_location: str = "gs://my-bucket/stage/sales",
) -> OffloadTransportDuckDB:
    """Create a configured OffloadTransportDuckDB instance with mocked dependencies."""
    transport = object.__new__(OffloadTransportDuckDB)
    transport._dry_run = dry_run
    transport._offload_transport_parallelism = parallelism
    transport._offload_transport_consistent_read = True
    transport._offload_transport_snapshot = snapshot_scn
    transport._offload_transport_rdbms_session_parameters = {}
    transport._compress_load_table = True
    transport._duckdb_threads = 2
    transport._duckdb_memory_limit = "2GB"
    transport._duckdb_temp_root = str(tmp_path / "duckdb_run")
    transport._duckdb_extension_path = "/opt/goe/oracle.duckdb_extension"
    transport._duckdb_extension_dir = None
    transport._duckdb_extension_repo = "https://cofin.github.io/duckdb-oracle"
    transport._duckdb_call_timeout_ms = 0
    transport._rdbms_module = "goe_offload"
    transport._transport_context = {}

    transport._orchestration_config = MagicMock(
        ora_conn="localhost:1521/FREEPDB1",
        rdbms_app_user="goe_app",
        rdbms_app_pass="SuperSecretPass123!",
        bigquery_dataset_project="my-gcp-project",
        google_impersonate_service_account=None,
    )
    transport._messages = MagicMock()
    transport._messages.offload_step.side_effect = lambda _step, fn, execute=True, **_kw: fn()
    transport._log = MagicMock()

    transport._source_table = MagicMock()
    transport._source_table.parallel_query_hint.return_value = "NO_PARALLEL"
    transport._rdbms_columns = []

    transport._rdbms_api = MagicMock()
    transport._rdbms_api.get_rdbms_session_setup_hint.return_value = "/*+ NO_PARALLEL */"
    transport._rdbms_api.get_rdbms_session_setup_commands.return_value = [
        "ALTER SESSION SET TIME_ZONE='UTC';",
    ]

    staging_cols = [
        StagingParquetColumn("ID", PARQUET_TYPE_INT64, staging_file_column_name="ID"),
        StagingParquetColumn("NAME", PARQUET_TYPE_STRING, staging_file_column_name="NAME"),
    ]
    transport._staging_file = MagicMock()
    transport._staging_file.get_staging_columns.return_value = staging_cols
    transport._staging_file.binary_data_as_base64.return_value = False

    transport._target_table = MagicMock()

@pytest.mark.parametrize(
    "split_type",
    [
        SPLIT_TYPE_BY_PARTITION,
        SPLIT_TYPE_BY_SUBPARTITION,
        SPLIT_TYPE_BY_EXTENT,
        SPLIT_TYPE_BY_MOD,
        SPLIT_TYPE_BY_ID_RANGE,
    ],
)
def test_build_batch_oracle_queries_all_split_types_preserve_scn(
    tmp_path: Path,
    split_type: str,
) -> None:
    """Verify all 5 split types produce batch SQL with AS OF SCN and goe_offload_batch predicates."""
    transport = _build_duckdb_transport_stub(
        tmp_path,
        parallelism=3,
        split_type=split_type,
        snapshot_scn=555666777,
    )
    queries = transport._build_batch_oracle_queries()

    assert len(queries) == 3
    if split_type == SPLIT_TYPE_BY_ID_RANGE:
        transport._get_id_range.assert_called_once()
    for idx, query in enumerate(queries):
        assert "AS OF SCN 555666777" in query
        assert f"WHERE goe_offload_batch = {idx}" in query


def test_probe_duckdb_oracle_capabilities_rejects_wallet_and_lob_without_upstream_flags() -> None:
    """Verify capability probe rejects wallet auth without U3 and LOB columns without U4."""
    mock_conn = MagicMock()
    mock_conn.execute.return_value.fetchall.return_value = [("oracle_connection_limit",)]
    mock_duckdb = MagicMock()
    mock_duckdb.connect.return_value = mock_conn

    wallet_cfg = MagicMock(
        offload_transport_duckdb_extension_path="/opt/goe/oracle.duckdb_extension",
        offload_transport_duckdb_extension_dir=None,
        offload_fs_scheme="gs",
        use_oracle_wallet=True,
        offload_transport_auth_using_oracle_wallet=False,
    )
    with patch.dict("sys.modules", {"duckdb": mock_duckdb}):
        assert probe_duckdb_oracle_capabilities(wallet_cfg, None, MagicMock()) is False

    lob_cfg = MagicMock(
        offload_transport_duckdb_extension_path="/opt/goe/oracle.duckdb_extension",
        offload_transport_duckdb_extension_dir=None,
        offload_fs_scheme="gs",
        use_oracle_wallet=False,
        offload_transport_auth_using_oracle_wallet=False,
    )
    lob_table = MagicMock(columns=[MagicMock(data_type=ORACLE_TYPE_CLOB)])
    with patch.dict("sys.modules", {"duckdb": mock_duckdb}):
        assert probe_duckdb_oracle_capabilities(lob_cfg, lob_table, MagicMock()) is False


def test_transport_dry_run_executes_nothing_and_cleans_up_temp_dir(tmp_path: Path) -> None:
    """Verify dry-run logs batch queries with gcss:// target without opening DuckDB connections."""
    transport = _build_duckdb_transport_stub(tmp_path, dry_run=True, parallelism=2)
    mock_duckdb = MagicMock()
    with patch.dict("sys.modules", {"duckdb": mock_duckdb}):
        rows = transport.transport()

    assert rows is None
    mock_duckdb.connect.assert_not_called()
    transport._dfs_client.copy_from_local.assert_not_called()
    logged_messages = " ".join(str(call.args[0]) for call in transport._log.call_args_list)
    assert "TO 'gcss://my-bucket/stage/sales/part-00000.parquet'" in logged_messages
    run_root = Path(transport._duckdb_temp_root)
    assert list(run_root.glob("goe_duckdb_*")) == []


def test_transport_execute_mode_streams_directly_to_gcss_and_redacts_secrets(tmp_path: Path) -> None:
    """Verify execute mode streams Parquet directly to gcss:// via community gcs extension and redacts secrets."""
    transport = _build_duckdb_transport_stub(tmp_path, dry_run=False, parallelism=2)
    executed_sqls: list[str] = []

    def _connect_side_effect(*_args: Any, **_kwargs: Any) -> MagicMock:
        conn = MagicMock()

        def _exec_side_effect(sql: str, *_params: Any) -> MagicMock:
            executed_sqls.append(sql)
            cursor = MagicMock()
            if sql.startswith("SELECT name FROM duckdb_settings()"):
                cursor.fetchall.return_value = [
                    ("oracle_call_timeout_ms",),
                    ("oracle_session_init_sql",),
                ]
            elif sql.startswith("SELECT count(*) FROM duckdb_secrets()"):
                cursor.fetchone.return_value = (0,)
            elif sql.startswith("COPY ("):
                cursor.fetchone.return_value = (125,)
            return cursor

        conn.execute.side_effect = _exec_side_effect
        return conn

    mock_duckdb = MagicMock()
    mock_duckdb.connect.side_effect = _connect_side_effect
    fake_creds = MagicMock()
    fake_creds.__class__.__name__ = "Credentials"
    fake_creds.__class__.__module__ = "google.auth.compute_engine.credentials"

    with patch.dict("sys.modules", {"duckdb": mock_duckdb}), patch(
        "goe.offload.transport.duckdb_transport._resolve_credentials_and_project",
        return_value=(fake_creds, "my-gcp-project"),
    ):
        rows = transport.transport()

    assert rows == 250
    assert transport._transport_context[TRANSPORT_CXT_ROWS] == 250
    assert transport._transport_context[TRANSPORT_CXT_BYTES] == 4096
    transport._dfs_client.copy_from_local.assert_not_called()
    assert any("TO 'gcss://my-bucket/stage/sales/part-00000.parquet'" in s for s in executed_sqls)
    assert any("TO 'gcss://my-bucket/stage/sales/part-00001.parquet'" in s for s in executed_sqls)
    assert any("LOAD gcs" in s for s in executed_sqls)
    assert any("SET gcs_transfer_concurrency = 2" in s for s in executed_sqls)
    logged_messages = " ".join(str(call.args[0]) for call in transport._log.call_args_list)
    assert "SuperSecretPass123!" not in logged_messages
    assert "PASSWORD '***'" in logged_messages
    run_root = Path(transport._duckdb_temp_root)
    assert list(run_root.glob("goe_duckdb_*")) == []
