# Task 1.1: Register `OFFLOAD_TRANSPORT_METHOD_DUCKDB`, add `OFFLOAD_TRANSPORT_DUCKDB_*` config options, and implement `is_duckdb_available()`

## Objective

Register `OFFLOAD_TRANSPORT_METHOD_DUCKDB = "DUCKDB"` and `OFFLOAD_TRANSPORT_DUCKDB = "DUCKDB"` as an explicit opt-in transport method (excluded from `AUTO` selection), wire the `OFFLOAD_TRANSPORT_DUCKDB_*` configuration options (including `OFFLOAD_TRANSPORT_DUCKDB_EXTENSION_DIR`) through `OrchestrationConfig`, `orchestration_defaults.py`, `option_descriptions.py`, `option_validation.py`, and `src/goe/cli/commands/offload.py`, and implement `is_duckdb_available()` with complete upstream capability gating for both `cofin/duckdb-oracle` and `northpolesec/duckdb-gcs`.

## Context

1. **Transport Constants & Selection (`src/goe/offload/offload_transport.py:95-145`, `L491-598`):**
   - `OFFLOAD_TRANSPORT_METHOD_*` constants are defined at `L95-103`, `VALID_OFFLOAD_TRANSPORT_METHODS` at `L104-113`, and `OFFLOAD_TRANSPORT_GOE_METHODS` at `L118-123`.
   - `OFFLOAD_TRANSPORT_*` high-level selectors are defined at `L133-138` (`OFFLOAD_TRANSPORT_AUTO`, `OFFLOAD_TRANSPORT_SPARK`, `OFFLOAD_TRANSPORT_SQOOP`, `OFFLOAD_TRANSPORT_GOE`, `OFFLOAD_TRANSPORT_GCP`).
   - Add `OFFLOAD_TRANSPORT_METHOD_DUCKDB = "DUCKDB"` to `VALID_OFFLOAD_TRANSPORT_METHODS` and add `OFFLOAD_TRANSPORT_DUCKDB = "DUCKDB"` to `VALID_OFFLOAD_TRANSPORTS`.
   - **Important:** Do **not** add `OFFLOAD_TRANSPORT_METHOD_DUCKDB` to `OFFLOAD_TRANSPORT_GOE_METHODS` or to `AUTO` selection lists; it is strictly opt-in via `--offload-transport-method=DUCKDB` or `OFFLOAD_TRANSPORT=DUCKDB`.
2. **Configuration Options (`src/goe/config/orchestration_config.py:47-197`, `L210-280`, `L316-721` and `src/goe/config/orchestration_defaults.py:675-800`):**
   - Add the DuckDB transport configuration attributes to `EXPECTED_CONFIG_ARGS`, `OrchestrationConfig` type annotations, `OrchestrationConfig.from_dict`, and `orchestration_defaults.py`:
     - `offload_transport_duckdb_version: str` (`OFFLOAD_TRANSPORT_DUCKDB_VERSION`, default `"1.5.5"`)
     - `offload_transport_duckdb_extension_path: str | None` (`OFFLOAD_TRANSPORT_DUCKDB_EXTENSION_PATH`, default `None`)
     - `offload_transport_duckdb_extension_dir: str | None` (`OFFLOAD_TRANSPORT_DUCKDB_EXTENSION_DIR`, default `None`, for pre-seeded `oracle` and `gcs` extension binaries)
     - `offload_transport_duckdb_extension_repository: str` (`OFFLOAD_TRANSPORT_DUCKDB_EXTENSION_REPOSITORY`, default `"https://cofin.github.io/duckdb-oracle"`)
     - `offload_transport_duckdb_threads: int` (`OFFLOAD_TRANSPORT_DUCKDB_THREADS`, default `2`)
     - `offload_transport_duckdb_memory_limit: str` (`OFFLOAD_TRANSPORT_DUCKDB_MEMORY_LIMIT`, default `"2GB"`)
     - `offload_transport_duckdb_temp_directory: str` (`OFFLOAD_TRANSPORT_DUCKDB_TEMP_DIRECTORY`, default `f"{offload_home}/run/duckdb"`)
     - `offload_transport_duckdb_max_bytes: int` (`OFFLOAD_TRANSPORT_DUCKDB_MAX_BYTES`, default `20 * 1024 * 1024 * 1024` = `21474836480`)
     - `offload_transport_duckdb_call_timeout_ms: int` (`OFFLOAD_TRANSPORT_DUCKDB_CALL_TIMEOUT_MS`, default `0`)
3. **Availability Gate (`is_duckdb_available` in `src/goe/offload/offload_transport.py:390`):**
   - `is_duckdb_available(offload_operation, config, offload_source_table=None, messages=None) -> bool` returns `False` and logs a `VVERBOSE` reason (matching `is_query_import_available` at `L346-390`) if any of the following conditions hold:
     1. `config.offload_staging_format != FILE_STORAGE_FORMAT_PARQUET`
     2. `config.target != DBTYPE_BIGQUERY`
     3. `import duckdb` fails or `duckdb.__version__ != config.offload_transport_duckdb_version`
     4. `offload_source_table` size (`size_in_bytes`) exceeds `config.offload_transport_duckdb_max_bytes`
     5. `(config.use_oracle_wallet or config.offload_transport_auth_using_oracle_wallet)` is `True` and the loaded `oracle` extension does not advertise external wallet auth support (`oracle_external_auth` / U3 capability probe)
     6. `offload_source_table` contains LOB or LONG columns (`ORACLE_TYPE_CLOB`, `ORACLE_TYPE_NCLOB`, `ORACLE_TYPE_BLOB`, `ORACLE_TYPE_LONG`, `ORACLE_TYPE_LONG_RAW`) and the loaded `oracle` extension does not advertise piecewise LOB read support (`oracle_lob_piecewise_fetch` / U4 capability probe)
     7. Probing `LOAD oracle` (and `LOAD gcs` / `INSTALL gcs FROM community` when `config.offload_fs_scheme == "gs"`) fails.

     ```python
     # SPDX-FileCopyrightText: 2026 The GOE Authors
     # SPDX-License-Identifier: Apache-2.0

     def is_duckdb_available(
         offload_operation: Any,
         config: Any,
         offload_source_table: Any = None,
         messages: Any = None,
         probe_extension: bool = True,
     ) -> bool:
         """Return True if DuckDB, duckdb-oracle, and duckdb-gcs satisfy all transport requirements."""
         if getattr(config, "offload_staging_format", None) != FILE_STORAGE_FORMAT_PARQUET:
             log(
                 "DuckDB transport is not available because OFFLOAD_STAGING_FORMAT is not PARQUET",
                 messages,
                 detail=VVERBOSE_LEVEL,
             )
             return False

         if getattr(config, "target", None) != DBTYPE_BIGQUERY:
             log(
                 "DuckDB transport is only supported for BigQuery targets",
                 messages,
                 detail=VVERBOSE_LEVEL,
             )
             return False

         try:
             import duckdb
         except ImportError:
             log("DuckDB transport is not available because duckdb is not installed", messages, detail=VVERBOSE_LEVEL)
             return False

         expected_version = getattr(config, "offload_transport_duckdb_version", "1.5.5")
         if getattr(duckdb, "__version__", None) != expected_version:
             log(
                 f"DuckDB version {getattr(duckdb, '__version__', None)} does not match required {expected_version}",
                 messages,
                 detail=VVERBOSE_LEVEL,
             )
             return False

         max_bytes = getattr(config, "offload_transport_duckdb_max_bytes", 20 * 1024 * 1024 * 1024)
         table_bytes = getattr(offload_source_table, "size_in_bytes", None)
         if table_bytes is not None and max_bytes and table_bytes > max_bytes:
             log(
                 f"Table size {table_bytes} exceeds OFFLOAD_TRANSPORT_DUCKDB_MAX_BYTES ({max_bytes})",
                 messages,
                 detail=VVERBOSE_LEVEL,
             )
             return False

         if not probe_extension:
             return True

         from goe.offload.transport.duckdb_transport import probe_duckdb_oracle_capabilities

         return probe_duckdb_oracle_capabilities(config, offload_source_table, messages)
     ```
