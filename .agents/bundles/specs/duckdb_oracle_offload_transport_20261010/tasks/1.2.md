# Task 1.2: Implement `OffloadTransportDuckDB` with community `gcs` extension (`gcss://`) and wire `offload_transport_factory`

## Objective

Implement `OffloadTransportDuckDB(OffloadTransport)` in `src/goe/offload/transport/duckdb_transport.py` and register its branch in `src/goe/offload/factory/offload_transport_factory.py` so GOE streams split Oracle batches in parallel via DuckDB `oracle_query` and the high-performance community `gcs` extension (`northpolesec/duckdb-gcs`, `COPY (...) TO 'gcss://<bucket>/<staging_prefix>/part-{i:05d}.parquet'`), with local file + `_dfs_client.copy_from_local` retained only as a fallback for non-GCS staging backends.

## Context

1. **Community `gcs` DuckDB Extension (`northpolesec/duckdb-gcs`) Architecture:**
   - **Extension Loading (`ensure_duckdb_gcs_extension`):**
     - Try `conn.execute("LOAD gcs")` first (zero network call when pre-seeded in `OFFLOAD_TRANSPORT_DUCKDB_EXTENSION_DIR` or `~/.duckdb/extensions`).
     - If `LOAD gcs` raises, acquire module-level `_gcs_setup_lock` (`threading.Lock()`) and execute `conn.execute("INSTALL gcs FROM community")` followed by `conn.execute("LOAD gcs")`.
   - **Performance Pragmas:**
     ```sql
     SET gcs_enable_metadata_cache = true;
     SET gcs_metadata_cache_ttl = 3600;
     SET gcs_list_cache_ttl = 3600;
     SET gcs_transfer_concurrency = <threads>;
     ```
   - **`gcss://` URI Scheme (`to_duckdb_gcs_uri`):**
     - Built-in `httpfs` claims `gs://` and `gcs://` (which require S3 XML HMAC keys and fail with ADC).
     - The community `gcs` extension registers the **`gcss://`** scheme (`gcss://<bucket>/<staging_prefix>/part-0000N.parquet`). Convert `gs://` and `gcs://` staging URIs to `gcss://` when executing DuckDB `COPY ... TO 'gcss://...' (FORMAT PARQUET, COMPRESSION SNAPPY)` so Parquet parts stream directly from DuckDB's C++ worker threads (`google-cloud-cpp`) to GCS without serializing under the Python GIL or staging to local disk first.
     - Retain local `temp_directory` + `self._dfs_client.copy_from_local` only as a fallback for non-GCS staging backends.
   - **Dual-Mode ADC Secret Provisioning (`configure_duckdb_gcs_secret`):**
     - Resolve credentials via `resolve_gcp_credentials(config)` (importing from `goe.util.gcp_credentials` if present, or falling back to `google.auth.default(scopes=["https://www.googleapis.com/auth/devstorage.read_write"])`).
     - **GCP Compute / Direct Service Account (`GCECredentials`, Cloud Run `K_SERVICE`/`K_REVISION`, or `ServiceAccountCredentials` without impersonation):**
       - Query `SELECT count(*) FROM duckdb_secrets() WHERE name = 'goe_gcs'`; if already `> 0`, skip re-executing DDL to prevent optimistic catalog write-write conflicts.
       - Otherwise execute parameterized DDL (always passing `PROJECT_ID` when known, because without `PROJECT_ID`, `google-cloud-cpp` fails to resolve billing/quotas and raises `IO Error`):
         ```sql
         CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER credential_chain, PROJECT_ID ?)
         ```
     - **Developer Workstation User ADC (`authorized_user`) or Impersonated Service Account (`impersonated_credentials.Credentials` / `GOOGLE_IMPERSONATE_SERVICE_ACCOUNT`):**
       - Because `google-cloud-cpp` `credential_chain` does not support `authorized_user` or Python-side impersonation, mint/refresh an OAuth2 access token (`https://www.googleapis.com/auth/devstorage.read_write` scope, refreshing when `expiry` is `None` or within a 10-minute / 600-second expiry margin) and provision:
         ```sql
         CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER access_token, ACCESS_TOKEN ?)
         ```
     - **`registered_state` C++ Client Caching Invariant:**
       - `northpolesec/duckdb-gcs` caches `google::cloud::storage::Client` in `client_context->registered_state` per connection and checks `registered_state` before `SecretManager`. `OffloadTransportDuckDB` opens a fresh DuckDB connection per offload execution / batch worker (and refreshes/recycles connections if a multi-batch run approaches the 10-minute token expiry margin).
2. **Reuse of Existing GOE Split & Projection Infrastructure (`src/goe/offload/offload_transport.py:639-720`, `L995-1136`):**
   - `self._get_transport_split_type(partition_chunk, native_range_split_available=False)` (`L1061-1080`) determines the split strategy and tunes `self._offload_transport_parallelism`.
   - `self._get_transport_row_source_query(split_type, partition_chunk, id_col_min=id_min, id_col_max=id_max)` (`L995-1023`) builds the Oracle subquery with `AS OF SCN <snapshot>` embedded on every table reference and `goe_offload_batch` (`0 .. parallelism - 1`) projected on multi-batch splits.
   - `self._build_offload_query_lists(convert_expressions_on_rdbms_side=True, for_qi=True)` (`L1082-1119`) wraps `DATE`, `TIMESTAMP`, `TIMESTAMP WITH (LOCAL) TIME ZONE`, `INTERVAL`, and string-staged `NUMBER` columns in Oracle-side `TO_CHAR(...)` expressions.
3. **Invariants (SCN, Time Zone, Resource Bounds, Secrets Hygiene, Cleanup):**
   - **R5 (SCN):** Assert `f"AS OF SCN {self._offload_transport_snapshot}"` appears in every batch Oracle SQL string before execution when `self._offload_transport_consistent_read` is `True`.
   - **R6 (Time Zone):** Set `os.environ["ORA_SDTZ"] = "UTC"` before loading `oracle`.
   - **R7 (Secrets Hygiene):** Never log raw Oracle passwords or GCS access tokens in `self._log()` calls.

def to_duckdb_gcs_uri(uri: str) -> str:
    """Convert a gs:// or gcs:// URI to the gcss:// scheme registered by the community gcs extension."""
    if uri.startswith("gs://"):
        return "gcss://" + uri[len("gs://") :]
    if uri.startswith("gcs://"):
        return "gcss://" + uri[len("gcs://") :]
    return uri


def ensure_duckdb_gcs_extension(conn: Any, threads: int = 2) -> None:
    """Load the community gcs extension (installing under a lock if needed) and apply performance pragmas."""
    try:
        conn.execute("LOAD gcs")
    except Exception:
        with _gcs_setup_lock:
            conn.execute("INSTALL gcs FROM community")
            conn.execute("LOAD gcs")

    conn.execute("SET gcs_enable_metadata_cache = true")
    conn.execute("SET gcs_metadata_cache_ttl = 3600")
    conn.execute("SET gcs_list_cache_ttl = 3600")
    conn.execute(f"SET gcs_transfer_concurrency = {max(1, int(threads))}")


def _uses_native_credential_chain(credentials: Any, config: Any = None) -> bool:
    """Return True when running on GCE/Cloud Run or using a direct service account without impersonation."""
    if getattr(config, "google_impersonate_service_account", None) or os.environ.get(
        "GOOGLE_IMPERSONATE_SERVICE_ACCOUNT"
    ):
        return False
    cls_module = getattr(credentials.__class__, "__module__", "")
    cls_name = getattr(credentials.__class__, "__name__", "")
    if "impersonated_credentials" in cls_module:
        return False
    if "compute_engine" in cls_module or cls_name == "GCECredentials":
        return True
    if os.environ.get("K_SERVICE") or os.environ.get("K_REVISION"):
        return True
    if "service_account" in cls_module:
        return True
    return False


def _resolve_credentials_and_project(config: Any) -> tuple[Any, str | None]:
    """Resolve ADC credentials and project ID using goe.util.gcp_credentials or google.auth.default."""
    project_id = getattr(config, "bigquery_dataset_project", None) or os.environ.get("GOOGLE_CLOUD_PROJECT")
    try:
        from goe.util.gcp_credentials import resolve_gcp_credentials

        creds, detected_project = resolve_gcp_credentials(config, scopes=[GCS_STORAGE_RW_SCOPE])
        return creds, project_id or detected_project
    except ImportError:
        creds, detected_project = google.auth.default(scopes=[GCS_STORAGE_RW_SCOPE])
        return creds, project_id or detected_project


def configure_duckdb_gcs_secret(
    conn: Any,
    credentials: Any,
    project_id: str | None = None,
    config: Any = None,
) -> str:
    """Provision the goe_gcs DuckDB secret using credential_chain (Compute/SA) or access_token (User ADC/Impersonation)."""
    if _uses_native_credential_chain(credentials, config=config):
        existing_row = conn.execute(
            "SELECT count(*) FROM duckdb_secrets() WHERE name = 'goe_gcs'"
        ).fetchone()
        if not existing_row or int(existing_row[0]) == 0:
            if project_id:
                conn.execute(
                    "CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER credential_chain, PROJECT_ID ?)",
                    [project_id],
                )
            else:
                conn.execute("CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER credential_chain)")
        return "credential_chain"

    if hasattr(credentials, "with_scopes") and not getattr(credentials, "scopes", None):
        credentials = credentials.with_scopes([GCS_STORAGE_RW_SCOPE])

    expiry = getattr(credentials, "expiry", None)
    now_utc = datetime.now(timezone.utc).replace(tzinfo=None)
    needs_refresh = (
        not getattr(credentials, "token", None)
        or expiry is None
        or (expiry - now_utc) <= timedelta(seconds=GCS_TOKEN_REFRESH_MARGIN_SECONDS)
    )
    if needs_refresh:
        credentials.refresh(GoogleAuthRequest())

    conn.execute(
        "CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER access_token, ACCESS_TOKEN ?)",
        [credentials.token],
    )
    return "access_token"


def build_duckdb_cast_projection(
    staging_columns: list[Any],
    base64_columns: set[str] | None = None,
) -> str:
    """Build the outer DuckDB SELECT projection casting each column to its exact Parquet staging type."""
    encoded_cols = base64_columns or set()
    expressions: list[str] = []
    for col in staging_columns:
        source_name = col.name.upper()
        alias_name = col.staging_file_column_name
        duckdb_type = DUCKDB_PARQUET_TYPE_MAP.get(col.data_type)
        if not duckdb_type:
            raise OffloadTransportException(f"Unsupported Parquet staging column type for DuckDB: {col.data_type}")
        if col.name in encoded_cols or source_name in encoded_cols:
            expressions.append(f'base64(CAST("{source_name}" AS BLOB)) AS "{alias_name}"')
        else:
            expressions.append(f'CAST("{source_name}" AS {duckdb_type}) AS "{alias_name}"')
    return ", ".join(expressions)


def verify_batch_scn_invariant(
    batch_sql: str,
    consistent_read: bool,
    snapshot_scn: int | None,
) -> None:
    """Verify that AS OF SCN is present in the Oracle batch SQL when consistent read is enabled."""
    if consistent_read and snapshot_scn is not None:
        expected_clause = f"AS OF SCN {snapshot_scn}"
        if expected_clause.upper() not in batch_sql.upper():
            raise ValueError(
                f"DuckDB transport SCN invariant violated: expected '{expected_clause}' in batch SQL"
            )


def probe_duckdb_oracle_capabilities(
    config: Any,
    offload_source_table: Any = None,
    messages: Any = None,
) -> bool:
    """Probe whether the duckdb-oracle and duckdb-gcs extensions load and satisfy wallet and LOB gates."""
    try:
        import duckdb
    except ImportError:
        return False

    os.environ["ORA_SDTZ"] = "UTC"
    conn = None
    try:
        connect_cfg: dict[str, str] = {"allow_unsigned_extensions": "true"}
        ext_dir = getattr(config, "offload_transport_duckdb_extension_dir", None)
        if ext_dir:
            connect_cfg["extension_directory"] = str(ext_dir)

        conn = duckdb.connect(":memory:", config=connect_cfg)
        ext_path = getattr(config, "offload_transport_duckdb_extension_path", None)
        if ext_path:
            conn.execute(f"LOAD '{ext_path}'")
        else:
            repo = getattr(
                config,
                "offload_transport_duckdb_extension_repository",
                "https://cofin.github.io/duckdb-oracle",
            )
            conn.execute(f"SET custom_extension_repository='{repo}'")
            conn.execute("LOAD oracle")

        if getattr(config, "offload_fs_scheme", "gs") in ("gs", "gcs", "gcss"):
            ensure_duckdb_gcs_extension(
                conn,
                threads=getattr(config, "offload_transport_duckdb_threads", 2),
            )

        settings_rows = conn.execute("SELECT name FROM duckdb_settings() WHERE name LIKE 'oracle_%'").fetchall()
        setting_names = {row[0] for row in settings_rows}

        uses_wallet = bool(
            getattr(config, "use_oracle_wallet", False)
            or getattr(config, "offload_transport_auth_using_oracle_wallet", False)
        )
        if uses_wallet and "oracle_external_auth" not in setting_names:
            if messages:
                messages.log(
                    "DuckDB transport is not available because Oracle Wallet requires duckdb-oracle U3 external auth",
                    detail=VVERBOSE_LEVEL,
                )
            return False

        columns = getattr(offload_source_table, "columns", None) or []
        has_lob = any(getattr(col, "data_type", None) in ORACLE_LOB_AND_LONG_TYPES for col in columns)
        if has_lob and "oracle_lob_piecewise_fetch" not in setting_names:
            if messages:
                messages.log(
                    "DuckDB transport is not available for LOB/LONG columns without duckdb-oracle U4 support",
                    detail=VVERBOSE_LEVEL,
                )
            return False

        return True
    except Exception as exc:
        if messages:
            messages.log(
                f"DuckDB extension probe failed: {exc}",
                detail=VVERBOSE_LEVEL,
            )
        return False
    finally:
        if conn is not None:
            conn.close()


class OffloadTransportDuckDB(OffloadTransport):
    """Offload transport that streams Oracle batches into GCS Parquet via DuckDB, duckdb-oracle, and duckdb-gcs."""

    def __init__(
        self,
        offload_target_table: Any,
        offload_source_table: Any,
        offload_operation: Any,
        orchestration_config: Any,
        messages: Any,
        dfs_client: Any,
        rdbms_columns_override: list[Any] | None = None,
    ) -> None:
        """Initialize the DuckDB offload transport and enforce UTC session time zone."""
        os.environ["ORA_SDTZ"] = "UTC"
        super().__init__(
            offload_target_table,
            offload_source_table,
            offload_operation,
            orchestration_config,
            messages,
            dfs_client,
            rdbms_columns_override=rdbms_columns_override,
        )
        self._duckdb_threads: int = getattr(
            orchestration_config, "offload_transport_duckdb_threads", 2
        )
        self._duckdb_memory_limit: str = getattr(
            orchestration_config, "offload_transport_duckdb_memory_limit", "2GB"
        )
        self._duckdb_temp_root: str = getattr(
            orchestration_config,
            "offload_transport_duckdb_temp_directory",
            os.path.join(os.environ.get("OFFLOAD_HOME", "/tmp"), "run", "duckdb"),
        )
        self._duckdb_extension_path: str | None = getattr(
            orchestration_config, "offload_transport_duckdb_extension_path", None
        )
        self._duckdb_extension_dir: str | None = getattr(
            orchestration_config, "offload_transport_duckdb_extension_dir", None
        )
        self._duckdb_extension_repo: str = getattr(
            orchestration_config,
            "offload_transport_duckdb_extension_repository",
            "https://cofin.github.io/duckdb-oracle",
        )
        self._duckdb_call_timeout_ms: int = getattr(
            orchestration_config, "offload_transport_duckdb_call_timeout_ms", 0
        )
        self._validate_staging_file_format()

    def _is_direct_gcs_streaming_enabled(self) -> bool:
        """Return True when the staging location uses GCS (gs://, gcs://, or gcss://)."""
        staging_loc = self._staging_file.get_staging_table_location()
        return staging_loc.startswith(("gs://", "gcs://", "gcss://"))

    def _base64_column_names(self) -> set[str]:
        """Return the set of source column names that must be base64-encoded in Parquet."""
        if not self._staging_file.binary_data_as_base64():
            return set()
        return {
            col.name.upper()
            for col in self._rdbms_columns
            if col.canonical_type in (GOE_TYPE_BINARY, GOE_TYPE_LARGE_BINARY)
        }

    def _build_batch_oracle_queries(self, partition_chunk: Any = None) -> list[str]:
        """Construct the per-batch Oracle SQL queries with hints, TO_CHAR casts, and AS OF SCN."""
        split_type = self._get_transport_split_type(
            partition_chunk,
            native_range_split_available=False,
        )
        id_col_min = None
        id_col_max = None
        if split_type == SPLIT_TYPE_BY_ID_RANGE:
            id_col_min, id_col_max = self._get_id_range()

        row_source_query = self._get_transport_row_source_query(
            split_type,
            partition_chunk,
            id_col_min=id_col_min,
            id_col_max=id_col_max,
        )
        _, query_expression_list = self._build_offload_query_lists(
            convert_expressions_on_rdbms_side=True,
            for_qi=True,
        )
        projection = self._sql_projection_from_offload_query_expression_list(query_expression_list)
        hint_block = self._rdbms_api.get_rdbms_session_setup_hint(
            self._offload_transport_rdbms_session_parameters,
            self._source_table.parallel_query_hint(),
        )
        action_comment = f"/* {self._rdbms_action()} */"

        parallelism = max(1, int(self._offload_transport_parallelism or 1))
        if parallelism <= 1 or split_type is None:
            sql = f"SELECT {action_comment} {hint_block} {projection} FROM ({row_source_query})"
            verify_batch_scn_invariant(
                sql,
                bool(self._offload_transport_consistent_read),
                self._offload_transport_snapshot,
            )
            return [sql]

        queries: list[str] = []
        for batch_idx in range(parallelism):
            sql = (
                f"SELECT {action_comment} {hint_block} {projection} "
                f"FROM ({row_source_query}) WHERE goe_offload_batch = {batch_idx}"
            )
            verify_batch_scn_invariant(
                sql,
                bool(self._offload_transport_consistent_read),
                self._offload_transport_snapshot,
            )
            queries.append(sql)
        return queries

    def _parquet_compression_codec(self) -> str:
        """Return the DuckDB Parquet compression codec matching compress_load_table."""
        return "SNAPPY" if self._compress_load_table else "UNCOMPRESSED"

    def _configure_worker_connection(
        self,
        conn: Any,
        parallelism: int,
        use_direct_gcs: bool,
        gcp_credentials: Any = None,
        gcp_project_id: str | None = None,
    ) -> None:
        """Load oracle and gcs extensions, apply session settings, and create redacted secrets."""
        if self._duckdb_extension_path:
            conn.execute(f"LOAD '{self._duckdb_extension_path}'")
        else:
            conn.execute(f"SET custom_extension_repository='{self._duckdb_extension_repo}'")
            conn.execute("LOAD oracle")

        conn.execute(f"SET oracle_connection_limit={max(8, parallelism)}")
        setting_rows = conn.execute("SELECT name FROM duckdb_settings() WHERE name LIKE 'oracle_%'").fetchall()
        setting_names = {row[0] for row in setting_rows}
        if "oracle_call_timeout_ms" in setting_names:
            conn.execute(f"SET oracle_call_timeout_ms={int(self._duckdb_call_timeout_ms)}")
        if "oracle_session_init_sql" in setting_names:
            init_cmds = self._rdbms_api.get_rdbms_session_setup_commands(
                self._rdbms_module,
                self._rdbms_action(),
                self._offload_transport_rdbms_session_parameters,
                include_semi_colons=True,
                escape_semi_colons=False,
                max_ts_scale=self._max_ts_scale(),
            )
            joined_init = " ".join(init_cmds).replace("'", "''")
            conn.execute(f"SET oracle_session_init_sql='{joined_init}'")

        dsn = getattr(self._orchestration_config, "ora_conn", "")
        user = getattr(self._orchestration_config, "rdbms_app_user", "")
        password = getattr(self._orchestration_config, "rdbms_app_pass", "")
        self._log(
            f"DuckDB Secret: CREATE TEMPORARY SECRET goe_ora_secret (TYPE oracle, DSN '{dsn}', USER '{user}', PASSWORD '***')",
            detail=VVERBOSE_LEVEL,
        )
        escaped_dsn = str(dsn).replace("'", "''")
        escaped_user = str(user).replace("'", "''")
        escaped_pass = str(password).replace("'", "''")
        conn.execute(
            f"CREATE TEMPORARY SECRET goe_ora_secret (TYPE oracle, CONNECTION_STRING '{escaped_dsn}', "
            f"USER '{escaped_user}', PASSWORD '{escaped_pass}')"
        )

        if use_direct_gcs and gcp_credentials is not None:
            ensure_duckdb_gcs_extension(conn, threads=self._duckdb_threads)
            secret_mode = configure_duckdb_gcs_secret(
                conn,
                credentials=gcp_credentials,
                project_id=gcp_project_id,
                config=self._orchestration_config,
            )
            self._log(
                f"DuckDB GCS Secret: CREATE OR REPLACE SECRET goe_gcs (TYPE gcp, PROVIDER {secret_mode}, CREDENTIALS '***')",
                detail=VVERBOSE_LEVEL,
            )

    def _run_single_batch(
        self,
        batch_idx: int,
        oracle_sql: str,
        cast_projection: str,
        target_parquet_uri: str,
        local_fallback_path: Path | None,
        worker_temp_dir: Path,
        parallelism: int,
        use_direct_gcs: bool,
        gcp_credentials: Any = None,
        gcp_project_id: str | None = None,
    ) -> tuple[int, int]:
        """Execute a single Oracle -> DuckDB COPY batch (direct gcss:// or local fallback)."""
        import duckdb

        compression = self._parquet_compression_codec()
        escaped_ora_sql = oracle_sql.replace("'", "''")
        copy_sql = (
            f"COPY (SELECT {cast_projection} FROM oracle_query('goe_ora_secret', '{escaped_ora_sql}')) "
            f"TO '{target_parquet_uri}' (FORMAT PARQUET, COMPRESSION {compression})"
        )
        self._log(f"DuckDB batch {batch_idx} Oracle SQL: {oracle_sql}", detail=VERBOSE_LEVEL)
        self._log(
            f"DuckDB batch {batch_idx} COPY SQL: COPY (SELECT {cast_projection} FROM oracle_query('goe_ora_secret', <ora_sql>)) "
            f"TO '{target_parquet_uri}' (FORMAT PARQUET, COMPRESSION {compression})",
            detail=VERBOSE_LEVEL,
        )
        if self._dry_run:
            return 0, 0

        worker_temp_dir.mkdir(parents=True, exist_ok=True)
        connect_config: dict[str, str] = {
            "allow_unsigned_extensions": "true",
            "threads": str(self._duckdb_threads),
            "memory_limit": self._duckdb_memory_limit,
            "temp_directory": str(worker_temp_dir),
        }
        if self._duckdb_extension_dir:
            connect_config["extension_directory"] = str(self._duckdb_extension_dir)

        conn = duckdb.connect(":memory:", config=connect_config)
        try:
            self._configure_worker_connection(
                conn,
                parallelism=parallelism,
                use_direct_gcs=use_direct_gcs,
                gcp_credentials=gcp_credentials,
                gcp_project_id=gcp_project_id,
            )
            result = conn.execute(copy_sql).fetchone()
            rows_written = int(result[0]) if result else 0
            bytes_written = (
                local_fallback_path.stat().st_size
                if local_fallback_path is not None and local_fallback_path.exists()
                else 0
            )
            return rows_written, bytes_written
        finally:
            conn.close()

    def transport(self, partition_chunk: Any = None) -> int | None:
        """Execute the DuckDB offload transport step and return the number of rows imported."""
        self._reset_transport_context()

        def step_fn() -> int | None:
            self._clean_staging_area()
            batch_queries = self._build_batch_oracle_queries(partition_chunk)
            cast_projection = build_duckdb_cast_projection(
                self._staging_file.get_staging_columns(),
                base64_columns=self._base64_column_names(),
            )
            parallelism = len(batch_queries)
            staging_dir = self._staging_file.get_staging_table_location().rstrip("/")
            use_direct_gcs = self._is_direct_gcs_streaming_enabled()

            gcp_credentials = None
            gcp_project_id = None
            if use_direct_gcs and not self._dry_run:
                gcp_credentials, gcp_project_id = _resolve_credentials_and_project(
                    self._orchestration_config
                )

            Path(self._duckdb_temp_root).mkdir(parents=True, exist_ok=True)
            run_dir = Path(tempfile.mkdtemp(prefix="goe_duckdb_", dir=self._duckdb_temp_root))
            try:
                total_rows = 0
                total_bytes = 0
                batch_targets: list[tuple[int, str, Path | None]] = []
                for idx in range(parallelism):
                    if use_direct_gcs:
                        gcss_uri = to_duckdb_gcs_uri(f"{staging_dir}/part-{idx:05d}.parquet")
                        batch_targets.append((idx, gcss_uri, None))
                    else:
                        local_path = run_dir / f"part-{idx:05d}.parquet"
                        batch_targets.append((idx, str(local_path), local_path))

                with ThreadPoolExecutor(max_workers=parallelism) as executor:
                    futures = {
                        executor.submit(
                            self._run_single_batch,
                            idx,
                            batch_queries[idx],
                            cast_projection,
                            target_uri,
                            local_path,
                            run_dir / f"spill_{idx:05d}",
                            parallelism,
                            use_direct_gcs,
                            gcp_credentials,
                            gcp_project_id,
                        ): (idx, local_path)
                        for idx, target_uri, local_path in batch_targets
                    }
                    for future in as_completed(futures):
                        rows_written, bytes_written = future.result()
                        total_rows += rows_written
                        total_bytes += bytes_written

                if not self._dry_run:
                    if use_direct_gcs:
                        total_bytes = self._get_staging_area_size() or 0
                    else:
                        for idx, _target_uri, local_path in sorted(batch_targets, key=lambda item: item[0]):
                            if local_path is not None:
                                remote_uri = f"{staging_dir}/part-{idx:05d}.parquet"
                                self._dfs_client.copy_from_local(str(local_path), remote_uri, overwrite=True)
                                local_path.unlink(missing_ok=True)

                self._transport_context[TRANSPORT_CXT_ROWS] = total_rows if not self._dry_run else None
                self._transport_context[TRANSPORT_CXT_BYTES] = total_bytes if not self._dry_run else None
                self._target_table.post_transport_tasks(self._staging_file)
                if not self._dry_run:
                    self._check_rows_imported(total_rows)
                return total_rows if not self._dry_run else None
            finally:
                shutil.rmtree(run_dir, ignore_errors=True)

        return self._messages.offload_step(
            command_steps.STEP_STAGING_TRANSPORT,
            step_fn,
            execute=not self._dry_run,
        )
