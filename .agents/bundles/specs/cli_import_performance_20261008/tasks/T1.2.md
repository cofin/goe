# Task T1.2: Transitive Import Decoupling in `goe.listener.utils` & `goe.util.goe_log_fh`

## Objective

Eliminate ~521 ms of transitive imports (`litestar`, `numpy`, `lark`, and `gcsfs`) from non-Listener CLI command executions by converting `orchestrate` and `ping` in `src/goe/listener/utils/__init__.py` and `GCS_MIN_BLOCK_SIZE` in `src/goe/util/goe_log_fh.py` to `if TYPE_CHECKING:` + PEP 562 `__getattr__` lazy resolution.

## Steps

1. Add `test_offload_messages_import_does_not_load_litestar_or_gcsfs` in `tests/unit/cli/test_cli_root.py` and confirm initial failure.
2. Update `src/goe/listener/utils/__init__.py` to lazily resolve `orchestrate` and `ping` via `if TYPE_CHECKING:` + PEP 562 `__getattr__` while keeping lightweight `cache`, `groupby`, and `system` exports.
3. Update `src/goe/util/goe_log_fh.py` to lazily resolve `GCS_MIN_BLOCK_SIZE` via `if TYPE_CHECKING:` + PEP 562 `__getattr__` and `bind_lazy_imports(__name__, _LAZY_IMPORTS)` inside `GOELogFileHandle._get_fs()` when opening `gs://` paths, and move inline `#` comments in `flush()` into its docstring.
4. Run `uv run pytest tests/unit/cli tests/unit/listener tests/unit/offload/test_offload_messages.py`, `uv run ruff check`, and `uv run mypy src/goe`.

## Acceptance Criteria

- [x] **REQ-PERF-03**: Importing `goe.offload.offload_messages`, `goe.listener.utils.cache`, or `goe.util.goe_log_fh` does not load `litestar` or `gcsfs` into `sys.modules`, while preserving all public attributes and static types.
