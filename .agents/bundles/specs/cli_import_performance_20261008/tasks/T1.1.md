# Task T1.1: Borderless Rich-Click Config & Zero-Type-Loss CLI Lazy Binding

## Objective

Configure borderless modern `rich-click` formatting in `src/goe/cli/config.py` and `src/goe/cli/main.py`, create `src/goe/cli/_lazy.py`, and convert `src/goe/cli/common.py` and `src/goe/cli/commands/{connect,listener,offload,report,sync,validate}.py` to use `if TYPE_CHECKING:` + PEP 562 `__getattr__` + `bind_lazy_imports(__name__, _LAZY_IMPORTS)` so CLI help/menu rendering loads zero heavy backend modules while preserving 100% of static type hints and `@patch(...)` unit test seams.

## Steps

1. Add `test_cli_help_does_not_import_heavy_backends` and `test_cli_lazy_attribute_resolution` in `tests/unit/cli/test_cli_root.py` and confirm initial failure before lazy bindings are wired.
2. Create `src/goe/cli/_lazy.py` with `LazyImportMap`, `resolve_lazy_attribute`, and `bind_lazy_imports`.
3. Update `src/goe/cli/common.py` to use `if TYPE_CHECKING:` + `_LAZY_IMPORTS` + `__getattr__` + `bind_lazy_imports`.
4. Update `src/goe/cli/commands/{connect,listener,offload,report,sync,validate}.py` to use `if TYPE_CHECKING:` + `_LAZY_IMPORTS` + `__getattr__` + `bind_lazy_imports(__name__, _LAZY_IMPORTS)` at callback entry.
5. Run `uv run pytest tests/unit/cli`, `uv run ruff check src/goe/cli tests/unit/cli`, and `uv run mypy src/goe/cli`.

## Acceptance Criteria

- [x] **REQ-PERF-01**: Borderless modern `rich-click` help rendering without duplicate headings or unparsed Rich markup tags.
- [x] **REQ-PERF-02**: Zero-type-loss lazy loading across `src/goe/cli/` verified by `mypy`, `ruff`, and `pytest tests/unit/cli`.
