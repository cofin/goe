# Task 1.1: Remove `bin/*` wrappers and Redis deprecation shims

## Objective

Delete every `DeprecationWarning` shim that exists only for backward compatibility: the seven `bin/*` CLI delegators (plus their packaging, shell, and test references) and the Redis aliases `goe.util.redis_tools` / `goe.listener.utils.cache.RedisClient`. After this task the only CLI entrypoint is the `goe` console script and the only cache names are `MemoryCache` / `MemorySyncCache`.

## Context

- Baseline commit `46890a8`. Console script: `[project.scripts] goe = "goe.cli.main:cli"` (`pyproject.toml:71`).
- `bin/offload`, `bin/connect`, `bin/listener`, `bin/logmgr`, `bin/agg_validate`, `bin/offload_status_report`, `bin/schema_sync` are 20-line Python scripts that warn and call `goe.cli.main.cli` with an inserted subcommand.
- `Makefile:174-175` (inside the `target:` recipe that starts at `Makefile:172`):
  ```makefile
  	@mkdir -p $(TARGET_DIR)/bin
  	@cp bin/{offload,connect,logmgr,agg_validate} $(TARGET_DIR)/bin 2>/dev/null || true
  ```
- `docs/google_cloud_run/goe.sh:18-20`:
  ```bash
  export USER=$(whoami)
  . ${OFFLOAD_HOME}/.venv/bin/activate
  ${OFFLOAD_HOME}/bin/$*
  ```
  The activated venv puts the `goe` console script on `PATH`.
- `tests/unit/cli/test_bin_wrappers.py:1-18` subprocess-executes every `bin/*` script (fails at baseline: `ModuleNotFoundError: No module named 'goe'` because the shebang uses the system interpreter).
- `tests/unit/listener/test_deprecation_shims.py:1-56` contains `test_cache_redis_client_deprecation_shim`, `test_redis_tools_module_deprecation_shim`, and the parametrized `test_legacy_bin_wrapper_deprecation`; every test in the file covers a shim deleted here, so the whole file is deleted.
- `tests/unit/cli/test_listener_command.py:57` docstring reads `"""Verify bare goe listener (and bin/listener) starts the server by default."""`.
- `src/goe/util/redis_tools.py:1-34` is a pure shim (`RedisClient(MemorySyncCache)`, module `cache = RedisClient`, import-time `DeprecationWarning`). `git grep -n "redis_tools" -- src tests tools` finds no importer other than `tests/unit/listener/test_deprecation_shims.py:24-29`.
- `src/goe/listener/utils/cache.py`:
  - line 10 `import warnings` is used only by the two `RedisClient` shims.
  - lines 189-203 `MemoryCache.__getattr__` returns `MemoryCache`/`MemorySyncCache` for those names (needed because `goe.listener.utils.__init__` binds the package attribute `cache` to the `MemoryCache()` instance) and has a `RedisClient` branch at 191-198.
  - lines 340-350 module-level `__getattr__` exists only for `RedisClient`.
- `src/goe/goe.py:24`, `src/goe/offload/offload_messages.py:16`, `src/goe/connect/connect.py:52` import `MemorySyncCache` directly (aliased); they do not use the shims and are cleaned in Task `1.2`.
- `tools/goe-listener.sh:43` (`$OFFLOAD_HOME/bin/listener`) is deleted in Task `1.2`; `pyproject.toml:289,354` `bin` exclusions are removed in Task `1.5`; documentation references are removed in Task `1.6`.
- Strategy justification: deleting deprecated shims is a behavior-preserving deletion for every supported entrypoint (`goe <subcommand>`), so `characterization` applies; no new failing test is written.
