# Task 1.1: Delete `bin/*` CLI wrapper scripts and update build/shell entrypoints

## Objective
Remove all seven deprecated `bin/*` CLI wrapper scripts (`bin/offload`, `bin/connect`, `bin/listener`, `bin/logmgr`, `bin/agg_validate`, `bin/offload_status_report`, `bin/schema_sync`), strip `bin/` packaging from `Makefile`, update `docs/google_cloud_run/goe.sh` to invoke the `goe` console entrypoint directly, and remove `test_legacy_bin_wrapper_deprecation` from `tests/unit/listener/test_deprecation_shims.py`.

## Context
- All CLI commands are consolidated under the `goe` console script (`goe = "goe.cli:main"` in `pyproject.toml:66`).
- Seven legacy bash/Python wrapper scripts remain in `bin/`:
  - `bin/offload` (`bin/offload:1-21`)
  - `bin/connect` (`bin/connect:1-21`)
  - `bin/listener` (`bin/listener:1-21`)
  - `bin/logmgr` (`bin/logmgr:1-21`)
  - `bin/agg_validate` (`bin/agg_validate:1-21`)
  - `bin/offload_status_report` (`bin/offload_status_report:1-21`)
  - `bin/schema_sync` (`bin/schema_sync:1-21`)
- `Makefile:174-175` copies `bin/{offload,connect,logmgr,agg_validate}` into `$(TARGET_DIR)/bin` during `build-package`.
- `docs/google_cloud_run/goe.sh:20` runs `${OFFLOAD_HOME}/bin/$*` instead of `goe "$@"`. (Note: `tools/goe-listener.sh` and `pyproject.toml` `bin/` exclusions are handled in Tasks `1.2` and `1.3` respectively to maintain disjoint file ownership.)
- `tests/unit/listener/test_deprecation_shims.py:32-57` (`test_legacy_bin_wrapper_deprecation`) asserts the existence of `bin/offload`, `bin/connect`, `bin/listener`, `bin/logmgr`, `bin/agg_validate`, `bin/offload_status_report`, and `bin/schema_sync`.

## Steps

### Step 1: Delete all seven `bin/*` wrapper scripts
Delete the entire `bin/` directory and its seven wrapper files:
```bash
git rm bin/offload bin/connect bin/listener bin/logmgr bin/agg_validate bin/offload_status_report bin/schema_sync
```

### Step 2: Remove `bin/` copy step from `Makefile`
In `Makefile:172-182`, remove lines `174-175`:
```makefile
	@mkdir -p $(TARGET_DIR)/conf
	@mkdir -p $(TARGET_DIR)/doc
	@mkdir -p $(TARGET_DIR)/lib/jars
	@mkdir -p $(TARGET_DIR)/license
	@mkdir -p $(TARGET_DIR)/log
	@mkdir -p $(TARGET_DIR)/run
	@mkdir -p $(TARGET_DIR)/sql
	@mkdir -p $(TARGET_DIR)/tools
	@mkdir -p $(TARGET_DIR)/version
```

### Step 3: Update `docs/google_cloud_run/goe.sh`
In `docs/google_cloud_run/goe.sh:16-21`, replace `${OFFLOAD_HOME}/bin/$*` with `goe "$@"`:
```bash
echo "Executing command: goe $*"

exec goe "$@"
```

### Step 4: Remove `test_legacy_bin_wrapper_deprecation` from `tests/unit/listener/test_deprecation_shims.py`
Update `tests/unit/listener/test_deprecation_shims.py:1-57` to remove `test_legacy_bin_wrapper_deprecation` (lines 32–57) and unused `Path` / `pytest` imports so only the Redis shim tests remain until Task `1.2` deletes the file:
```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

"""Unit tests for Redis deprecation shims prior to removal in Task 1.2."""

from __future__ import annotations

import importlib
import sys
import warnings

from goe.listener.utils import cache
from goe.listener.utils.cache import MemorySyncCache


def test_cache_redis_client_deprecation_shim() -> None:
    """Verify cache.RedisClient aliases MemorySyncCache with a DeprecationWarning."""
    with warnings.catch_warnings(record=True) as caught:
        warnings.simplefilter("always", DeprecationWarning)
        cls = getattr(cache, "RedisClient")
        assert cls is MemorySyncCache
        assert any("RedisClient is deprecated" in str(w.message) for w in caught)


def test_redis_tools_module_deprecation_shim() -> None:
    """Verify goe.util.redis_tools emits a DeprecationWarning on import."""
    sys.modules.pop("goe.util.redis_tools", None)
    with warnings.catch_warnings(record=True) as caught:
        warnings.simplefilter("always", DeprecationWarning)
        mod = importlib.import_module("goe.util.redis_tools")
        assert mod.RedisClient is MemorySyncCache
        assert any("goe.util.redis_tools is deprecated" in str(w.message) for w in caught)
```
