# Task 1.4: Synchronize `docs/user_guide.md` and OKF knowledge bundle files

## Objective
Update `docs/user_guide.md` to replace all 22 `$OFFLOAD_HOME/bin/offload` command examples with `goe offload` and document the removal of `bin/*` wrappers and `goe.util.redis_tools`, and synchronize `.agents/bundles/knowledge/patterns/cli-architecture.md`, `.agents/bundles/knowledge/patterns/serialization-and-utils.md`, and `.agents/bundles/product/product.md` with the current architecture.

## Context
- `docs/user_guide.md` contains 22 occurrences of `$OFFLOAD_HOME/bin/offload` at lines `31, 49, 106, 120, 142, 218, 226, 236, 271, 291, 326, 353, 363, 382, 383, 384, 385, 386, 601, 769, 837, 883`.
- `.agents/bundles/knowledge/patterns/cli-architecture.md:1-76` still includes a `### 3. Legacy bin/ Wrapper Delegators` section at lines `33-36` and mentions `bin/` wrappers in its frontmatter description and title.
- `.agents/bundles/knowledge/patterns/serialization-and-utils.md:1-54` should document that `goe.util.json_tools` is the sole JSON serialization module (`goe.util.serialization` removed) and that in-process caching (`MemoryCache` and `MemorySyncCache` in `src/goe/listener/utils/cache.py`) has completely replaced `goe.util.redis_tools` and external Redis/Valkey dependencies.
- `.agents/bundles/product/product.md:19` still mentions `Valkey` in `- Includes a REST Listener and MCP service (Litestar, Granian, litestar-queues, Valkey) for remote orchestration and event inspection.`

## Steps

### Step 1: Update `docs/user_guide.md`
1. Replace all 22 occurrences of `$OFFLOAD_HOME/bin/offload` in `docs/user_guide.md` (lines `31, 49, 106, 120, 142, 218, 226, 236, 271, 291, 326, 353, 363, 382, 383, 384, 385, 386, 601, 769, 837, 883`) with `goe offload`.
2. Add a concise **CLI Entrypoint & Migration Note** callout near the top of `docs/user_guide.md` (above the first `goe offload` invocation at line 31):
```markdown
> **Note**: All GOE commands are invoked via the unified `goe` CLI (`goe offload`, `goe connect`, `goe listener`, `goe logmgr`, `goe agg-validate`, `goe status-report`, `goe schema-sync`). Legacy `$OFFLOAD_HOME/bin/*` wrapper scripts and the `goe.util.redis_tools` compatibility shim have been removed.
```

### Step 2: Update `.agents/bundles/knowledge/patterns/cli-architecture.md`
1. Update the YAML frontmatter `description` in `.agents/bundles/knowledge/patterns/cli-architecture.md:1-7` to remove `legacy bin/ wrapper delegation`.
2. Remove section `### 3. Legacy bin/ Wrapper Delegators` (`cli-architecture.md:33-36`) and renumber subsequent sections cleanly, stating that `goe` (`src/goe/cli/__init__.py`) is the sole entrypoint and `bin/*` wrappers have been removed.

### Step 3: Update `.agents/bundles/knowledge/patterns/serialization-and-utils.md` and `.agents/bundles/product/product.md`
1. In `.agents/bundles/knowledge/patterns/serialization-and-utils.md`, document that `src/goe/util/json_tools.py` is the canonical JSON serialization module (`src/goe/util/serialization.py`, `env.py`, `text.py`, `uuids.py` shims removed) and add a section `### 4. In-Process Cache (`MemoryCache` & `MemorySyncCache`)` documenting that `src/goe/listener/utils/cache.py` provides async `MemoryCache` and synchronous `MemorySyncCache` without any Redis/Valkey dependency or `goe.util.redis_tools` shim.
2. In `.agents/bundles/product/product.md:19`, change:
