# Task 1.4: Purge 9 unimported dead modules

## Objective

Delete nine modules that have no runtime importer (and the tests that only exercise them), and repoint `tests/unit/util/test_json_tools.py` at the canonical `goe.util.json_tools` API, so later typing ratchets (PRD 2) do not carry dead code.

## Context

- Baseline commit `46890a8`; no earlier task in this flow edits these files.
- Verified with `git grep -n -E "<module path>|<symbol>" -- src tests tools bin pyproject.toml Makefile .github` at baseline:
  - `goe.conductor` / `HybridViewService`: only importer `tests/conductor/test_hybrid_view_service.py:7`. `HybridViewService.__init__` raises `NotImplementedError` unconditionally (`src/goe/conductor/hybrid_view_service.py:75`). `src/goe/conductor/__init__.py` and `tests/conductor/__init__.py` are empty package markers.
  - `goe.listener.services.hybrid_view`: no importer; `src/goe/listener/services/__init__.py:6-9` exports only `SystemService` and `orchestration_runner`.
  - `goe.util.serialization`: only importer `tests/unit/util/test_json_tools.py:20-28` (plus the docstring/calls in `test_serialization_module_domain_fallback` at 126-141). Its `serialize_object`/`serialize_object_bytes` simply delegate to `goe.util.json_tools`, and its `DEFAULT_TYPE_ENCODERS` is re-exported from `sqlspec.utils.serializers` (`goe.util.json_tools` does **not** export it).
  - `goe.util.env`, `goe.util.text`, `goe.util.uuids`, `goe.util.exception_trigger`, `goe.util.local_cache`, `goe.util.retry_logic`: zero importers.
- `tests/unit/util/test_json_tools.py:9-28` baseline imports:
  ```python
  import numpy as np
  import pytest

  from goe.orchestration.execution_id import ExecutionId
  from goe.util.json_tools import (
      convert_field_to_camel_case,
      deserialize_object,
      encode_datetime_object,
      serialize_object,
      serialize_object_bytes,
  )
  from goe.util.serialization import (
      DEFAULT_TYPE_ENCODERS,
  )
  from goe.util.serialization import (
      serialize_object as serialization_serialize_object,
  )
  from goe.util.serialization import (
      serialize_object_bytes as serialization_serialize_object_bytes,
  )
  ```
- Strategy justification: deleting unreachable modules is a behavior-preserving deletion → `characterization` (green focused baseline before and after).
