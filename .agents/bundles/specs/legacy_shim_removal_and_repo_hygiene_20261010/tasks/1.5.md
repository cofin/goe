# Task 1.5: Port upstream `#275` release-please, migrate dependencies, and modernize the Cloud Run image

## Objective

Bring the fork's release automation in line with upstream `gluent/goe#275` while keeping the fork's `uv build` + PyApp jobs, remove stale/unused dependency declarations, migrate `lark-parser` to `lark>=1.1.9`, replace `termcolor` with the in-repo ANSI helper, re-lock, and make the Cloud Run image use Python 3.12 via `uv`.
