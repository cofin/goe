# Task 1.1: Create `OracleGateway`, Externalize Repository SQL to `oracle_repo.sql`, and Remove Legacy `sqlspec_client` Scaffold

## Objective

Update `pyproject.toml` to use `sqlspec[performance,oracledb,adbc,duckdb]>=0.61.0` (only the `performance` extra group, dropping `mypyc`), create the foundational `OracleGateway` module (`src/goe/persistence/oracle_gateway.py`) wrapping `sqlspec.adapters.oracledb.OracleSyncConfig`, `sqlspec.adapters.oracledb.OracleSyncDriver`, and `sqlspec.loader.SQLFileLoader`, externalize all Oracle repository SQL queries from `src/goe/persistence/oracle/oracle_orchestration_repo_client.py` (`L430-1035`) into `src/goe/persistence/sql/oracle_repo.sql`, and delete any legacy `src/goe/persistence/sqlspec_client.py` or `src/goe/persistence/__pycache__/sqlspec_client*.pyc` scaffold artifacts.

## Context

- `pyproject.toml` (`L35`) should specify `sqlspec[performance,oracledb,adbc,duckdb]>=0.61.0` (using only the `performance` group rather than `mypyc`).
- `src/goe/persistence/oracle/oracle_orchestration_repo_client.py` currently embeds 550+ lines of raw f-string SQL across:
  - `get_offloadable_schemas` (`L430-510`): interpolates `ora_adm_user`, `ora_app_user`, and `ora_repo_user` via f-strings at `L463`.
  - `get_schema_tables` (`L511-876`): interpolates `{self._repo_user}` at `L667, L673, L690, L692, L790` and `{unsupported_column_pattern}` at `L770-771`, with `:schema_name` bind at `L578, L605, L634, L649, L795`.
  - `get_table_columns` (`L878-905`): binds `:schema_name` and `:table_name`.
  - `get_table_partitions` (`L907-923`) and `get_table_subpartitions` (`L925-940`): binds `:schema_name` and `:table_name`.
  - `get_command_step_codes` (`L942-945`): interpolates `{self._repo_user}.command_step`.
  - `get_command_executions` (`L947-973`) and `get_command_execution` (`L975-1001`): interpolates `{self._repo_user}` on `COMMAND_EXECUTION`, `OFFLOAD_CHUNK`, `OFFLOAD_METADATA`, and `BACKEND_TYPE`.
  - `get_command_execution_steps` (`L943-1035`): interpolates `{self._repo_user}` and optionally filters `WHERE CE.UUID = :execution_id`.
- `OracleOrchestrationRepoClient` also executes PL/SQL procedures (`offload_repo.delete_offload_metadata`, `save_offload_metadata`, `start_command_execution`, `end_command_execution`, `start_command_execution_step`, `end_command_execution_step`, `start_offload_chunk`, `end_offload_chunk`) and PL/SQL functions returning `oracledb.DB_TYPE_OBJECT` (`offload_repo.get_offload_metadata`) as well as `conn.gettype(...)` for `OFFLOAD_METADATA_OBJ` and `OFFLOAD_PARTITION_LIST_IOT` (`L94-425`).
- SQLSpec's `ParameterValidator` rejects mixed positional and named bind styles. All SQLSpec Oracle queries must use `:param_name` named binds passed as a `dict[str, Any]`.

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

from unittest.mock import MagicMock

import msgspec
import pytest

from goe.persistence.oracle_gateway import (
    OracleGateway,
    get_oracle_repo_sql_loader,
    validate_oracle_identifier,
)


class SampleRow(msgspec.Struct, kw_only=True):
    code: str
    count_val: int = 0


def test_oracle_repo_sql_loader_loads_all_named_queries() -> None:
    """Verify all repository SQL statements are loaded by SQLFileLoader."""
    loader = get_oracle_repo_sql_loader()
    expected = {
        "get_offloadable_schemas",
        "get_schema_tables",
        "get_table_columns",
        "get_table_partitions",
        "get_table_subpartitions",
        "get_command_step_codes",
        "get_command_executions",
        "get_command_execution",
        "get_command_execution_steps_all",
        "get_command_execution_steps_by_id",
    }
    assert expected.issubset(set(loader.list_queries()))


def test_validate_oracle_identifier_enforces_strict_pattern() -> None:
    """Verify identifier validation accepts valid Oracle identifiers and rejects injection."""
    assert validate_oracle_identifier("GOE_REPO") == "GOE_REPO"
    assert validate_oracle_identifier("c##goe$adm_1") == "C##GOE$ADM_1"
    with pytest.raises(ValueError, match="Invalid Oracle identifier"):
        validate_oracle_identifier("GOE_REPO; DROP TABLE dual")


def test_gateway_render_sql_substitutes_repo_user_and_preserves_binds() -> None:
    """Verify get_statement replaces {repo_user} safely while keeping :execution_id bind."""
    gateway = OracleGateway(repo_user="goe_repo")
    sql_obj = gateway.get_statement("get_command_execution", params={"execution_id": b"1234"})
    assert "GOE_REPO.COMMAND_EXECUTION" in sql_obj.raw_sql
    assert ":execution_id" in sql_obj.raw_sql


def test_gateway_select_structs_hydrates_msgspec_models() -> None:
    """Verify select_structs maps uppercase Oracle columns into msgspec.Struct fields."""
    mock_conn = MagicMock()
    mock_cursor = MagicMock()
    mock_cursor.description = [("CODE", None, None, None, None, None, None), ("COUNT_VAL", None, None, None, None, None, None)]
    mock_cursor.fetchall.return_value = [("STEP_A", 3), ("STEP_B", 7)]
    mock_conn.cursor.return_value.__enter__.return_value = mock_cursor
    mock_conn.cursor.return_value = mock_cursor

    gateway = OracleGateway(repo_user="GOE_REPO", connection_factory=lambda: mock_conn)
    rows = gateway.select_structs(
        "get_command_step_codes",
        schema_type=SampleRow,
    )
    assert len(rows) == 2
    assert rows[0] == SampleRow(code="STEP_A", count_val=3)
    assert rows[1] == SampleRow(code="STEP_B", count_val=7)


def test_gateway_call_plsql_with_out_var() -> None:
    """Verify call_plsql_proc_with_int_out creates an integer OUT bind and returns its scalar value."""
    mock_conn = MagicMock()
    mock_cursor = MagicMock()
    mock_var = MagicMock()
    mock_var.getvalue.return_value = 42
    mock_cursor.var.return_value = mock_var
    mock_conn.cursor.return_value = mock_cursor

    gateway = OracleGateway(repo_user="GOE_REPO", connection_factory=lambda: mock_conn)
    result = gateway.call_plsql_proc_with_int_out(
        "offload_repo.start_command_execution",
        out_index=0,
        params=[None, b"uuid-bytes", "OFFLOAD", "{}"],
        commit=True,
    )
    assert result == 42
    mock_cursor.callproc.assert_called_once()
    mock_conn.commit.assert_called_once()
```

### Step 4: Implement `src/goe/persistence/oracle_gateway.py`

Create `src/goe/persistence/oracle_gateway.py` implementing:
- `validate_oracle_identifier(identifier: str) -> str`: validates `^[A-Za-z][A-Za-z0-9_$#]*$` (after stripping optional surrounding double quotes) and returns uppercase identifier.
