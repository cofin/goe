# Task 1.2: Move `OracleFrontendApi` Dictionary SQL to `frontend_metadata.sql`, Add a Validated Connection, Share `OracleQuery` Row Projection

## Objective

1. Move the 16 static data-dictionary statements in `src/goe/offload/oracle/oracle_frontend_api.py` into `src/goe/offload/oracle/sql/frontend_metadata.sql` and execute them through `OracleGateway`; delete the inline literals. Public and private method results stay identical.
2. Add `OracleFrontendApi.get_validated_oracle_connection()` (the gateway's connection provider) so gateway queries keep `_open_cursor`'s `TRACEFILE_IDENTIFIER` tagging and sniped-session reconnect.
3. Rewrite `_open_cursor` so reconnection runs after the `except` block (same error substrings, same single retry), removing exception chaining on a failed reconnect.
4. Replace the duplicated row-zip loop in `OracleQuery.fetch` with `goe.persistence.oracle_gateway.rows_as_dicts`, keeping upper-case keys.

SELECT column_name
FROM  (
       SELECT column_name
       ,      column_id
       ,      MAX(column_id) OVER () AS last_column_id
       ,      ROW_NUMBER() OVER (ORDER BY num_distinct DESC) AS ndv_rank
       FROM   all_tab_cols
       WHERE  owner = :owner
       AND    table_name = :table_name

,      column_id
,      nullable
,      data_type
,      data_precision
,      data_scale
,      data_length     AS byte_length
,      data_default
,      hidden_column
,      char_used
,      char_length

WHERE  owner = :owner
AND    table_name = :table_name
AND    hidden_column = 'NO'

SELECT current_scn FROM v$database;

-- name: get_db_unique_name

```python
    def _open_cursor(self) -> None:
        """Open a fresh cursor, reconnecting once when the session was sniped or the connection was lost.

        The ``ALTER SESSION SET TRACEFILE_IDENTIFIER`` execute is what surfaces a dead session; taking a cursor is
        not enough. Errors are matched by substring because python-oracledb reports padded (``ORA-02396``) and
        unpadded (``DPI-1080: connection was closed by ORA-2396``) codes: ORA-02396 idle-time sniping, ORA-03113
        end-of-file, ORA-03114 not connected, ORA-03135 lost contact. Reconnection runs after the ``except`` block,
        once, so a failed reconnect is not chained to the original error.
        """

        def setup_cursor() -> None:
            self._db_curs = self._db_conn.cursor()
            self._db_curs.execute('ALTER SESSION SET TRACEFILE_IDENTIFIER="%s"' % FRONTEND_TRACE_ID)

        if not self._db_conn:
            self._db_curs = None
            return
        reconnect_reason = None
        try:
            setup_cursor()
        except cxo.DatabaseError as exc:
            if not any(marker in str(exc) for marker in RECONNECT_ERROR_MARKERS):
                raise
            reconnect_reason = str(exc)
        if reconnect_reason is not None:
            self._log(f"Reconnecting to Oracle due to: {reconnect_reason}", detail=VVERBOSE)
            logger.info(f"Reconnecting to Oracle due to: {reconnect_reason}")
            self._disconnect(force=True)
            self._connect()
            setup_cursor()
```
