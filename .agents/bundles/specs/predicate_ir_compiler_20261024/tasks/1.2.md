# Task 1.2: Build multi-dialect PredicateCompiler and render_predicate with NamespacedCache memoization

## Objective

1. Create `src/goe/offload/predicates/compiler.py` implementing `PredicateCompiler.to_sqlglot(expr, dialect)` and `render_predicate(expr, dialect, bind_style=None)` supporting `oracle`, `bigquery`, `snowflake`, `tsql`, `hive`, `spark`, and `duckdb`.
2. Emit dialect-accurate literal SQL (`bind_style=None`) and parameterized `RenderedSQL` (`bind_style="named_colon" | "named_at" | "qmark" | "pyformat" | "auto"`) preserving exact 38-digit `Decimal` values and nanosecond timestamps.
3. Memoize compiled predicate outputs in `sqlspec.core.NamespacedCache` (or bounded LRU keyed by `(expr, dialect, bind_style)`).
4. Write unit tests in `tests/unit/offload/predicates/test_compiler.py` covering all 7 dialects in both literal and bind modes.

## Context

- Current dialect rendering is split across `_TypedPredicateToAst` (`src/goe/offload/predicate_offload.py:707-830`, which only handles `oracle` and `bigquery` timestamps and raises `PredicateOffloadException` for other dialects), `snowflake_predicate.py`, `synapse_predicate.py`, `hadoop_predicate.py`, and `spark_thrift_predicate.py`.
- Dialect formatting rules required for parity across GOE frontends and backends:
  - `oracle`: double-quoted identifiers (`"ALIAS"."COL"` or `"COL"`); `DATE` literal `TO_DATE('YYYY-MM-DD HH24:MI:SS', 'YYYY-MM-DD HH24:MI:SS')` (or `TO_DATE(:bind_0, 'YYYY-MM-DD HH24:MI:SS')` in bind mode); `TIMESTAMP` / `TIMESTAMP WITH TIME ZONE` literal `TIMESTAMP 'YYYY-MM-DD HH24:MI:SS.FF9'` (or `TO_TIMESTAMP(:bind_0, 'YYYY-MM-DD HH24:MI:SS.FF9')` in bind mode); bind placeholders `:bind_0`, `:bind_1`.
  - `bigquery`: backtick-quoted identifiers (`` `COL` ``); `DATE` literal `DATE 'YYYY-MM-DD'`; `DATETIME` literal `DATETIME 'YYYY-MM-DD HH:MM:SS[.ffffff]'`; `TIMESTAMP` literal `TIMESTAMP 'YYYY-MM-DD HH:MM:SS[.ffffff]+00:00'`; `NUMERIC` / `BIGNUMERIC` literals via `NUMERIC '...'` / `BIGNUMERIC '...'` when decimal scale is present; bind placeholders `@bind_0`, `@bind_1`.
  - `snowflake`: double-quoted identifiers (`"COL"`); `DATE` literal `TO_DATE('YYYY-MM-DD')`; `TIMESTAMP_NTZ` / `TIMESTAMP` literal `TO_TIMESTAMP_NTZ('YYYY-MM-DD HH24:MI:SS.FF9')`; bind placeholders `%(bind_0)s` or `:bind_0`.
  - `tsql` (MSSQL / Synapse): bracketed identifiers (`[COL]` or unquoted per caller option, default quoted `[COL]`); `DATE` literal `CAST('YYYY-MM-DD' AS DATE)`; `DATETIME2` literal `CAST('YYYY-MM-DD HH:MM:SS.fffffff' AS DATETIME2(7))` (truncating 9-digit nanoseconds to 7 digits for T-SQL `DATETIME2(7)`); bind placeholders `?` or `:bind_0`.
  - `hive` / `spark`: backtick-quoted identifiers (`` `COL` ``); `DATE` literal ` CAST('YYYY-MM-DD' AS DATE)` or `'YYYY-MM-DD'`; `TIMESTAMP` literal `TIMESTAMP 'YYYY-MM-DD HH:MM:SS.fffffffff'`.
  - `duckdb`: double-quoted identifiers (`"COL"`); `DATE 'YYYY-MM-DD'`, `TIMESTAMP 'YYYY-MM-DD HH:MM:SS.ffffff'`, `::DECIMAL(38, s)`; bind placeholders `$bind_0` or `?`.
