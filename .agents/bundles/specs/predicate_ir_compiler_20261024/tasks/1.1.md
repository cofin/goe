# Task 1.1: Build immutable PredicateExpr AST and sqlglot-backed predicate DSL parser

## Objective

1. Create `src/goe/offload/predicates/ast.py` defining `PredicateExpr` as a `msgspec` tagged union of `FrozenBaseStruct` nodes (`LogicalAnd`, `LogicalOr`, `LogicalNot`, `BinaryComparison`, `InListPredicate`, `NullCheckPredicate`, `ColumnRef`, `LiteralValue` with `TypedValue` supporting `int`, `float`, `Decimal`, `str`, `bytes`, `date`, `datetime`, and `np.datetime64`).
2. Create `src/goe/offload/predicates/parser.py` implementing `@lru_cache(maxsize=2048)` `parse_predicate_dsl(dsl_str)`, `resolve_predicate_types(expr, columns, include_synthetic=True)`, and `parse_safe_sql_predicate(sql_where, dialect)` using `sqlglot` with zero `lark` or `languard` dependency.
3. Preserve exact 38-to-76-digit `Decimal` values (`Decimal(text)` without `float()` conversion) and 9-digit nanosecond `np.datetime64` values during parsing and DSL formatting.
4. Write unit tests in `tests/unit/offload/predicates/test_parser.py` covering DSL parsing, exact decimal and nanosecond preservation, column resolution, synthetic partition injection, and `OptionValueError` error diagnostics.

## Context

- `src/goe/offload/predicate_offload.py:320-321` currently parses decimals via `float(value)` in `RawToInternalAST.decimal_value`, corrupting high-precision `NUMBER(38)` / `BIGNUMERIC` literals such as `numeric(123456789012345678901234567890.12345678)`.
- `src/goe/offload/predicate_offload.py:576-641` defines the offload predicate DSL grammar:
  - Columns: `column(COL)` or `column(ALIAS.COL)` (case-insensitive, normalized to uppercase).
  - Values: `numeric(<signed_int_or_decimal>)`, `string("<escaped_double_quoted_string>")`, `datetime(YYYY-MM-DD[ HH:MM:SS[.f1..9]])`, `literal("<raw_sql_expr>")`.
  - Comparisons: `=`, `!=`, `<`, `<=`, `>`, `>=` (either `column op value` or `value op column`), `column IN (v1, v2, ...)`, `column NOT IN (v1, v2, ...)`, `column IS NULL`, `column IS NOT NULL`, and parenthesized `AND` / `OR` / `NOT` groups.
- `src/goe/offload/predicate_offload.py:324-406` (`GenericPredicateToTyped`) validates each referenced column against `Sequence[ColumnMetadataInterface]`:
  - Unknown column -> `OptionValueError(f"Unable to resolve column '{col_name}' in offload predicate")`.
  - `not col.valid_for_offload_predicate()` -> `OptionValueError(f"Data type is not supported for offload predicate: {col.data_type}")`.
  - Incompatible value kind vs column category (`is_number_based()`, `is_date_based()`, `is_string_based()`) -> `OptionValueError(f"Columns of data type {col.data_type} cannot be compared to {kind_name} values")`.
- `src/goe/offload/predicate_offload.py:517-575` (`InsertSyntheticPartitionClauses`) checks `get_partition_columns(table_columns)` and `match_partition_column_by_source(column_name, partition_columns)`; when `is_synthetic_partition_column(synthetic_part_col)` is true on a binary comparison, it wraps the comparison in `LogicalAnd((comparison, synthetic_comparison))` using `SyntheticPartitionLiteral.gen_synthetic_literal(synthetic_part_col, table_columns, value_obj)`.

  ```python
  # SPDX-FileCopyrightText: 2026 The GOE Authors
  # SPDX-License-Identifier: Apache-2.0

  """Immutable intermediate representation AST for GOE offload predicates."""

  from datetime import date, datetime
  from decimal import Decimal
  from typing import Literal

  import numpy as np

  from goe.typing import FrozenBaseStruct

  __all__ = (
      "BinaryComparison",
      "ColumnRef",
      "ComparisonOp",
      "InListPredicate",
      "LiteralKind",
      "LiteralValue",
      "LogicalAnd",
      "LogicalNot",
      "LogicalOr",
      "NullCheckPredicate",
      "PredicateExpr",
      "TypedValue",
      "alias_column_names",
      "column_names",
      "rename_column",
      "to_dsl",
      "with_column_alias",
  )

  type ComparisonOp = Literal["=", "!=", "<", "<=", ">", ">="]
  type LiteralKind = Literal["integer", "decimal", "string", "bytes", "date", "datetime", "raw_sql"]
  type ScalarValue = int | float | Decimal | str | bytes | date | datetime | np.datetime64


  class ColumnRef(FrozenBaseStruct, tag="col"):
      """Column reference with optional table alias normalized to uppercase."""

      name: str
      alias: str | None = None


  class TypedValue(FrozenBaseStruct, tag="val"):
      """Typed literal value preserving exact Decimal digits and nanosecond timestamps."""

      kind: LiteralKind
      text: str

      @property
      def raw(self) -> ScalarValue:
          """Return the typed Python or NumPy value for bind parameters and synthetic literals."""
          if self.kind == "integer":
              return int(self.text)
          if self.kind == "decimal":
              return Decimal(self.text)
          if self.kind == "bytes":
              return bytes.fromhex(self.text)
          if self.kind == "date":
              return np.datetime64(self.text, "D")
          if self.kind == "datetime":
              return np.datetime64(self.text.replace(" ", "T"))
          return self.text


  class LiteralValue(FrozenBaseStruct, tag="lit"):
      """Literal AST node paired with an optional resolved database column data type."""

      value: TypedValue
      data_type: str | None = None


  class BinaryComparison(FrozenBaseStruct, tag="cmp"):
      """Binary comparison between a column reference and a literal value."""

      op: ComparisonOp
      column: ColumnRef
      literal: LiteralValue
      lhs_is_column: bool = True


  class InListPredicate(FrozenBaseStruct, tag="in"):
      """IN or NOT IN membership predicate over a tuple of literal values."""

      column: ColumnRef
      values: tuple[LiteralValue, ...]
      negated: bool = False


  class NullCheckPredicate(FrozenBaseStruct, tag="null"):
      """IS NULL or IS NOT NULL predicate."""

      column: ColumnRef
      is_not_null: bool = False


  class LogicalAnd(FrozenBaseStruct, tag="and"):
      """Conjunction over two or more child predicate expressions."""

      children: tuple["PredicateExpr", ...]


  class LogicalOr(FrozenBaseStruct, tag="or"):
      """Disjunction over two or more child predicate expressions."""

      children: tuple["PredicateExpr", ...]


  class LogicalNot(FrozenBaseStruct, tag="not"):
      """Logical negation of a child predicate expression."""

      child: "PredicateExpr"


  type PredicateExpr = (
      BinaryComparison
      | InListPredicate
      | NullCheckPredicate
      | LogicalAnd
      | LogicalOr
      | LogicalNot
  )
  ```
