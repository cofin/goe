# Task 1.3: Implement `ValidationSqlEngine` and Modernize `CrossDbValidator` in `offload_validation.py`

## Objective

1. Implement `ValidationSqlEngine(ValidationQueryEngineProtocol)` and `get_validation_query_engine(dialect: str = "oracle") -> ValidationQueryEngineProtocol` so validation query construction and `--filters` validation sit behind `ValidationQueryEngineProtocol` (`src/goe/offload/sql_engine.py`).
2. Refactor `CrossDbValidator` in `src/goe/offload/offload_validation.py` (`L397-504`) to:
   - Validate user-supplied string `--filters` in `_adjust_filters_front` (`L473-486`) and `_adjust_filters_back` (`L488-504`) via `get_validation_query_engine(dialect).validate_filter_clause(...)`, eliminating raw SQL injection / subquery splicing via `--filters`.
   - Build the validation aggregate `SELECT ... FROM ... WHERE ... GROUP BY ... ORDER BY ...` query in `_construct_simple_agg_sql` (`L397-444`) via `get_validation_query_engine(dialect).build_aggregate_query(ValidationQuerySpec(...))` and **delete the legacy raw string-splicing SQL assembly**.
   - Preserve Oracle `/*+ PARALLEL(...) */` hints, `AS OF SCN <scn>` flashback clauses, and exact output column aliases (`CNT`, `<GROUP_COL>`, `<COL>_<AGG>`) expected by `_compare_results` (`L530-651`).

## Context

- In `src/goe/offload/offload_validation.py`:
  - `_construct_simple_agg_sql` (`L397-444`) currently splices `select_list`, `where_clause` (`" AND ".join("(%s)" % f for f in filters)`), `group_by`, and `order_by` via string formatting (`L415-443`).
  - `_adjust_filters_front` (`L473-486`) and `_adjust_filters_back` (`L488-504`) convert `GenericPredicate` instances via `predicate_offload.predicate_to_where_clause(...)`, but pass raw string elements in `filters` directly through into the `WHERE` clause without validation (`L446-471`).
  - `_compare_results` (`L530-651`) unpacks result rows positionally and by alias (`CNT`, group columns, `COL_MIN`, `COL_MAX`, etc.). Inside `ValidationSqlEngine`, never run `sqlglot.optimizer.qualify` or `optimize` because `qualify` rewrites aliases to `_col_1` (`research/sql_generation_and_dialects.md` §3.6 & R5).

3. `engine.build_aggregate_query(ValidationQuerySpec(...))` simplifies redundant `1 = 1` conjuncts, parenthesizes multi-clause filters cleanly, and preserves `/*+ PARALLEL(t, 4) */` hints, `AS OF SCN 123456` flashback clauses, `GROUP BY`, `ORDER BY`, and exact aggregate alias names (`CNT`, `"ID_MIN"`, `` `ID_MAX` ``).
4. `CrossDbValidator` accepts a custom `ValidationQueryEngineProtocol` instance without depending directly on `sqlglot`.

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

import pytest

from goe.offload.offload_validation import (
    OffloadValidationException,
    combine_validation_filters,
    get_validation_query_engine,
    validate_raw_filter_clause,
)
from goe.offload.predicate_offload import PredicateOffloadException
from goe.offload.sql_engine import ValidationQueryEngineProtocol, ValidationQuerySpec


def test_validation_query_engine_satisfies_protocol() -> None:
    """Verify get_validation_query_engine returns a ValidationQueryEngineProtocol instance."""
    engine = get_validation_query_engine("bigquery")
    assert isinstance(engine, ValidationQueryEngineProtocol)


def test_validate_raw_filter_clause_accepts_valid_conditions() -> None:
    """Verify safe SQL filter strings pass AST allowlist validation."""
    cleaned = validate_raw_filter_clause("ID >= 100 AND REGION IN ('US', 'EU')", dialect="oracle")
    assert "100" in cleaned


def test_validate_raw_filter_clause_rejects_subquery_injection() -> None:
    """Verify subquery injection in --filters is rejected."""
    with pytest.raises((OffloadValidationException, PredicateOffloadException)):
        validate_raw_filter_clause("ID = 1 OR (SELECT COUNT(*) FROM user_tables) > 0", dialect="oracle")


def test_build_aggregate_query_preserves_hints_scn_and_aliases() -> None:
    """Verify build_aggregate_query preserves Oracle hints, AS OF SCN, and projection aliases."""
    engine = get_validation_query_engine("oracle")
    spec = ValidationQuerySpec(
        table_identifier='"SH"."SALES"',
        select_items=['COUNT(*) AS CNT', 'MIN("ID") AS "ID_MIN"'],
        where_clauses=["1 = 1", '"ID" > 10', '"REGION" = \'US\''],
        group_by_cols=['"REGION"'],
        order_by_cols=["1"],
        query_hints="/*+ PARALLEL(t, 4) */",
        prior_to_where="AS OF SCN 987654",
        dialect="oracle",
    )
    sql = engine.build_aggregate_query(spec)
    assert "/*+ PARALLEL(t, 4) */" in sql
    assert 'FROM "SH"."SALES" AS OF SCN 987654' in sql
    assert 'WHERE ("ID" > 10) AND ("REGION" = \'US\')' in sql
    assert 'GROUP BY "REGION"' in sql
    assert "ORDER BY 1" in sql


def test_combine_validation_filters_wraps_and_simplifies() -> None:
    """Verify multiple filter clauses are combined into a parenthesized conjunction."""
    where_sql = combine_validation_filters(["ID > 10", "REGION = 'US'"], dialect="bigquery")
    assert where_sql == "(ID > 10) AND (REGION = 'US')"
```
