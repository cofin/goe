# Task 1.3: Add platform process worker and file orchestration locking

## Objective

1. Create `src/goe/platform/worker.py` with `LocalProcessWorker` (using `run_checked_cmd` and `tempfile.SpooledTemporaryFile`), container-aware `CgroupQuota`, and `LameDuckController`.
2. Create `src/goe/platform/locking.py` with `FileOrchestrationLock` (using `filelock.FileLock` in `$OFFLOAD_HOME/run/`), `OrchestrationLockInterface`, `OrchestrationLockTimeout`, `orchestration_lock_for_table`, and `orchestration_lock_from_hybrid_metadata`.
3. Migrate all callers of `goe.orchestration.orchestration_lock` (`execution.py`, `operation.py`, `listener/controllers/orchestration.py`, `schema_sync.py`) to `goe.platform.locking`, and delete `src/goe/orchestration/orchestration_lock.py` and `tests/unit/orchestration/test_orchestration_lock.py` ( as well as `src/goe/util/local_manager.py` and `src/goe/orchestration/factory/orchestration_lock_factory.py` if present).

## Context

- `src/goe/orchestration/orchestration_lock.py:1-115` implements table locking using `filelock.FileLock` with lock files named `orchestration_<owner>_<table>.lock` under `os.path.join(os.environ.get("OFFLOAD_HOME") or "", "run")`.
- Callers of `goe.orchestration.orchestration_lock`:
  - `src/goe/orchestration/execution.py:30`
  - `src/goe/orchestration/operation.py:48`
  - `src/goe/listener/controllers/orchestration.py:21`
  - `src/goe/schema_sync/schema_sync.py:28`
- `LocalProcessWorker` in `src/goe/platform/worker.py` wraps local command execution via `run_checked_cmd` and manages temporary staging buffers via `tempfile.SpooledTemporaryFile(max_size=max_spool_bytes)` so small outputs stay in memory and large outputs spill cleanly to disk.
- `CgroupQuota(FrozenBaseStruct)` in `src/goe/platform/worker.py` reads Linux cgroup v2 (`/sys/fs/cgroup/cpu.max`, `/sys/fs/cgroup/memory.max`) with fallback to `os.cpu_count()` and `os.sysconf` to compute `effective_cpus`, `effective_memory_bytes`, `recommended_duckdb_memory_limit` (75% clamp), and `recommended_workers`.
- `LameDuckController` coordinates graceful drain on `SIGTERM`/`SIGINT` so in-flight offloads finish or release locks cleanly.
