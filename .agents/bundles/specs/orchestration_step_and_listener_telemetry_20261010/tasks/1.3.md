# Task 1.3: Listener `OpenTelemetryPlugin`, `litestar-queues` Worker Context Propagation & MCP Tool Spans

## Objective

Connect the GOE Litestar Listener (`src/goe/listener/`) HTTP controllers, `litestar-queues` background workers (`src/goe/listener/jobs.py`), and MCP server (`src/goe/listener/mcp.py`) into the unified OpenTelemetry trace tree:
1. **Litestar `OpenTelemetryPlugin` (`src/goe/listener/app.py:31-65`)**:
   - Import `OpenTelemetryConfig` and `OpenTelemetryPlugin` from `litestar.plugins.opentelemetry` (never from deprecated `litestar.contrib.opentelemetry`).
   - When `ObservabilityRuntime.settings.enabled` is `True`, attach `OpenTelemetryPlugin(OpenTelemetryConfig(tracer_provider=runtime.tracer_provider, meter_provider=runtime.meter_provider, exclude=["/health", "/api/health"]))` to `plugins` in `create_app()`.
2. **`litestar-queues` Observability & Worker Context Propagation (`src/goe/listener/app.py`, `src/goe/listener/controllers/orchestration.py:110-127`, `src/goe/listener/jobs.py:17-22`)**:
   - Pass `ObservabilityConfig(enable_otel=runtime.settings.enabled, tracer_provider=runtime.tracer_provider, meter_provider=runtime.meter_provider)` to `QueueConfig` in `src/goe/listener/app.py`.
   - In `execute_offload_command` (`src/goe/listener/controllers/orchestration.py:110-127`), inject carrier headers (`_otel_carrier = inject_carrier()`) alongside `params` and bind `execution_id` on the HTTP request span (`goe.execution.id = str(execution_id)`).
   - In `run_offload_job` (`src/goe/listener/jobs.py:17-22`), extract `_otel_carrier` (if present) using `extract_carrier` and `opentelemetry.context.attach`, and invoke `OrchestrationRunner().offload(clean_params, execution_id=ExecutionId.from_str(execution_id))` so the worker's `goe.command.offload` span is a child of the originating HTTP request trace.
3. **MCP Tool Spans (`src/goe/listener/mcp.py`)**:
   - Wrap MCP tool handlers with a `traced_mcp_tool(tool_name)` context manager emitting `goe.mcp.tool.<tool_name>` spans with `goe.mcp.tool_name = tool_name`.

### 3.1 `src/goe/listener/jobs.py` Worker Context Extraction

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

"""Background job handlers with OpenTelemetry context propagation for the GOE Listener."""

from __future__ import annotations

from typing import Any

from opentelemetry import context

from goe.observability.context import bind_execution_context, extract_carrier
from goe.orchestration.execution_id import ExecutionId
from goe.orchestration.orchestration_runner import OrchestrationRunner


async def run_offload_job(
    execution_id: str,
    command_type: str,
    params: dict[str, Any],
    *,
    otel_carrier: dict[str, str] | None = None,
) -> dict[str, Any]:
    """Execute an offload job in the background worker while preserving parent W3C trace context."""
    clean_params = dict(params)
    carrier = otel_carrier or clean_params.pop("_otel_carrier", None)
    parent_ctx = extract_carrier(carrier) if isinstance(carrier, dict) else context.get_current()
    ctx_token = context.attach(parent_ctx)
    exec_id_obj = ExecutionId.from_str(execution_id)
    try:
        with bind_execution_context(execution_id=exec_id_obj, command_type=command_type):
            runner = OrchestrationRunner()
            result = runner.offload(clean_params, execution_id=exec_id_obj)
            return {"execution_id": execution_id, "status": "completed", "result": bool(result)}
    finally:
        context.detach(ctx_token)
```

### 3.2 `src/goe/listener/app.py` `OpenTelemetryPlugin` Registration

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

"""Helper to build Litestar OpenTelemetryPlugin and Queue ObservabilityConfig."""

from __future__ import annotations

from typing import Any

from litestar.plugins.opentelemetry import OpenTelemetryConfig, OpenTelemetryPlugin
from litestar_queues.observability import ObservabilityConfig as QueueObservabilityConfig

from goe.observability.runtime import get_observability_runtime


def build_listener_otel_plugin() -> OpenTelemetryPlugin | None:
    """Return a configured Litestar OpenTelemetryPlugin when telemetry is enabled."""
    runtime = get_observability_runtime()
    if not runtime.settings.enabled:
        return None
    otel_config = OpenTelemetryConfig(
        tracer_provider=runtime.tracer_provider,
        meter_provider=runtime.meter_provider,
        exclude=["/health", "/api/health"],
    )
    return OpenTelemetryPlugin(config=otel_config)


def build_queue_observability_config() -> QueueObservabilityConfig:
    """Return a configured litestar_queues ObservabilityConfig bound to GOE providers."""
    runtime = get_observability_runtime()
    return QueueObservabilityConfig(
        enable_otel=runtime.settings.enabled,
        tracer_provider=runtime.tracer_provider if runtime.settings.enabled else None,
        meter_provider=runtime.meter_provider if runtime.settings.enabled else None,
    )
```
