# Task 1.2: Instrument `OrchestrationRunner` commands and `OffloadMessages` steps

## Objective

1. `OrchestrationRunner.__init__` bootstraps telemetry with `ensure_observability(self._config)` (no-op if the CLI already configured it; configures from env in listener workers).
2. `OrchestrationRunner.offload()` runs `_command_begin` through command completion inside `traced_command(...)`, and `_command_begin` persists `_trace_id`/`_span_id` into the `OFFLOAD_REPO` command parameters when a span is recording.
3. `OffloadMessages.offload_step()` wraps each executed step in `traced_step(...)`, emits `record_skipped_step(...)` for skipped steps, marks swallowed optional-step failures, and persists `_trace_id`/`_span_id` in `end_command_step` step details.
4. `OffloadMessages.warning()` adds a `log.warning` event to the current span.
