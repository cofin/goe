# Task 1.3: DuckDB transport per-batch spans with thread context propagation

## Objective

The PRD 3 DuckDB transport runs one in-process DuckDB `COPY` per batch on a `ThreadPoolExecutor`. `ThreadPoolExecutor` does not copy `contextvars`, so without this task every batch loses its parent span and execution binding. Make each batch a `goe.transport.duckdb.batch` child of the `goe.transport.duckdb` span (created by task 1.2) with `goe.transport.batch.index` and `goe.transport.batch.rows` attributes, by submitting batch work through `submit_with_context`.

## Context

- Depends on task 1.2 (`goe.observability.transport.submit_with_context`, `traced_transport_batch`; `OffloadTransport.get_transport_method()` in `src/goe/offload/transport/base.py`). Baseline commit `46890a8`.
- `src/goe/offload/transport/duckdb_transport.py` does not exist at HEAD; chapter `duckdb_oracle_offload_transport_20261010` task 1.3 creates `class OffloadTransportDuckDB(OffloadTransport)`, sets `self._offload_transport_method = OFFLOAD_TRANSPORT_METHOD_DUCKDB` (`"DUCKDB"`, from `src/goe/offload/transport/duckdb_constants.py`), and defines:
  - `_run_batch(self, batch: int, copy_sql: str, access_token: str, project_id: str | None, run_dir: Path) -> int` (one fresh `duckdb` connection per batch; returns rows written);
  - `_run_batches(self, copy_sqls: list[str]) -> int`, which runs `executor.submit(self._run_batch, batch, sql, access_token, project_id, run_dir)` for each `(batch, sql)` inside `with ThreadPoolExecutor(max_workers=len(copy_sqls)) as executor:` and returns the summed `future.result()` values;
  - `transport()` wrapping the work in `self._messages.offload_step(command_steps.STEP_STAGING_TRANSPORT, step_fn, ...)`.
  Locate the submission site with `grep -n "executor.submit" src/goe/offload/transport/duckdb_transport.py`. If chapter 3.4 renames these methods, apply the same edit to the method that performs one batch and the single `executor.submit(...)` call.
- The DuckDB transport spawns no subprocesses and attaches to Oracle through the DuckDB `oracle` extension, so it does not use `run_os_cmd` or `get_rdbms_session_setup_commands`; its trace coverage is the task 1.2 `goe.chunk`/`goe.transport.duckdb` spans plus these batch spans.
- `submit_with_context(executor, fn, *args)` copies the caller context per submission (a single `Context` cannot be entered by two threads concurrently).
- Verification strategy `behavior_tdd`: red proof is the new test failing because no `goe.transport.duckdb.batch` span exists (`StopIteration`).

```python
"""Behavior tests for DuckDB transport batch spans."""

from collections.abc import Iterator
from pathlib import Path

import pytest

from goe.observability import runtime
from goe.observability.config import ObservabilitySettings
from goe.observability.spans import traced_command
from goe.offload.transport.duckdb_transport import OffloadTransportDuckDB

EXEC_ID = "2f1b7c1e-0000-4000-8000-000000000060"


@pytest.fixture
def memory_runtime() -> Iterator[runtime.ObservabilityRuntime]:
    """Configure an in-memory runtime for one test."""
    active = runtime.configure_observability(ObservabilitySettings(enabled=True, exporter="memory"), set_global=False)
    yield active
    runtime.shutdown_observability()


def test_batches_are_children_of_command(
    memory_runtime: runtime.ObservabilityRuntime, tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    transport = object.__new__(OffloadTransportDuckDB)
    monkeypatch.setenv("ORA_SDTZ", "UTC")
    transport._offload_transport_method = "DUCKDB"
    transport._duckdb_temp_root = str(tmp_path)
    monkeypatch.setattr(transport, "_gcs_access_token", lambda: ("token", "proj"), raising=False)
    monkeypatch.setattr(
        transport, "_run_batch", lambda batch, sql, token, project, run_dir: 5, raising=False
    )
    with traced_command("OFFLOAD", EXEC_ID) as command_op:
        assert transport._run_batches(["COPY 1", "COPY 2"]) == 10
    command_span_id = command_op.span.get_span_context().span_id
    batches = [s for s in memory_runtime.get_finished_spans() if s.name == "goe.transport.duckdb.batch"]
    assert sorted(span.attributes["goe.transport.batch.index"] for span in batches) == [0, 1]
    assert all(span.parent.span_id == command_span_id for span in batches)
    assert all(span.attributes["goe.execution.id"] == EXEC_ID for span in batches)
    assert all(span.attributes["goe.transport.batch.rows"] == 5 for span in batches)
```

```python
        self, batch: int, copy_sql: str, access_token: str, project_id: str | None, run_dir: Path
```
