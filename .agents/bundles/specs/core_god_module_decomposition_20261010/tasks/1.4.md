# Task 1.4: Decompose `offload_transport.py` and `offload_transport_factory.py` into `src/goe/offload/transport/`

## Objective

Move the live content of `src/goe/offload/offload_transport.py` and `src/goe/offload/factory/offload_transport_factory.py` verbatim into `src/goe/offload/transport/` (`constants.py`, `availability.py`, `base.py`, `spark_thrift.py`, `spark_submit.py`, `query_import.py`, `factory.py`), delete the unused module `logger`, and leave both legacy modules as docstring-plus-redundant-alias facades over their observed import surfaces.

## Context

- **Why `characterization`**: behavior-preserving move. Initial evidence: existing transport unit tests plus new selection/validation characterization tests pass before the move.
- **Baseline**: `46890a8`. `src/goe/offload/offload_transport.py` and `tests/unit/offload/test_offload_transport.py` are listed in PRD 1 Chapter 1.2 Task 1.3 (`gcp_adc_credential_unification_20261010:1.3`); locate code by symbol.
- **Where the other transports live**: `OffloadTransportSparkDataprocGcloud`, `OffloadTransportSparkBatchesGcloud` (+ canaries) are in `src/goe/offload/spark/dataproc_offload_transport.py`; `OffloadTransportSparkLivy` (+ canary) in `src/goe/offload/spark/livy_offload_transport.py`; `OffloadTransportStandardSqoop`, `OffloadTransportSqoopByQuery`, `OffloadTransportSqoopCanary` in `src/goe/offload/hadoop/sqoop_offload_transport.py`. Those modules import from `goe.offload.offload_transport` and stay unchanged; their imports keep working through the facade.

- **Dependency direction** (verified with `ast`): `availability` → `constants`; `base` → `constants`; `spark_thrift`, `spark_submit` → `base` (`OffloadTransportSpark`); `query_import` → `base` (`OffloadTransport`, `convert_nans_to_nulls`); `factory` → `availability`, `base`, `constants`, `spark_thrift`, `spark_submit`, `query_import`.
- **Import cycle that must stay broken**: `offload_transport_factory` imports the Dataproc, Livy, and Sqoop classes inside the function body (factory file L42, L56, L94, L111, L125). Those modules import `goe.offload.offload_transport`, and that facade re-exports `choose_offload_transport_method` from `transport/factory.py`, so a module-level import of them in `transport/factory.py` would cycle. Keep those function-scoped imports and state the reason in the function docstring. The imports of `OffloadTransportQueryImport`, `OffloadTransportSparkThrift`, `OffloadTransportSparkSubmit` (factory file L30, L70, L82) become module-level imports from `goe.offload.transport.query_import`, `.spark_thrift`, `.spark_submit`.
- **Downstream contract**: `bigquery_first_backend_modernization_20261010` expects `choose_offload_transport_method` in `src/goe/offload/transport/factory.py` and `OffloadTransportQueryImport` in `src/goe/offload/transport/query_import.py`.
- **`src/goe/offload/transport/__init__.py`** contains only the SPDX header and a docstring; `goe.config.config_validation_functions` imports `goe.offload.offload_transport` very early, so a heavy package `__init__` would widen that import chain.
