# Task 1.3: Build differential parity suite and golden fixtures across all 19 Oracle type families

## Objective

1. Capture committed golden Parquet and Avro parity fixtures in `tests/unit/offload/transport/fixtures/query_import_parity/golden_manifest.json` from the current `ParquetEncoder` (`src/goe/util/parquet_encoder.py`) and `AvroEncoder` (`src/goe/util/avro_encoder.py`) before they are removed in Task 1.4.
2. Create `tests/unit/offload/transport/test_query_import_parity.py` asserting 100% equivalence of staged Parquet and Avro output (column names, physical/logical types, nullability, row counts, canonical per-row values/bytes, `SNAPPY`/`DEFLATE`/`UNCOMPRESSED` compression, `NaN`/`Inf` -> `NULL` scrubbing, and 0-row empty tables) across all 19 Oracle type families.
3. Create `tests/integration/offload/test_query_import_parity_oracle.py` exercising live Oracle extraction (`AS OF SCN`, multibyte UTF-8, >64 KiB `CLOB`/`BLOB`, high-precision `NUMBER`, `TIMESTAMP(9)`, `TIMESTAMP WITH TIME ZONE`, `INTERVAL`) through `OracleArrowStreamExtractor` + `ArrowParquetStagingWriter` / `ArrowAvroStagingWriter` and verifying staged file parity.

## Context

- Master PRD 8 §4 mandates a differential parity harness before deleting `ParquetEncoder` (`src/goe/util/parquet_encoder.py`) and `AvroEncoder` (`src/goe/util/avro_encoder.py`).
- All 19 Oracle type families mapped by `src/goe/offload/oracle/oracle_column.py` must be covered in the deterministic dataset:
  1. `NUMBER(4, 0)` (`GOE_TYPE_INTEGER_2`)
  2. `NUMBER(9, 0)` (`GOE_TYPE_INTEGER_4`)
  3. `NUMBER(18, 0)` (`GOE_TYPE_INTEGER_8`)
  4. `NUMBER(38, 0)` (`GOE_TYPE_INTEGER_38`)
  5. `NUMBER(38, 9)` (bounded decimal `GOE_TYPE_DECIMAL`)
  6. Unbounded `NUMBER` / `FLOAT(126)` (`TO_CHAR(..., 'TM')` 38+ digit decimal string)
  7. `BINARY_FLOAT` (including `-0.0`, `NaN`, `+Inf`, `-Inf`)
  8. `BINARY_DOUBLE` (including `-0.0`, `NaN`, `+Inf`, `-Inf`)
  9. `CHAR(10)` (fixed-width padded UTF-8)
  10. `NCHAR(10)` (fixed-width national character set)
  11. `VARCHAR2(4000)` (multibyte UTF-8 string)
  12. `NVARCHAR2(2000)` (national variable string)
  13. `RAW(2000)` (binary bytes / base64 in Query Import RDBMS projection)
  14. `CLOB` / `NCLOB` / `LONG` (both `< 64 KiB` and `> 64 KiB`, e.g., `96 KiB`)
  15. `BLOB` / `LONG RAW` (both `< 64 KiB` and `> 64 KiB`, e.g., `96 KiB`)
  16. `DATE` (including historical dates and time components)
  17. `TIMESTAMP(6)` and `TIMESTAMP(9)` (nanosecond precision)
  18. `TIMESTAMP(6) WITH TIME ZONE` and `TIMESTAMP(6) WITH LOCAL TIME ZONE`
  19. `INTERVAL YEAR(4) TO MONTH` and `INTERVAL DAY(5) TO SECOND(6)` (plus `ROWID` / `XMLTYPE` string serialization and all-`NULL` row)

## Steps

- [ ] 1. Generate and commit `tests/unit/offload/transport/fixtures/query_import_parity/golden_manifest.json` by running the legacy `ParquetEncoder` and `AvroEncoder` over the 19-type deterministic row matrix (non-null boundary rows, multibyte/large LOB row, `NaN`/`Inf` row with `nan_values_as_null=True` and `False`, all-`NULL` row, and 0-row empty dataset) and recording:
  - Parquet Arrow schema field list (`name`, `type`, `nullable`), compression codec, row count, and canonical JSON row representation.
  - Avro schema dict (`name`, `fields`), codec, row count, and canonical JSON row representation (with binary bytes rendered as lowercase hex).
- [ ] 2. Write `tests/unit/offload/transport/test_query_import_parity.py`:
  - `test_parquet_staging_parity_matches_golden_manifest_across_all_19_oracle_types`: feeds the 19-type dataset through `OracleArrowStreamExtractor` + `ArrowParquetStagingWriter` (with `DuckDBEngine`), reads the written Parquet file back with `pyarrow.parquet.read_table`, and asserts exact equality of column names, Arrow types, nullability, row counts, and canonical row values against `golden_manifest.json` (and against live `ParquetEncoder` if still importable prior to Task 1.4).
  - `test_avro_staging_parity_matches_golden_manifest_across_all_19_oracle_types`: feeds the 19-type dataset through `OracleArrowStreamExtractor` + `ArrowAvroStagingWriter`, reads the written Avro file back with `fastavro.reader`, and asserts exact equality of schema fields, nullability, row counts, and canonical row values against `golden_manifest.json`.
  - `test_parquet_and_avro_empty_table_parity`: verifies 0-row extraction produces schema-identical Parquet and Avro files with `total_rows == 0`.
  - `test_nan_and_inf_scrubbing_parity`: verifies `nan_values_as_null=True` converts `float("nan")`, `float("inf")`, and `float("-inf")` to `None` identically to `ParquetEncoder._convert_nans_to_null`.
- [ ] 3. Write `tests/integration/offload/test_query_import_parity_oracle.py` (marked with `@pytest.mark.integration` so it runs cleanly under `make test-integration-oracle` and skips gracefully when Oracle credentials are absent) comparing staged output on a live Oracle 19-type test table.
- [ ] 4. Run the verification block and confirm all parity tests and static checks pass.
