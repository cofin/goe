# Task 1.4: Replace OffloadTransportQueryImport with Arrow streaming and delete legacy ParquetEncoder and AvroEncoder

## Objective

1. Rewrite `OffloadTransportQueryImport` in `src/goe/offload/transport/query_import.py` to stream Oracle extraction batches through `OracleArrowStreamExtractor` and write staged files via `ArrowParquetStagingWriter` (for `FILE_STORAGE_FORMAT_PARQUET`) or `ArrowAvroStagingWriter` (for `FILE_STORAGE_FORMAT_AVRO`), preserving `--offload-transport-method=QUERY_IMPORT`, its configuration keys, and its staged-file contract.
2. Honor `--offload-transport-parallelism` and `AS OF SCN` consistent reads in `OffloadTransportQueryImport`, fixing the legacy defect where `query_import.py:62, 113-117` hard-locked `parallelism = 1` and logged `"Ignoring --offload-transport-consistent-read for serial transport task"` even when `AS OF SCN` was applied.
3. Update `src/goe/offload/registry.py` to wire staging writer resolution directly to `ArrowParquetStagingWriter` and `ArrowAvroStagingWriter`.
4. Delete the superseded row-by-row modules: `src/goe/util/parquet_encoder.py`, `src/goe/util/avro_encoder.py`, `src/goe/offload/factory/query_import_factory.py`, and `src/goe/offload/query_import_interface.py`.

## Context

- `src/goe/offload/transport/query_import.py:40-177` currently calls `query_import_factory()` (`src/goe/offload/factory/query_import_factory.py:1-58`), which instantiates `QueryImportParquet` or `QueryImportAvro` (`src/goe/offload/query_import_interface.py:1-145`) wrapping `ParquetEncoder` (`src/goe/util/parquet_encoder.py:1-170`) and `AvroEncoder` (`src/goe/util/avro_encoder.py:1-190`).
- Now that Task 1.3 has verified 100% parity between the legacy encoders and `OracleArrowStreamExtractor` + `ArrowParquetStagingWriter` / `ArrowAvroStagingWriter`, the legacy encoders and factory must be deleted in the same cutover commit (Hard Rule 9).

## Steps

- [ ] 1. Write failing behavioral tests in `tests/unit/offload/transport/test_query_import.py`:
  - `test_query_import_transport_streams_parquet_via_arrow_and_duckdb`: verifies `OffloadTransportQueryImport.transport()` extracts via `arrow_batch_extraction`, writes Parquet via `ArrowParquetStagingWriter`, populates `TRANSPORT_CXT_ROWS` and `TRANSPORT_CXT_BYTES`, and invokes `post_transport_tasks`.
  - `test_query_import_transport_streams_avro_via_arrow_and_fastavro`: verifies `OffloadTransportQueryImport.transport()` writes Avro via `ArrowAvroStagingWriter` when `FILE_STORAGE_FORMAT_AVRO` is configured.
  - `test_query_import_transport_honors_parallelism_and_consistent_read_scn`: verifies `OffloadTransportQueryImport` preserves configured `offload_transport_parallelism` and pins extraction queries to `AS OF SCN` without logging the obsolete `"Ignoring --offload-transport-consistent-read"` message.
  - `test_legacy_row_by_row_encoders_are_deleted`: verifies `goe.util.parquet_encoder`, `goe.util.avro_encoder`, `goe.offload.query_import_interface`, and `goe.offload.factory.query_import_factory` are no longer present or imported anywhere under `src/goe/`.
- [ ] 2. Rewrite `src/goe/offload/transport/query_import.py` to use `DuckDBEngine`, `OracleArrowStreamExtractor`, `ArrowParquetStagingWriter`, and `ArrowAvroStagingWriter`:
  - Keep `OFFLOAD_TRANSPORT_METHOD_QUERY_IMPORT`, `query_import_fetch_size()`, and `OffloadTransportQueryImport` class signature unchanged.
  - When `_staging_format == FILE_STORAGE_FORMAT_PARQUET`, open a shared `DuckDBEngine` (`load_oracle=False`), extract each batch split via `self._rdbms_api.arrow_batch_extraction(...)`, and write via `ArrowParquetStagingWriter` before copying local staging files to DFS (or streaming directly when cloud secret is active).
  - When `_staging_format == FILE_STORAGE_FORMAT_AVRO`, extract via `self._rdbms_api.arrow_batch_extraction(...)`, write local Avro via `ArrowAvroStagingWriter`, and copy to DFS via `_query_import_copy_to_dfs`.
- [ ] 3. Update `src/goe/offload/registry.py` to remove any reference to `query_import_factory` and register the Arrow staging writers.
- [ ] 4. Delete `src/goe/util/parquet_encoder.py`, `src/goe/util/avro_encoder.py`, `src/goe/offload/factory/query_import_factory.py`, and `src/goe/offload/query_import_interface.py`.
- [ ] 5. Run the verification block (including `test_query_import_parity.py` from Task 1.3) and confirm all tests and static gates pass.
