# Task 1.2: Migrate Listener App and CLI Launcher from Granian to Vertebra

## Objective

1. Update `src/goe/listener/app.py` and `src/goe/listener/asgi.py` to replace `GranianPlugin` (`litestar-granian`) with `LitestarPlugin` from `vertebra.extensions.litestar` while keeping module-level `goe.listener.asgi:app` construction free of network and disk I/O.
2. Update `src/goe/cli/commands/listener.py` to build and execute the `vtb run goe.listener.asgi:app --interface asgi` command line (or `vertebra.supervisor.Supervisor`), run `DurableJobWorker.run_forever()` directly when `--worker-only` is passed, delete `src/goe/listener/server.py` and `src/goe/listener/__main__.py`, and swap `granian` and `litestar-granian` for `vertebra` in `pyproject.toml`.

## Context

- `src/goe/listener/app.py:16, 45` imports `GranianPlugin` from `litestar_granian`.
- `src/goe/cli/commands/listener.py:21-26, 178-204` lazily imports `Granian` and `Interfaces`, treats `--worker-only` as a no-op (`lines 191-193`), and starts `Granian("goe.listener.asgi:app", ...)`.
- `src/goe/listener/server.py:1-32` and `src/goe/listener/__main__.py:1-23` are legacy Granian entrypoints superseded by `goe listener start`.
- `cofin/vertebra` provides `LitestarPlugin` in `vertebra.extensions.litestar` (`src/py/vertebra/extensions/litestar/plugin.py:32-166`) and the `vtb run` CLI (`[sys.executable, "-m", "vertebra", "run", "goe.listener.asgi:app", "--interface", "asgi", ...]`).
- When `--worker-only` is supplied to `goe listener start`, no HTTP ingress process is started; the CLI initializes the job store and runs `DurableJobWorker.run_forever()` until `SIGINT`/`SIGTERM`.
