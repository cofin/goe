# Task 1.3: Configure Vertebra Runtime Settings and Verify End-to-End Concurrency and Lifespan

## Objective

1. Extend `ListenerSettings(FrozenBaseStruct)` in `src/goe/listener/config/application.py` with Vertebra runtime fields (`topology: Literal["shm", "embedded"] = "shm"`, `threads: int = 1`, `drain_timeout_seconds: int = 30`, `shutdown_timeout_seconds: int = 35`) and `to_vertebra_env(base_env)` preserving existing `VERTEBRA_*` caller environment variables, and document the Listener runtime variables in `templates/conf/offload.env.template.common`.
2. Create the end-to-end ASGI lifespan, CORS `OPTIONS` preflight, `HEAD` probe, SSE/chunked response, and 64-way concurrent request verification suite in `tests/unit/listener/test_vertebra_runtime_integration.py`.

## Context

- `src/goe/listener/config/application.py:19-52` defines `host`, `port`, `http_workers`, `reload`, `shared_token`, `certfile`, `keyfile`, `ssl_enabled`, and `heartbeat_interval`, but lacks Vertebra topology (`OFFLOAD_LISTENER_TOPOLOGY` / `VERTEBRA_TOPOLOGY`), thread count (`OFFLOAD_LISTENER_THREADS` / `VERTEBRA_THREADS`), and graceful drain timeout settings (`OFFLOAD_LISTENER_DRAIN_TIMEOUT`).
- As documented in `.agents/bundles/specs/prd_10_staged_orchestration_durable_jobs_and_vertebra_listener_20261024/research/vertebra-and-runtime-evaluation.md:58-68`, the end-to-end verification suite must prove that `goe.listener.asgi:app` initializes its lifespan state (`ListenerCache`, `JobStore`, `DurableJobWorker`), fails cleanly if a startup hook raises, responds to browser CORS `OPTIONS` preflight (`204`/`200` with `access-control-allow-origin` and `access-control-allow-methods`) and `HEAD /api/system/status/`, streams chunked/SSE responses without truncating payloads, and completes 64 concurrent requests across `/api/system/status/`, `/api/system/config/`, `/api/orchestration/executions/`, and `/mcp` without deadlocking or leaking connections.

## Steps

- [ ] 1. Create `tests/unit/listener/test_vertebra_runtime_integration.py` testing:
  - `ListenerSettings.to_vertebra_env(base_env)` populating `VERTEBRA_HOST`, `VERTEBRA_PORT`, `VERTEBRA_TOPOLOGY`, `VERTEBRA_WORKERS`, `VERTEBRA_THREADS`, `VERTEBRA_DRAIN_TIMEOUT`, and `VERTEBRA_SHUTDOWN_TIMEOUT` while preserving any `VERTEBRA_*` keys already present in `base_env`.
  - End-to-end ASGI lifespan startup and shutdown on `create_app()`: `app.state` contains the initialized `ListenerCache` and `JobStore` during active requests and closes the worker and store cleanly on `lifespan.shutdown`; injecting a failing startup hook causes `lifespan.startup.failed` and refuses traffic.
  - `OPTIONS /api/orchestration/offload/` returning CORS preflight headers (`access-control-allow-origin`, `access-control-allow-methods`, `access-control-allow-headers`) and `HEAD /api/system/status/` returning `200` with an empty body.
  - Streaming/chunked log responses and 64 concurrent requests across `/api/system/status/`, `/api/system/schemas/`, `/api/orchestration/executions/`, and `/mcp` completing within 5 seconds with zero `500` responses or unhandled exceptions.
