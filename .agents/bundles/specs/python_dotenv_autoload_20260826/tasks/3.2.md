# Task 3.2: Author CLI characterization and integration verification for option defaults

## Objective
Author tests in `tests/unit/cli/` verifying that invoking CLI subcommands (`goe offload`, `goe connect`, `goe validate`, `goe sync`) automatically populates option defaults from `offload.env` without requiring external shell variable exports.

## Context
CLI subcommands rely on `orchestration_defaults` to compute default values for CLI flags (such as `--target`, `--force`, `--create-backend-db`). Ensuring that the CLI properly reads defaults from an auto-loaded configuration file guarantees seamless developer and operations UX.

## Steps
1. In `tests/unit/cli/test_offload_command.py` (or `tests/unit/cli/test_cli_root.py`), create characterization tests:
   - Use `CliRunner` from `click.testing` in an isolated environment with a synthesized `offload.env` file.
   - Verify that running `goe offload --help` or invoking `goe offload` accurately captures defaults specified in the configuration file.
   - Verify that CLI arguments passed explicitly on the command line override values in `offload.env`.
2. Ensure test isolation with `tmp_path` and `monkeypatch`.
3. Ensure no inline comments are present in the Python code.

## Verification
- Run `uv run pytest tests/unit/cli/ -v`.
- Run `uv run ruff check tests/unit/cli/`.

## Acceptance Criteria
- [ ] CLI runner tests confirm `offload.env` values are consumed by CLI option parsers.
- [ ] Explicit CLI flags override `offload.env` values as expected.
- [ ] All CLI unit tests pass with zero failures.
