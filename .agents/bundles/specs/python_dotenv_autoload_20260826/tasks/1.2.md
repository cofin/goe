# Task 1.2: Enhance load_env with POSIX variable interpolation and auto OFFLOAD_HOME export

## Objective
Upgrade `load_env()` in [`src/goe/config/config_file.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/config/config_file.py) to enable POSIX variable interpolation (`interpolate=True`), enforce `override=False` precedence, and automatically populate `os.environ["OFFLOAD_HOME"]` when an `offload.env` file located inside a standard `conf/` directory is resolved.

## Context
Configuration templates in `templates/conf/` rely on variable expansion (e.g. `OFFLOAD_TRANSPORT_USER=${USER}`, `ORACLEDB_THICK_MODE=${USE_ORACLE_WALLET}`, `OFFLOAD_TRANSPORT_SPARK_SUBMIT_MASTER_URL="spark://${OFFLOAD_TRANSPORT_CMD_HOST}:7077"`). Furthermore, core GOE components (lock manager, transport listener JAR resolution, log manager) depend on `OFFLOAD_HOME`. By inferring and exporting `OFFLOAD_HOME` when `conf/offload.env` is discovered, the entire framework operates smoothly without manual shell environment configuration.

## Steps
1. In [`src/goe/config/config_file.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/config/config_file.py), update `load_env(path: str | None = None, override: bool = False) -> bool`:
   - Resolve `target_path = path or find_environment_file()`.
   - If `target_path` exists:
     - Invoke `load_dotenv(dotenv_path=target_path, override=override, interpolate=True)`.
     - Inspect `target_path`. If `os.environ.get("OFFLOAD_HOME")` is not set and the parent directory is named `conf`, auto-set `os.environ["OFFLOAD_HOME"] = os.path.dirname(os.path.dirname(os.path.abspath(target_path)))`.
     - Return `True`.
   - Return `False` if no environment file was found or loaded.
2. Ensure `load_env` is idempotent and safe to call multiple times.
3. Validate code with `ruff` and `mypy` ensuring PEP 257 docstrings and zero inline comments.

## Verification
- Run `uv run pytest tests/unit/config/test_config_file.py`.
- Run `uv run ruff check src/goe/config/config_file.py`.

- [x] `load_env()` correctly expands nested variables (`${USER}`, `${USE_ORACLE_WALLET}`) in definition order.
- [x] `load_env()` does not overwrite variables already present in `os.environ` when `override=False`.
- [x] `load_env()` auto-populates `os.environ["OFFLOAD_HOME"]` based on discovered `conf/offload.env` location.
- [x] `load_env()` returns `True` when a file is loaded and `False` when no file is present.
