# Task 2.1: Implement package-level auto-loading hook with test guards in src/goe/__init__.py

## Objective
Add an automatic environment loading hook to [`src/goe/__init__.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/__init__.py) that initializes `offload.env` when `goe` is imported, while protecting isolated unit test runs (`PYTEST_CURRENT_TEST`) and respecting explicit opt-out directives (`GOE_NO_AUTOLOAD_ENV=1`).

## Context
When developers or automated workflows import `goe` submodules or run commands, having environment variables populated automatically upon package entry guarantees that module-level constants and default factories receive valid configuration without requiring explicit bootstrap boilerplate.

## Steps
1. In [`src/goe/__init__.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/__init__.py), define `_autoload_environment() -> None`:
   - Check if `os.environ.get("GOE_NO_AUTOLOAD_ENV")` is set to `"1"` or `"true"`. If so, skip auto-loading.
   - Check if `"PYTEST_CURRENT_TEST"` in `os.environ`. If so, skip auto-loading to preserve mock test environments.
   - Import `load_env` from `goe.config.config_file` and invoke `load_env()`.
2. Call `_autoload_environment()` during package initialization.
3. Ensure no circular imports occur when importing `goe.config.config_file`.
4. Ensure no inline comments are present in the Python code, with any design rationale placed in the docstring.
