# Task 1.1: Implement multi-stage environment file discovery in config_file.py

## Objective
Enhance [`src/goe/config/config_file.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/config/config_file.py) to implement robust multi-stage configuration file discovery (`find_environment_file()` and modernized `get_environment_file_path()`), allowing GOE to find `offload.env` across local repository workspaces, containers, and production VM installations without requiring `$OFFLOAD_HOME` to be pre-exported in the shell.

## Context
Currently, [`get_environment_file_path()`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/config/config_file.py#L32-L36) only returns `os.path.join(offload_home, "conf", "offload.env")` if `OFFLOAD_HOME` is already set in `os.environ`. If `OFFLOAD_HOME` is missing, it returns `None`, breaking commands executed directly from a repository checkout or virtualenv.

## Steps
1. In [`src/goe/config/config_file.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/config/config_file.py), import `find_dotenv` from `dotenv`.
2. Implement `find_environment_file() -> str | None` with the following 4-tier precedence:
   - **Tier 1**: Check `os.environ.get("GOE_CONFIG_FILE")` or `os.environ.get("OFFLOAD_ENV_FILE")`. If the file exists, return the absolute path.
   - **Tier 2**: Check `os.environ.get("OFFLOAD_HOME")`. If set and `os.path.join(offload_home, "conf", CONFIG_FILE_NAME)` exists, return its path.
   - **Tier 3**: Dynamic upward search from current working directory via `find_dotenv(f"conf/{CONFIG_FILE_NAME}")` or `find_dotenv(CONFIG_FILE_NAME)`.
   - **Tier 4**: Check standard system paths: `/opt/goe/offload/conf/offload.env` and `/u01/app/goe/offload/conf/offload.env`.
3. Update `get_environment_file_path() -> str | None` to delegate to `find_environment_file()` for backward compatibility.
4. Ensure all typing uses Python >= 3.10 syntax (`str | None`), functions have PEP 257 Google-style docstrings, and no inline comments are present in Python code.

## Verification
- Run `uv run pytest tests/unit/config/test_config_file.py` to confirm path resolution across mock directory layouts and environment combinations.
- Run `uv run ruff check src/goe/config/config_file.py` and `uv run mypy src/goe/config/config_file.py`.

## Acceptance Criteria
- [x] `find_environment_file()` resolves explicit file paths when `GOE_CONFIG_FILE` or `OFFLOAD_ENV_FILE` is set.
- [x] `find_environment_file()` resolves `$OFFLOAD_HOME/conf/offload.env` when `OFFLOAD_HOME` is set.
- [x] `find_environment_file()` discovers `conf/offload.env` or `offload.env` from nested working directories via `find_dotenv()`.
- [x] `find_environment_file()` returns `None` gracefully when no environment file is found without throwing exceptions.
