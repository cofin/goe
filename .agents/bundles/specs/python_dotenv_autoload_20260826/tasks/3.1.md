# Task 3.1: Author comprehensive unit tests for path discovery tiers, variable expansion, and test isolation

## Objective
Implement a thorough unit test suite in `tests/unit/config/test_config_file.py` validating all 4 discovery tiers, variable interpolation, `override=False` precedence, auto `OFFLOAD_HOME` export, and `PYTEST_CURRENT_TEST` isolation.

## Context
Configuration loading is a fundamental foundation for all GOE components. A robust unit test suite ensures that changes to environment file loading do not break edge cases such as comments, single-quoted JSON parameters, nested variable references, or test environment isolation.

## Steps
1. Create or update `tests/unit/config/test_config_file.py` with the following test cases:
   - `test_find_environment_file_explicit`: Verify `GOE_CONFIG_FILE` and `OFFLOAD_ENV_FILE` take highest precedence.
   - `test_find_environment_file_offload_home`: Verify `$OFFLOAD_HOME/conf/offload.env` is resolved when `OFFLOAD_HOME` is set.
   - `test_find_environment_file_dynamic_search`: Verify dynamic upward search discovers `conf/offload.env` and `offload.env` in parent directories.
   - `test_find_environment_file_not_found`: Verify graceful return of `None` when no configuration file exists.
   - `test_load_env_posix_interpolation`: Verify `${USER}`, `${USE_ORACLE_WALLET}`, and nested variable references expand properly.
   - `test_load_env_json_and_quotes`: Verify JSON strings (`OFFLOAD_TRANSPORT_SPARK_PROPERTIES`) and quoted strings parse intact.
   - `test_load_env_override_precedence`: Verify `load_env(override=False)` preserves existing `os.environ` keys.
   - `test_load_env_auto_export_offload_home`: Verify `os.environ["OFFLOAD_HOME"]` is automatically populated from `conf/offload.env` location.
   - `test_autoload_guard_pytest_isolation`: Verify package auto-loading hook does not pollute environment during pytest execution.
2. Ensure all test functions follow pytest standards, have descriptive docstrings, and use `tmp_path` and `monkeypatch` for isolated environment testing.
3. Ensure no inline comments are present in the Python code.

## Verification
- Run `uv run pytest tests/unit/config/test_config_file.py -v`.
- Run `uv run ruff check tests/unit/config/test_config_file.py`.

## Acceptance Criteria
- [ ] 100% test coverage of all branches in `src/goe/config/config_file.py`.
- [ ] All discovery tiers, interpolation modes, and safety guards pass cleanly.
