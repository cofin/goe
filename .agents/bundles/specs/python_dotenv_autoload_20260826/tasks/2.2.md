# Task 2.2: Wire early environment auto-loading into CLI root and listener startup hooks

## Objective
Ensure that [`src/goe/cli/main.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/cli/main.py), [`src/goe/listener/asgi.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/listener/asgi.py), and [`src/goe/listener/app.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/listener/app.py) load `offload.env` prior to command registration, CLI OptionParser initialization, and Litestar application instantiation.

## Context
When running `goe offload`, `goe sync`, or `goe validate`, Click and OptionParser evaluate option defaults (e.g. `orchestration_defaults.query_engine_default()`) at the time subcommands are invoked. Calling `load_env()` at the very top of `src/goe/cli/main.py` guarantees that all CLI option defaults resolve against active environment variables. Similarly, when the listener is started via Granian or Litestar CLI (`goe listener start` or `granian --interface asgi goe.listener.asgi:app`), early initialization ensures the application configuration binds properly.

## Steps
1. In [`src/goe/cli/main.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/cli/main.py), ensure `load_env()` is invoked prior to importing subcommand definitions.
2. In [`src/goe/listener/asgi.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/listener/asgi.py) and [`src/goe/listener/app.py`](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/src/goe/listener/app.py), ensure `load_env()` is invoked before settings factory initialization (`get_app_settings()`).
