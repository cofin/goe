# Task 1.3: Wire cli/commands/sync.py, cli/commands/report.py, and Listener endpoints to SchemaSyncService and StatusReportService

## Objective

1. Update `src/goe/cli/commands/sync.py` to remove lazy imports of `goe.schema_sync.schema_sync` and delegate schema drift inspection and DDL application to `SchemaSyncService` in `goe.sync.differ`.
2. Update `src/goe/cli/commands/report.py` to remove lazy imports of `goe.offload.offload_status_report` and delegate report generation (including `--demo`, `--output-format`, and `--output-level`) to `StatusReportService` in `goe.report.service`.
3. Update `src/goe/listener/services/system.py` and `src/goe/listener/controllers/system.py` so Listener table status and schema drift preview endpoints delegate to `StatusReportService` and `SchemaSyncService` instead of instantiating unpooled `OffloadSourceTable` objects.

## Context

- `src/goe/cli/commands/sync.py:23-45, 70-100` currently lazy-imports `normalise_schema_sync_options` and `schema_sync` from the deleted `goe.schema_sync.schema_sync` module.
- `src/goe/cli/commands/report.py:16-21, 61-74` currently lazy-imports `offload_status_report_run` from the deleted `goe.offload.offload_status_report` module.
- `src/goe/listener/services/system.py` and `src/goe/listener/controllers/system.py` expose schema/table metadata and status endpoints for the Listener REST API and MCP tools (`get_table_offload_status`, `preview_schema_drift`).
- Task 1.1 created `SchemaSyncService` in `src/goe/sync/differ.py`, and Task 1.2 created `StatusReportService` in `src/goe/report/service.py`.
