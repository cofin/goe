# Task 3.2: Migrate shell scripts, CLI executables, Makefiles, and Dockerfiles

## Objective
Migrate all shell scripts and CLI wrapper scripts in [bin/](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/bin/), helper scripts in [tools/](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/tools/), Makefiles across the repo, and Dockerfiles in [docs/google_cloud_run/](file:///usr/local/google/home/codyfincher/code/gluent/next-goe/docs/google_cloud_run/) to the standardized 2-line `#` SPDX header:
```sh
# SPDX-FileCopyrightText: <year> The GOE Authors
# SPDX-License-Identifier: Apache-2.0
```

## Context
Executable scripts in `bin/` (such as `bin/offload`, `bin/connect`, `bin/listener`, `bin/logmgr`) and `tools/` (such as `tools/goe-listener.sh`, `tools/goe-shell-functions.sh`) contain shebang lines (e.g. `#!/usr/bin/env bash` or `#!/usr/bin/env python3`). The migration must ensure shebangs remain at line 1.

## Steps
1. Execute migration tool for shell/bin/Makefiles/Dockerfiles:
   ```bash
   uv run python tools/migrate_spdx_headers.py --path bin/
   uv run python tools/migrate_spdx_headers.py --path tools/ --ext .sh
   uv run python tools/migrate_spdx_headers.py --path Makefile
   uv run python tools/migrate_spdx_headers.py --path target/Makefile
   uv run python tools/migrate_spdx_headers.py --path tools/transport/Makefile
   uv run python tools/migrate_spdx_headers.py --path docs/google_cloud_run/
   ```
2. Verify all `bin/*` scripts remain executable and shebangs are preserved at line 1.
3. Validate Makefiles run cleanly (`make help` or `make --dry-run`).

## Verification
- `git diff bin/ tools/ Makefile` confirms clean comment replacement.
- Shebangs remain intact at line 1 of executable files.

## Acceptance Criteria
- [ ] All files in `bin/`, `tools/*.sh`, `Makefile`, and `docs/google_cloud_run/` have valid SPDX headers.
- [ ] Executable permissions and shebang lines are strictly preserved.
