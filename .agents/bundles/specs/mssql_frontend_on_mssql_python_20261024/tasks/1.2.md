# Task 1.2: Clean up OffloadTransportMSSQLApi, modernize MSSQLColumn typing, and switch pyproject.toml extras to mssql-python

## Objective

1. Remove dead `sqoop_rdbms_specific_*` methods and unused `include_fixed_sqoop` parameters from `src/goe/offload/microsoft/mssql_offload_transport_rdbms_api.py`.
2. Modernize `src/goe/offload/microsoft/mssql_column.py` with PEP 585/604 type annotations, Google-style docstrings, and zero inline comments.
3. Update `pyproject.toml` so `sql_server` (and `mssql`) optional dependencies specify `"mssql-python"` instead of `"pymssql"`, and update the `all` extra accordingly.
4. Add unit tests in `tests/unit/offload/microsoft/test_mssql_source_table.py` covering `MSSQLSourceTable` canonical type mappings, `MSSQLColumn.from_mssql`, `OffloadTransportMSSQLApi`, and `pyproject.toml` dependency declarations.

## Context

- `src/goe/offload/microsoft/mssql_offload_transport_rdbms_api.py:73-85, 155-177` still defines `sqoop_rdbms_specific_jvm_overrides`, `sqoop_rdbms_specific_jvm_table_options`, `sqoop_rdbms_specific_options`, and `sqoop_rdbms_specific_table_options` after Sqoop removal.
- `src/goe/offload/microsoft/mssql_column.py:39-198` lacks type annotations on `__init__`, `from_mssql`, `format_data_type`, and predicate capability methods.
- `pyproject.toml:86-89, 111` lists `"pymssql"` under `[project.optional-dependencies].sql_server` and `all`.
