# Task 1.4: Move Oracle transport connections onto registry sessions

## Objective

1. `OffloadTransportOracleApi` uses `OracleDatabaseRegistry.for_options(offload_options)` and never opens a standalone connection.
2. `get_id_range` runs in `registry.app_transport_session("GOE", "OffloadTransport")`.
3. The SQL statistics function checks out `registry.app_transport_session(rdbms_module, conn_action or "OffloadTransport")` per call and keeps querying `LOG_SQL_STATS_QUERY_TEXT` with the transport module and action, so `gv$sql` matching is unchanged.
4. `query_import_extraction` runs in `registry.app_transport_session("GOE", "OffloadTransport", isolate_session=True)` so its `ALTER SESSION` commands and output type handler never reach another pool checkout.
5. `_get_fixed_goe_parameters` decides `CELL_OFFLOAD_PROCESSING` from `registry.server_version()` (no throwaway admin connection).
6. `log_ash_usage`, `_get_adm_connection`, `_close_adm_connection`, `_get_app_connection`, `_close_app_connection`, the base-class connection attributes, and `get_rdbms_connection_for_oracle` are deleted.
