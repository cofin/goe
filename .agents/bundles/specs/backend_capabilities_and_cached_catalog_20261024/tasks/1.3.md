# Task 1.3: Slim BackendApiInterface and BackendTableInterface to delegate to capabilities, catalog cache, and backend services

## Objective

1. Refactor `src/goe/offload/backend_api.py` so `UdfParameter` and `UdfDetails` inherit from `FrozenBaseStruct`, `BackendApiInterface` exposes `self.capabilities: BackendCapabilities`, `self.catalog: CachedBackendCatalog`, `self._session_mgr: BackendSessionManager`, and `self._ddl_compiler: BackendDDLCompiler`, delegates capability queries to `self.capabilities`, delegates session/logging/DDL helpers to `self._session_mgr` and `self._ddl_compiler`, and eliminates `str_summary_of_self` imports.
2. Refactor `src/goe/offload/backend_table.py` so `BackendTableInterface` delegates synthetic partition SQL compilation to `self._db_api._ddl_compiler`, delegates cast planning and staged data validation to `StagingLoadService`, delegates subchunk discovery and final/materialized-join insert planning to `FinalTableMerger`, and delegates metadata lookups and write-through invalidation to `self._db_api.catalog`.
3. Extend `tests/unit/offload/test_backend_api.py` and `tests/unit/offload/test_backend_table.py` to verify service delegation, capability resolution, and write-through catalog invalidation across `BackendApiInterface` and `BackendTableInterface`.

    ```python
    class UdfParameter(FrozenBaseStruct):
        """Single parameter name and data type for a backend UDF."""

        name: str | None
        data_type: str

        def __post_init__(self) -> None:
            assert self.data_type


    class UdfDetails(FrozenBaseStruct):
        """Metadata descriptor for a backend user-defined function."""

        db_name: str
        udf_name: str
        return_type: str | None
        parameters: list[UdfParameter] | tuple[UdfParameter, ...] | None

        def __post_init__(self) -> None:
            assert self.db_name
            assert self.udf_name
            if self.return_type:
                assert isinstance(self.return_type, str)
            if self.parameters:
                assert isinstance(self.parameters, (list, tuple))
                assert isinstance(self.parameters[0], UdfParameter)

        def parameter_spec_string(self) -> str:
            """Return the parameters as a comma-separated string for end-user display."""
            return ",".join(
                " ".join([(arg.name or ""), (arg.data_type or "")]) for arg in (self.parameters or ())
            )
    ```
