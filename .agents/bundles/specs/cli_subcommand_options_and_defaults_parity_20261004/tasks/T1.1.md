# Task T1.1: `goe offload` CLI Option Completeness & Option Groups

## 1. Objective & Context

Comparing `src/goe/cli/commands/offload.py` against `src/goe/goe.py:2939-3105` and `src/goe/offload/offload.py:345, 613-640` revealed:
1. `--older-than-days` (`src/goe/cli/commands/offload.py:131-135`) is declared with `type=int`, whereas `src/goe/offload/offload.py:345` calls `check_opt_is_posint("--older-than-days", options.older_than_days)` which expects a `str` (`re.match(r"^\d+$", v)` raises `TypeError` on `int`).
2. `src/goe/cli/commands/offload.py` is missing 12 CLI options from `get_offload_options()` (`src/goe/goe.py:2939-3105`):
   - `--bucket-hash-column` (`"bucket_hash_col"`)
   - `--not-null-propagation` (`"not_null_propagation"`, `hidden=True`)
   - `--hive-column-stats` (`"hive_column_stats"`, `is_flag=True`, `default=None`)
   - `--offload-stats` (`"offload_stats_method"`)
   - `--offload-chunk-impala-insert-hint` (`"impala_insert_hint"`)
   - `--dev-log` (`"dev_log"`, `is_flag=True`, `default=None`, `hidden=True`)
   - `--dev-log-level` (`"dev_log_level"`, `hidden=True`)
   - `--transform-column` (`"column_transformation_list"`, `multiple=True`, `hidden=True`)
   - `--offload-transport-validation-polling-interval` (`"offload_transport_validation_polling_interval"`, `hidden=True`)
   - `--sqoop-additional-options` (`"sqoop_additional_options"`)
   - `--sqoop-mapreduce-map-memory-mb` (`"sqoop_mapreduce_map_memory_mb"`, `type=int`)
   - `--sqoop-mapreduce-map-java-opts` (`"sqoop_mapreduce_map_java_opts"`)
3. `src/goe/cli/commands/offload.py` must also apply `@common_options` and `extract_common_options(ctx, kwargs)` so `-v`, `-q`, `--no-ansi`, and hidden diagnostic flags (`--error-before-step`, `--no-version-check`, etc.) work on both `goe offload ... -v` and `bin/offload ... -v`.

    verify_mode = kwargs.pop("verify", None)
    if no_verify:
        options_dict["verify_row_count"] = False
    elif verify_mode is not None:
        options_dict["verify_row_count"] = verify_mode.lower()

    for k, v in kwargs.items():
        if isinstance(v, tuple):
            if v:
                options_dict[k] = list(v)
        elif v is not None:
            options_dict[k] = v

    options = Values(options_dict)
    offload_by_cli(options)
