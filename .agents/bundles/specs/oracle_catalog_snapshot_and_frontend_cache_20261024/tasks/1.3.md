# Task 1.3: Refactor OracleFrontendApi to delegate catalog reads to OracleCatalogService and FrontendCatalogCache

## Objective

1. Refactor `src/goe/offload/oracle/oracle_frontend_api.py` to delegate catalog and session-context methods (`get_table_snapshot`, `get_session_context`, `get_columns`, `get_partition_column_names`, `get_partition_columns`, `get_subpartition_column_names`, `get_subpartition_columns`, `get_primary_key_column_names`, `get_table_default_parallelism`, `get_table_size`, `table_exists`, `view_exists`, `is_view`, `get_session_user`, `get_db_unique_name`, `max_table_name_length`, `frontend_version`) to `FrontendCatalogCache` and `OracleCatalogService`.
2. Invalidate the `FrontendCatalogCache` entry or schema whenever `OracleFrontendApi._execute_ddl_or_dml` executes DDL statements.
3. Trim `src/goe/offload/oracle/sql/frontend_metadata.sql` to retain only queries not superseded by `oracle_catalog.sql` (`agg_validate_sample_column_names`), and add focused unit tests in `tests/unit/offload/oracle/test_oracle_frontend_api.py`.

## Context

- After Chapter 6.1 Task 1.3, `OracleFrontendApi` holds a leased connection from `OracleDatabaseRegistry` (`self._registry`, `self._db_conn`, `self._lease_role`) and executes statements via `self._run_statement`.
- Currently, calling `table_exists`, `is_view`, `get_columns`, `get_partition_columns`, `get_subpartition_columns`, `get_primary_key_column_names`, `get_table_default_parallelism`, and `get_table_size` on `OracleFrontendApi` triggers 9 separate queries against `frontend_metadata.sql`. Delegating all of them to `self.get_table_snapshot(schema, table_name)` (backed by `FrontendCatalogCache`) resolves all 9 calls from a single cached `OracleTableSnapshot`.
- Similarly, `get_session_user`, `get_db_unique_name`, `max_table_name_length`, and `frontend_version` resolve from `self.get_session_context()` (cached once per DSN pool in `FrontendCatalogCache`).

## Steps

- [ ] 1. Create `tests/unit/offload/oracle/test_oracle_frontend_api.py` testing:
  - `test_catalog_methods_reuse_single_cached_table_snapshot`: attaches a fake registry driver and fresh `FrontendCatalogCache` to `OracleFrontendApi`; calls `table_exists("SH", "SALES")`, `is_view("SH", "SALES")`, `get_columns("SH", "SALES")`, `get_partition_columns("SH", "SALES")`, `get_subpartition_columns("SH", "SALES")`, `get_primary_key_column_names("SH", "SALES")`, `get_table_default_parallelism("SH", "SALES")`, and `get_table_size("SH", "SALES")`; asserts `catalog_service.load_table_snapshot` was called once and all return values match the snapshot.
  - `test_session_context_methods_reuse_cached_session_context`: calls `get_session_user()`, `get_db_unique_name()`, `max_table_name_length()`, and `frontend_version()`; asserts `catalog_service.load_session_context` was called once.
  - `test_execute_ddl_invalidates_cached_snapshot`: populates the cache for `("SH", "SALES")`, runs `execute_ddl("ALTER TABLE SH.SALES ADD (NEW_COL NUMBER)")`, and verifies the cached entry for `("SH", "SALES")` was invalidated.
- [ ] 2. Run `uv run pytest tests/unit/offload/oracle/test_oracle_frontend_api.py -v` and confirm the new `get_table_snapshot` / `get_session_context` methods fail with `AttributeError` before the refactor.
- [ ] 3. Update `src/goe/offload/oracle/oracle_frontend_api.py`:
  - Import `FrontendCatalogCache, get_frontend_catalog_cache` from `goe.offload.frontend_cache` and `ORACLE_CATALOG_SQL_PATH, OracleSessionContext, OracleTableSnapshot, split_high_value_tokens` from `goe.offload.oracle.catalog`.
  - Add `catalog_cache: FrontendCatalogCache | None = None` to `__init__` (defaulting to `get_frontend_catalog_cache()`) and initialize `self._catalog_statements = NamedStatements(ORACLE_CATALOG_SQL_PATH)`.
  - Add public methods `get_session_context(self) -> OracleSessionContext` and `get_table_snapshot(self, schema: str, table_name: str, *, snapshot_scn: int | None = None, force_refresh: bool = False) -> OracleTableSnapshot` that execute through `run_with_session_retry` using `self._registry.driver_for(self._active_connection(), self._lease_role or "adm")` and `self._catalog_cache`.
  - Delegate `get_columns`, `get_partition_column_names`, `get_partition_columns`, `get_subpartition_column_names`, `get_subpartition_columns`, `get_primary_key_column_names`, `get_table_default_parallelism`, `get_table_size`, `table_exists`, `view_exists`, and `is_view` to `self.get_table_snapshot(schema, table_name)`.
  - Delegate `get_session_user`, `get_db_unique_name`, and `max_table_name_length` to `self.get_session_context()`.
  - Delegate `split_partition_high_value_string` to `list(split_high_value_tokens(hv_string))`.
  - In `_execute_ddl_or_dml`, call `self._catalog_cache.clear()` after executing non-dry-run DDL so any altered or newly created hybrid object is refreshed on next access.
- [ ] 4. Update `src/goe/offload/oracle/sql/frontend_metadata.sql` and `tests/unit/offload/test_oracle_frontend_metadata.py` so queries moved to `oracle_catalog.sql` are tested against `OracleCatalogService` / `OracleFrontendApi.get_table_snapshot` without duplicate SQL definitions.
- [ ] 5. Run the verification block.
