# Task 1.3: Delete the Sqoop transport and construct transports through the registry

## Objective

1. Delete `src/goe/offload/hadoop/sqoop_offload_transport.py`, the Sqoop transport constants, availability checks, selection rules, canary checker, base-class branches, facade re-exports, and connect checks.
2. Replace `offload_transport_factory()` with `goe.offload.registry.create_transport` at every call site and delete the facade module `src/goe/offload/factory/offload_transport_factory.py`.
3. Construct staging files and transport RDBMS APIs in `OffloadTransport.__init__` through `create_staging_file` and `create_transport_rdbms_api`, and backend tables in `goe.orchestration.execution` through `create_backend_table`.
4. Refuse MSSQL offloads in `choose_offload_transport_method` with `Unsupported DB type: mssql` because no remaining transport supports MSSQL.
