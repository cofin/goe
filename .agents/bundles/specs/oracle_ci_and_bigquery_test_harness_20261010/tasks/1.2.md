# Task 1.2: Create `sql/oracle/source/bootstrap_ci.sh` and configure Oracle 23ai Free + WIF BigQuery CI jobs

## Objective
Create a non-interactive, idempotent shell script `sql/oracle/source/bootstrap_ci.sh` that installs GOE's Oracle schemas (`GOE_ADM`, `GOE_APP`, `GOE_REPO`), PL/SQL packages (`OFFLOAD`, `OFFLOAD_REPO`), and test schemas (`GOE_TEST`, `SH_TEST`) into an Oracle 23ai Free (`gvenzl/oracle-free:23-slim-faststart`) container (`FREEPDB1`), and wire `integration-oracle` and opt-in keyless WIF `integration-bigquery` jobs into `.github/workflows/test.yaml`, `.github/workflows/ci.yaml`, and `Makefile`.

## Context
- `sql/oracle/source/install_offload.sql` uses interactive SQL*Plus `ACCEPT` prompts and requires build-time placeholders (`VERSION`/`BUILD` in `install_env.sql` and `upgrade_env.sql`, and `'%s-SNAPSHOT'` in `create_offload_package_spec.sql` and `create_offload_repo_package_spec.sql`) to be substituted first.
- `sql/oracle/source/create_offload_Roles_Users.sql` creates `GOE_ADM`, `GOE_APP`, and `GOE_REPO` with `PASSWORD EXPIRE`, which blocks automated Python `oracledb` connections unless reset after installation.
- `.github/workflows/test.yaml:1-72` only runs unit tests (`pytest tests/unit`) and does not run Oracle or BigQuery integration tests.

## Steps

### Step 1: Create `sql/oracle/source/bootstrap_ci.sh`
Create `sql/oracle/source/bootstrap_ci.sh` (`chmod +x`):
```bash
#!/usr/bin/env bash
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "${SCRIPT_DIR}/../../.." && pwd)"

ORACLE_HOST="${ORACLE_HOST:-127.0.0.1}"
ORACLE_PORT="${ORACLE_PORT:-1521}"
ORACLE_PDB="${ORACLE_PDB:-FREEPDB1}"
ORACLE_SYS_PASS="${ORACLE_SYS_PASS:-goe_ci_sys_pass}"
GOE_DB_PASS="${GOE_DB_PASS:-goe_ci_pass}"
GOE_VERSION="${GOE_VERSION:-2.0.0}"
GOE_BUILD="${GOE_BUILD:-ci}"

WORK_SQL_DIR="$(mktemp -d)"
trap 'rm -rf "${WORK_SQL_DIR}"' EXIT

cp -R "${SCRIPT_DIR}/." "${WORK_SQL_DIR}/"

sed -i "s/VERSION/${GOE_VERSION}/g; s/BUILD/${GOE_BUILD}/g" \
  "${WORK_SQL_DIR}/install_env.sql" \
  "${WORK_SQL_DIR}/upgrade_env.sql"

sed -i "s/%s-SNAPSHOT/${GOE_VERSION}-${GOE_BUILD}/g" \
  "${WORK_SQL_DIR}/create_offload_package_spec.sql" \
  "${WORK_SQL_DIR}/create_offload_repo_package_spec.sql"

cd "${WORK_SQL_DIR}"

sqlplus -S "sys/${ORACLE_SYS_PASS}@//${ORACLE_HOST}:${ORACLE_PORT}/${ORACLE_PDB} as sysdba" <<SQL
WHENEVER SQLERROR EXIT SQL.SQLCODE
DEFINE 1 = 'GOE_'
DEFINE 2 = 'USERS'
@install_env.sql
@create_offload_Roles_Users.sql
@create_offload_Schema.sql
@create_offload_package_spec.sql
@create_offload_package_body.sql
@create_offload_repo_Schema.sql
@create_offload_repo_package_spec.sql
@create_offload_repo_package_body.sql
@create_offload_Grants.sql
@create_offload_Synonyms.sql

ALTER USER GOE_ADM IDENTIFIED BY "${GOE_DB_PASS}" ACCOUNT UNLOCK;
ALTER USER GOE_APP IDENTIFIED BY "${GOE_DB_PASS}" ACCOUNT UNLOCK;
ALTER USER GOE_REPO IDENTIFIED BY "${GOE_DB_PASS}" ACCOUNT UNLOCK;

DECLARE
  v_count NUMBER;
BEGIN
  FOR u IN (SELECT column_value AS username FROM TABLE(sys.odcivarchar2list('GOE_TEST', 'SH_TEST'))) LOOP
    SELECT COUNT(*) INTO v_count FROM dba_users WHERE username = u.username;
    IF v_count = 0 THEN
      EXECUTE IMMEDIATE 'CREATE USER ' || u.username || ' IDENTIFIED BY "${GOE_DB_PASS}" DEFAULT TABLESPACE USERS QUOTA UNLIMITED ON USERS';
    ELSE
      EXECUTE IMMEDIATE 'ALTER USER ' || u.username || ' IDENTIFIED BY "${GOE_DB_PASS}" ACCOUNT UNLOCK QUOTA UNLIMITED ON USERS';
    END IF;
    EXECUTE IMMEDIATE 'GRANT CONNECT, RESOURCE, CREATE VIEW, CREATE MATERIALIZED VIEW, FLASHBACK ANY TABLE, SELECT ANY DICTIONARY TO ' || u.username;
    EXECUTE IMMEDIATE 'GRANT SELECT_CATALOG_ROLE TO ' || u.username;
  END LOOP;
END;
/
EXIT
SQL
```

### Step 2: Update `.github/workflows/test.yaml` and `.github/workflows/ci.yaml`
1. In `.github/workflows/test.yaml`, add two jobs alongside the unit test job:
   - `integration-oracle`:
     - Uses `services.oracle` with image `gvenzl/oracle-free:23-slim-faststart`, env `ORACLE_PASSWORD: goe_ci_sys_pass`, port `1521:1521`, and healthcheck `healthcheck.sh`.
     - Installs `sqlplus` (or executes `sqlplus` via `docker exec` into the Oracle service container), runs `sql/oracle/source/bootstrap_ci.sh`, and executes:
       ```bash
       uv run pytest tests/integration/persistence/test_orchestration_metadata.py tests/integration/offload/test_offload_source_table.py
       ```
   - `integration-bigquery`:
     - Guarded by `if: vars.GCP_WIF_PROVIDER != '' && github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository`.
     - Requests `permissions: { contents: read, id-token: write }`.
     - Uses `google-github-actions/auth@v3` with `workload_identity_provider: ${{ vars.GCP_WIF_PROVIDER }}` and `service_account: ${{ vars.GOE_IT_SA }}` (zero static JSON secret keys).
     - Runs `uv run goe connect` followed by `uv run pytest tests/integration -m "oracle or bigquery" -n 2`.
2. Add `gha-creds-*.json` to `.gitignore` to ensure ephemeral WIF credential config files are never committed.
