# Task 1.2: Wave 2 — Live Service, CLI & Orchestration Packages Type Annotations (`cli`, `listener`, `connect`, `schema_sync`, `scripts`, `orchestration`)

## Objective

Eliminate all `mypy` errors and dead helpers across `src/goe/cli/` (14 files), `src/goe/listener/` (23 live files), `src/goe/connect/` (7 files), `src/goe/schema_sync/` (11 files), `src/goe/scripts/` (2 files), and `src/goe/orchestration/` (including submodules created in Chapter 2.2)—covering the three packages (`goe.listener.*`, `goe.connect.*`, `goe.schema_sync.*`) that were previously excluded from type checking via `ignore_errors = true` in `pyproject.toml:317-325`.

## Context

- `pyproject.toml:317-325` currently masks all type errors in `goe.listener.*`, `goe.connect.*`, and `goe.schema_sync.*`:
  - `src/goe/listener/` (23 live files; note that `src/goe/listener/services/hybrid_view.py` and `src/goe/conductor/hybrid_view_service.py` were deleted as dead code in PRD 1 Chapter 1.1): Litestar controllers (`controllers/orchestration.py:1-127`, `controllers/system.py:1-97`), services (`services/orchestrate.py:1-31`, `services/periodic_tasks.py:1-144`, `services/system.py:1-115`), security (`security.py:1-116`), cache (`utils/cache.py:1-350`), jobs (`jobs.py:1-43`), schemas (`schemas.py`).
  - `src/goe/connect/` (7 files): `connect.py`, `connect_backend.py:1-424`, `connect_frontend.py:1-207`, `connect_functions.py:1-101`, `connect_transport.py:1-278`, `connect_constants.py:1-12`.
  - `src/goe/schema_sync/` (11 files): `schema_sync.py`, `schema_sync_analyzer.py:1-602`, `schema_sync_command_file.py:1-75`, `schema_sync_processor.py:1-93`, `schema_sync_step.py:1-76`, `steps/add_backend_column.py:1-90`, `steps/add_oracle_column.py:1-85`, `steps/step_builder.py:1-18`.
- Additionally, `src/goe/cli/` (14 files, including `commands/logmgr.py:1-108` and `commands/offload.py:1-552`), `src/goe/scripts/agg_validate.py`, and `src/goe/orchestration/` (`orchestration_runner.py:1-470`, `orchestration_lock.py:1-151`, `command_steps.py:1-114`, `execution_id.py:1-83`, `cli_entry_points.py:1-65`, plus submodules extracted from `goe.py` in Chapter 2.2) must pass strict `mypy` with all 14 error codes enabled and zero unused helpers.

## Steps

### Step 1: Type-Annotate `src/goe/cli/` and `src/goe/listener/`

1. **`src/goe/cli/` (`_lazy.py`, `common.py`, `config.py`, `console.py`, `main.py`, `commands/*.py`)**:
   - Ensure all lazy-bound symbols in `common.py` and `commands/*.py` (`connect.py`, `listener.py`, `logmgr.py`, `offload.py`, `report.py`, `sync.py`, `validate.py`) are declared under module-level `if TYPE_CHECKING:` so `mypy` resolves every symbol with `name-defined` enabled while keeping runtime imports lazy via `bind_lazy_imports(__name__, _LAZY_IMPORTS)`.
2. **`src/goe/listener/`**:
   - Resolve all `attr-defined`, `arg-type`, `return-value`, and `assignment` errors in `services/orchestrate.py:1-31`, `services/periodic_tasks.py:1-144`, `services/system.py:1-115`, `controllers/orchestration.py:1-127`, `controllers/system.py:1-97`, `security.py:1-116`, and `utils/cache.py:1-350`.
   - Ensure `OrchestrationConfig.as_defaults({})` and `ConnectOptions` / `OffloadOperationOptions` interactions in `listener/services/*` and `listener/utils/*` are strictly typed, and remove any dead imports or unused variables left over from `hybrid_view` removal.

### Step 2: Type-Annotate `src/goe/connect/`, `src/goe/schema_sync/`, `src/goe/scripts/`, and `src/goe/orchestration/`

1. **`src/goe/connect/` (`connect.py`, `connect_backend.py`, `connect_frontend.py`, `connect_functions.py`, `connect_transport.py`)**:
   - Type all test runner functions using `ConnectOptions` (from Chapter 2.1), `OrchestrationConfig`, and `OffloadMessages`.
2. **`src/goe/schema_sync/` (`schema_sync.py`, `schema_sync_analyzer.py`, `schema_sync_command_file.py`, `schema_sync_processor.py`, `schema_sync_step.py`, `steps/*.py`)**:
   - Annotate `SchemaSyncStep` (`schema_sync_step.py:17-76`) and its concrete subclasses `AddBackendColumn` (`steps/add_backend_column.py:1-90`) and `AddOracleColumn` (`steps/add_oracle_column.py:1-85`) using `SchemaSyncOptions`, `OffloadMessages`, and `ColumnMetadataInterface`.
3. **`src/goe/scripts/agg_validate.py` and `src/goe/orchestration/*.py`**:
   - Annotate `post_process_args`, `run_agg_validate`, `OrchestrationRunner` (`orchestration_runner.py:1-470`), `OrchestrationLock` (`orchestration_lock.py:1-151`), `ExecutionId` (`execution_id.py:1-83`), `command_steps.py:1-114`, and the `src/goe/orchestration/` modules decomposed in Chapter 2.2.
