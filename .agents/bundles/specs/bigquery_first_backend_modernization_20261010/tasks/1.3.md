# Task 1.3: Add `query_and_wait`, job labels, dataset CMEK defaults, and `GOEGcs` `transfer_manager` / bulk delete

## Objective

Modernize `BackendBigQueryApi` to use `client.query_and_wait()` for non-profiled SELECT/metadata queries, attach sanitized job attribution labels (`goe_command`, `goe_execution_id`, `goe_version`), pass `ClientInfo(user_agent=...)` and optional `BIGQUERY_BILLING_PROJECT`, set `default_kms_key_name` and optional load-dataset `default_table_expiration_ms` in `create_database`, and modernize `GOEGcs` to eliminate TOCTOU `exists()` checks (`if_generation_match=0`) and replace single-blob delete + polling loops with `bucket.delete_blobs(...)` and `transfer_manager` (deleting the replaced sequential single-blob delete and post-delete `exists()` polling loops outright).

## Context

1. **`query_and_wait` & Job Attribution (`src/goe/offload/bigquery/bigquery_backend_api.py:282-287`, `L332-350`, `L392-415`, `L441-446`):**
   - `_execute_query_fetch_x` (`L392-415`) currently calls `self._client.query(sql, job_config=job_config)` followed by `query_job.result()` and a redundant `if query_job.state != "DONE":` check (`L399`) for every query, including fast catalog lookups (`SESSION_USER()`, `INFORMATION_SCHEMA`).
   - When `profile=False` (the default for metadata and non-profiled SELECT queries), `self._client.query_and_wait(sql, job_config=job_config)` uses the `jobs.query` fast path in `google-cloud-bigquery >= 3.15` (locked at `3.44.0`). When `profile=True`, `self._client.query(...)` is retained so `query_job.job_id`, `slot_millis`, and encryption verification (`_check_bqm_job_encryption`) remain accessible with zero feature loss.
   - `_default_job_config` (`L282-287`) should populate `labels` with lowercase BigQuery-compliant label values (`^[a-z0-9_-]{0,63}$`) for `goe_version`, `goe_command`, and `goe_execution_id` when present on `self._connection_options` or `self._messages`.
   - `_get_bq_client` (`L441-446`) should pass `project=getattr(self._connection_options, "bigquery_billing_project", None) or None` and `client_info=google.api_core.gapic_v1.client_info.ClientInfo(user_agent=f"goe/{version}")`.
   - `_execute_global_session_parameters` (`L332-350`) currently restricts `default_config_white_list` (`L337`) to `["maximum_bytes_billed", "use_query_cache"]`; expand it to include `"labels"`, `"priority"`, `"job_timeout_ms"`, and `"reservation"`.
2. **Dataset CMEK Defaults (`src/goe/offload/bigquery/bigquery_backend_api.py:828-856`):**
   - `create_database` (`L828-856`) builds `CREATE SCHEMA ... OPTIONS(...)` with `description` and `location`, but omits `default_kms_key_name` even when `self.bigquery_kms_key_name()` is configured. Adding `default_kms_key_name='{self.bigquery_kms_key_name()}'` ensures all staging and temporary tables created in GOE-managed datasets inherit CMEK automatically. Also support optional `default_table_expiration_days` (`default_table_expiration_ms` in `OPTIONS` or `default_table_expiration_days`) for load datasets.
3. **`GOEGcs` Atomic No-Overwrite Uploads, Bulk Deletion, & Dead-Code Deletion (`src/goe/filesystem/goe_gcs.py:97-111`, `L129-184`, `L275-296`):**
   - `copy_from_local` (`L97-111`) and `write` (`L275-296`) call `self.stat(gcs_path)` (which invokes `blob.exists()`) before uploading when `overwrite=False`. Delete the pre-upload `self.stat(gcs_path)` check and instead pass `if_generation_match=0 if not overwrite else None` to `blob.upload_from_filename` / `blob.upload_from_string`.
   - `delete` (`L129-184`) lists blobs, deletes each blob individually via `blob_to_check.delete()`, and then loops up to 3 times with `time.sleep(1)` calling `blob_to_check.exists()` (`L145-182`). Delete the per-blob `blob_to_check.delete()` loop and the 3-attempt `time.sleep(1)` + `blob_to_check.exists()` post-delete polling loop, replacing them with `bucket.delete_blobs(blobs_to_delete)`.
   - Add `copy_many_from_local(self, local_paths: list[str], gcs_prefix: str, max_workers: int = 4)` using `google.cloud.storage.transfer_manager.upload_many_from_filenames` for multi-file batch uploads.

```python
def test_sanitize_bigquery_label_conforms_to_gcp_constraints() -> None:

    assert sanitize_bigquery_label("2.0.0-SNAPSHOT+build.1") == "2_0_0-snapshot_build_1"
    assert len(sanitize_bigquery_label("A" * 100)) == 63


def test_execute_query_fetch_x_uses_query_and_wait_when_not_profiling() -> None:
```

```python
from unittest.mock import MagicMock, patch

from goe.filesystem.goe_gcs import GOEGcs


def _build_gcs(dry_run: bool = False) -> tuple[GOEGcs, MagicMock]:
    """Build a GOEGcs client with a mocked google.cloud.storage.Client."""
    with patch("goe.filesystem.goe_gcs.storage.Client") as mock_storage_cls:
        client_mock = MagicMock()
        mock_storage_cls.return_value = client_mock
        gcs = GOEGcs(
            dfs_container="my-bucket",
            backend_dfs="GCP",
            messages=MagicMock(),
            dry_run=dry_run,
        )
    return gcs, client_mock


def test_copy_from_local_uses_if_generation_match_zero_when_no_overwrite() -> None:
    """Verify copy_from_local passes if_generation_match=0 when overwrite=False without calling exists()."""
    gcs, client_mock = _build_gcs(dry_run=False)
    bucket_mock = MagicMock()
    blob_mock = MagicMock()
    client_mock.get_bucket.return_value = bucket_mock
    bucket_mock.blob.return_value = blob_mock

    gcs.copy_from_local("/tmp/part-00000.parquet", "gs://my-bucket/stage/part-00000.parquet", overwrite=False)

    blob_mock.exists.assert_not_called()
    blob_mock.upload_from_filename.assert_called_once_with(
        "/tmp/part-00000.parquet",
        if_generation_match=0,
    )


def test_delete_uses_bucket_delete_blobs_without_polling_exists() -> None:
    """Verify delete batches blob deletions via bucket.delete_blobs and never polls blob.exists()."""
    gcs, client_mock = _build_gcs(dry_run=False)
    bucket_mock = MagicMock()
    blob_a = MagicMock()
    blob_a.name = "stage/part-00000.parquet"
    blob_b = MagicMock()
    blob_b.name = "stage/part-00001.parquet"
    client_mock.get_bucket.return_value = bucket_mock
    bucket_mock.list_blobs.return_value = [blob_a, blob_b]

    result = gcs.delete("gs://my-bucket/stage/part", recursive=True)

    assert result is True
    bucket_mock.delete_blobs.assert_called_once_with([blob_a, blob_b])
    blob_a.exists.assert_not_called()
    blob_b.exists.assert_not_called()
```
