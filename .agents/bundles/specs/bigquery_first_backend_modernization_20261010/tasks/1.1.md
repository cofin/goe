# Task 1.1: Default BigQuery staging to Parquet and add validated `BIGQUERY_LOAD_TABLE_MODE`

## Objective

Make `PARQUET` the default `OFFLOAD_STAGING_FORMAT` when `BACKEND_DISTRIBUTION=GCP` (explicit `AVRO` still honored) and add the `BIGQUERY_LOAD_TABLE_MODE` orchestration option (`NATIVE` default, `EXTERNAL` fallback) consumed by Task 1.3.

## Context

- Baseline `46890a8`. `gcp_adc_credential_unification_20261010:1.1` adds `google_*` entries and `legacy_shim_removal_and_repo_hygiene_20261010:1.2` removes `listener_redis_*` entries in the same three config files; locate anchors by symbol, not line.
- `src/goe/config/orchestration_defaults.py::offload_staging_format_default` (`L683-691`) returns `FILE_STORAGE_FORMAT_PARQUET` only for `BACKEND_DISTRO_SNOWFLAKE`/`BACKEND_DISTRO_MSAZURE`, else `FILE_STORAGE_FORMAT_AVRO`. `BACKEND_DISTRO_GCP` is already imported (`L18`).
- `src/goe/config/orchestration_config.py`: `EXPECTED_CONFIG_ARGS` list (`L47-197`, `"bigquery_dataset_project"` at `L54`), class annotations (`bigquery_dataset_project: str | None` at `L222`), `OrchestrationConfig.from_dict` keyword for `bigquery_dataset_project` (`L347-350`).
- `src/goe/config/config_validation_functions.py::normalise_bigquery_options` (`L111-121`) returns early unless `options.backend_distribution == BACKEND_DISTRO_GCP`.
- `src/goe/offload/offload_constants.py`: `BACKEND_DISTRO_GCP = "GCP"` (`L58`); `HADOOP_BASED_BACKEND_DISTRIBUTIONS` (`L67-72`).
- `templates/conf/offload.env.template.bigquery:60-61` sets `OFFLOAD_STAGING_FORMAT=AVRO`.
- Test helper: `tests.unit.test_functions.build_mock_options(mock_env)` patches `os.environ` and returns `OrchestrationConfig.from_dict({"verbose": False})`; `FAKE_ORACLE_BQ_ENV` (`tests/unit/test_functions.py:73-93`) sets `BACKEND_DISTRIBUTION=GCP` and does not set `OFFLOAD_STAGING_FORMAT`.
- Strategy `behavior_tdd`: new observable configuration behavior. Initial failing symptom: `AttributeError: 'OrchestrationConfig' object has no attribute 'bigquery_load_table_mode'` and `offload_staging_format == "AVRO"` for the GCP env.

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors

"""BigQuery-first configuration defaults and validation."""

import pytest

from goe.config.config_validation_functions import OrchestrationConfigException
from goe.offload.offload_constants import (
    BIGQUERY_LOAD_TABLE_MODE_EXTERNAL,
    BIGQUERY_LOAD_TABLE_MODE_NATIVE,
    FILE_STORAGE_FORMAT_AVRO,
    FILE_STORAGE_FORMAT_PARQUET,
)
from tests.unit.test_functions import FAKE_ORACLE_BQ_ENV, build_mock_options


def test_gcp_staging_format_defaults_to_parquet() -> None:
    """GCP backends stage Parquet unless OFFLOAD_STAGING_FORMAT is set."""
    config = build_mock_options(FAKE_ORACLE_BQ_ENV)
    assert config.offload_staging_format == FILE_STORAGE_FORMAT_PARQUET


def test_explicit_avro_staging_format_is_preserved() -> None:
    """An explicit OFFLOAD_STAGING_FORMAT=AVRO keeps Avro staging."""
    config = build_mock_options({**FAKE_ORACLE_BQ_ENV, "OFFLOAD_STAGING_FORMAT": "avro"})
    assert config.offload_staging_format == FILE_STORAGE_FORMAT_AVRO


def test_bigquery_load_table_mode_defaults_to_native() -> None:
    """BIGQUERY_LOAD_TABLE_MODE defaults to NATIVE."""
    config = build_mock_options(FAKE_ORACLE_BQ_ENV)
    assert config.bigquery_load_table_mode == BIGQUERY_LOAD_TABLE_MODE_NATIVE


def test_bigquery_load_table_mode_accepts_external_case_insensitively() -> None:
    """EXTERNAL is accepted in any case."""
    config = build_mock_options({**FAKE_ORACLE_BQ_ENV, "BIGQUERY_LOAD_TABLE_MODE": "external"})
    assert config.bigquery_load_table_mode == BIGQUERY_LOAD_TABLE_MODE_EXTERNAL


def test_bigquery_load_table_mode_rejects_unknown_value() -> None:
    """Unknown modes raise OrchestrationConfigException."""
    with pytest.raises(OrchestrationConfigException, match="BIGQUERY_LOAD_TABLE_MODE"):
        build_mock_options({**FAKE_ORACLE_BQ_ENV, "BIGQUERY_LOAD_TABLE_MODE": "STREAMING"})
```
