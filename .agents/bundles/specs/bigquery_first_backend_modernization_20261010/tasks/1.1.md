# Task 1.1: Replace Legacy SQL partition queries, fix dry-run leakage, and remove `__del__` in `BackendBigQueryApi`

## Objective

Delete all Legacy SQL code paths (`[$__PARTITIONS_SUMMARY__]` and `use_legacy_sql` parameter plumbing) in `BackendBigQueryApi` (`get_table_partition_count`, `get_table_partitions`, and `_default_job_config`), close the dry-run execution gap in `_execute_query_fetch_x`, and delete the unsafe `__del__` finalizer in favor of explicit context-manager (`__enter__` / `__exit__`) and idempotent `close()` semantics while preserving 100% of existing BigQuery functionality.

## Context

1. **Delete Legacy SQL `$__PARTITIONS_SUMMARY__` & `use_legacy_sql` Plumbing (`src/goe/offload/bigquery/bigquery_backend_api.py:1510-1532` and `_default_job_config` at `L282-287`):**
   - `get_table_partition_count(self, db_name, table_name)` (`L1510-1520`) currently executes:
     `SELECT COUNT(*) FROM [%s$__PARTITIONS_SUMMARY__]` with `query_options={"use_legacy_sql": True}`.
   - `get_table_partitions(self, db_name, table_name)` (`L1522-1532`) currently executes:
     `SELECT partition_id FROM [%s$__PARTITIONS_SUMMARY__]` with `query_options={"use_legacy_sql": True}` and maps `[ PartitionInfo(row[0]) for row in rows ]` via `self._table_partition_info(row[0])` (`src/goe/offload/backend_api.py:625-636`).
   - `_default_job_config(self, query_options=None)` (`L282-287`) only exists to branch on `"use_legacy_sql"` in `query_options`.
   - Delete both Legacy SQL queries and the `use_legacy_sql` assignment in `_default_job_config`. Replace `get_table_partition_count` and `get_table_partitions` with GoogleSQL queries against `\`<project>.<dataset>\`.INFORMATION_SCHEMA.PARTITIONS` using `bigquery.ScalarQueryParameter("table_name", "STRING", table_name)`, filtering out pseudo-partitions `'__NULL__'` and `'__UNPARTITIONED__'`.
2. **Dry-Run Leakage in `_execute_query_fetch_x` (`src/goe/offload/bigquery/bigquery_backend_api.py:358-433`):**
   - `_execute_ddl_or_dml` (`L289-330`) checks `if not self._dry_run:` (`L315`) before calling `self._client.query(...)`.
   - `_execute_query_fetch_x` (`L358-433`) only checks `if self._dry_run and not_when_dry_running: return None` (`L383-384`).
   - Read-only dictionary/catalog queries (`INFORMATION_SCHEMA`, `SESSION_USER()`, table/view introspection) must continue to run during dry-run when `not_when_dry_running=False`, while `_execute_query_fetch_x` must support `dry_run_preview: bool = False` (which sets `job_config.dry_run = True` and logs `query_job.total_bytes_processed` without executing the query) and honour `not_when_dry_running=True` when `self._dry_run` is active.
3. **Delete `__del__` Finalizer (`src/goe/offload/bigquery/bigquery_backend_api.py:173-174`, helper boundary `L226-229`, `close()` at `L813-815`):**
   - `def __del__(self): self.close()` at `L173-174` runs during garbage collection and interpreter shutdown, raising `AttributeError` if `__init__` failed before `self._client = None` (`L165`) and closing underlying `urllib3` pools during interpreter teardown.
   - Delete `__del__` completely, make `close()` idempotent (`getattr(self, "_client", None)` reset to `None`), and implement `__enter__` / `__exit__`.

### Step 1: Write Regression & Behavior Unit Tests (Red Phase)

Create `tests/unit/offload/bigquery/__init__.py` and `tests/unit/offload/bigquery/test_bigquery_partition_and_dry_run.py` testing:
1. `get_table_partition_count("my_ds", "my_tbl")` and `get_table_partitions("my_ds", "my_tbl")` execute GoogleSQL against `` `test-proj.my_ds`.INFORMATION_SCHEMA.PARTITIONS `` with `ScalarQueryParameter("table_name", "STRING", "my_tbl")`, exclude `'__NULL__'` and `'__UNPARTITIONED__'`, and never set `use_legacy_sql=True`.
2. `_default_job_config` constructs `bigquery.QueryJobConfig` without setting `use_legacy_sql=True` and raises `BackendApiException` if `use_legacy_sql` is passed.
3. `_execute_query_fetch_x` skips execution and returns `None` when `self._dry_run=True` and `not_when_dry_running=True`; when `self._dry_run=True` and `dry_run_preview=True`, it submits a `QueryJobConfig(dry_run=True)` job, logs `total_bytes_processed`, and returns `None` without calling `query_job.result()`.
4. `BackendBigQueryApi` has no `__del__` method, supports `with api:` context manager entry/exit, and `close()` is idempotent (`self._client` is closed once and set to `None`).

    api._bigquery_dataset_project = "test-proj"

    api._sql_engine_name = "BigQuery"

def test_get_table_partition_count_uses_information_schema_googlesql() -> None:
    """Verify get_table_partition_count queries INFORMATION_SCHEMA.PARTITIONS using GoogleSQL parameters."""
    api, client_mock = _build_api(dry_run=False)
    query_job = MagicMock()
    query_job.state = "DONE"
    query_job.result.return_value = [(4,)]
    client_mock.query.return_value = query_job

    count = api.get_table_partition_count("sales_ds", "orders")

    assert count == 4
    client_mock.query.assert_called_once()
    executed_sql = client_mock.query.call_args.args[0]
    job_config: bigquery.QueryJobConfig = client_mock.query.call_args.kwargs["job_config"]
    assert "INFORMATION_SCHEMA.PARTITIONS" in executed_sql
    assert "$__PARTITIONS_SUMMARY__" not in executed_sql
    assert "'__NULL__'" in executed_sql
    assert "'__UNPARTITIONED__'" in executed_sql
    assert not getattr(job_config, "use_legacy_sql", False)
    assert len(job_config.query_parameters) == 1
    param = job_config.query_parameters[0]
    assert param.name == "table_name"
    assert param.value == "orders"

### Step 2: Update `src/goe/offload/bigquery/bigquery_backend_api.py` (Green Phase)

1. **Delete `__del__` and add `__enter__`, `__exit__`, and idempotent `close()` (`src/goe/offload/bigquery/bigquery_backend_api.py:172-175` and `L813-815`):**
   - Delete lines `173-174` (`def __del__(self): self.close()`).
   - Add `__enter__` and `__exit__` directly after `__init__`, and update `close()` at `L813-815` so it safely checks `getattr(self, "_client", None)` and resets `self._client = None`:

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def __enter__(self) -> "BackendBigQueryApi":
        """Enter the runtime context related to this backend API instance."""
        return self

    def __exit__(self, exc_type: Any, exc_val: Any, exc_tb: Any) -> None:
        """Exit the runtime context and close the underlying BigQuery client."""
        self.close()

    def close(self) -> None:
        """Close the underlying BigQuery client idempotently."""
        client = getattr(self, "_client", None)
        if client is not None:
            client.close()
            self._client = None
```

2. **Delete `use_legacy_sql` plumbing from `_default_job_config` (`src/goe/offload/bigquery/bigquery_backend_api.py:282-287`):**
   - Replace `_default_job_config` so it always returns a standard GoogleSQL `bigquery.QueryJobConfig()` and rejects `use_legacy_sql`:

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def _default_job_config(self, query_options: dict[str, Any] | None = None) -> bigquery.QueryJobConfig:
        """Create a default GoogleSQL QueryJobConfig."""
        if query_options and query_options.get("use_legacy_sql"):
            raise BackendApiException("BigQuery Legacy SQL is not supported; use GoogleSQL.")
        return bigquery.QueryJobConfig()
```

3. **Update `_execute_query_fetch_x` for `dry_run_preview` (`src/goe/offload/bigquery/bigquery_backend_api.py:358-433`):**
   - Add `dry_run_preview: bool = False` keyword parameter to `_execute_query_fetch_x`.
   - When `self._dry_run and not_when_dry_running`, return `None` immediately after logging the SQL.
   - When `self._dry_run and dry_run_preview`, set `job_config.dry_run = True`, submit `query_job = self._client.query(sql, job_config=job_config)`, log `f"BigQuery dry-run estimated bytes processed: {query_job.total_bytes_processed}"` at `VVERBOSE_LEVEL`, and return `None` without calling `query_job.result()`.

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def _execute_query_fetch_x(
        self,
        sql: str,
        fetch_action: int = FETCH_ACTION_ALL,
        query_options: dict[str, Any] | None = None,
        log_level: int = VVERBOSE_LEVEL,
        time_sql: bool = False,
        not_when_dry_running: bool = False,
        query_params: list[tuple[str, str, Any]] | None = None,
        profile: bool = False,
        as_dict: bool = False,
        dry_run_preview: bool = False,
    ) -> Any:
        """Run a query and fetch results, honoring dry-run skipping and cost-preview modes."""
        assert sql
        job_config = self._default_job_config(query_options=query_options)
        if query_params:
            job_config.query_parameters = [bigquery.ScalarQueryParameter(n, t, v) for n, t, v in query_params]

        self._log_or_not(
            "%s SQL: %s" % (self._sql_engine_name, sql),
            log_level=log_level,
            query_options=query_options,
            query_params=query_params,
        )
        if self._dry_run and not_when_dry_running:
            return None
        if self._dry_run and dry_run_preview:
            job_config.dry_run = True
            preview_job = self._client.query(sql, job_config=job_config)
            self._log(
                f"BigQuery dry-run estimated bytes processed: {preview_job.total_bytes_processed}",
                detail=VVERBOSE_LEVEL,
            )
            return None
```

4. **Delete Legacy SQL `$__PARTITIONS_SUMMARY__` in `get_table_partition_count` and `get_table_partitions` (`src/goe/offload/bigquery/bigquery_backend_api.py:1510-1532`):**
   - Replace both methods with parameterized GoogleSQL queries against `INFORMATION_SCHEMA.PARTITIONS`:

```python
# SPDX-FileCopyrightText: 2026 The GOE Authors
# SPDX-License-Identifier: Apache-2.0

    def get_table_partition_count(self, db_name: str, table_name: str) -> int:
        """Return the number of table partitions using GoogleSQL INFORMATION_SCHEMA.PARTITIONS."""
        assert db_name and table_name
        sql = (
            f"SELECT COUNT(*) FROM {self.enclose_object_reference(db_name, 'INFORMATION_SCHEMA.PARTITIONS')} "
            "WHERE table_name = @table_name "
            "AND partition_id NOT IN ('__NULL__', '__UNPARTITIONED__')"
        )
        query_params = [("table_name", "STRING", table_name)]
        row = self.execute_query_fetch_one(sql, query_params=query_params)
        return row[0] if row else 0

    def get_table_partitions(self, db_name: str, table_name: str) -> dict[str, Any]:
        """Return a mapping of partition_id to partition info using GoogleSQL INFORMATION_SCHEMA.PARTITIONS."""
        assert db_name and table_name
        sql = (
            f"SELECT partition_id FROM {self.enclose_object_reference(db_name, 'INFORMATION_SCHEMA.PARTITIONS')} "
            "WHERE table_name = @table_name "
            "AND partition_id NOT IN ('__NULL__', '__UNPARTITIONED__') "
            "ORDER BY partition_id"
        )
        query_params = [("table_name", "STRING", table_name)]
        rows = self.execute_query_fetch_all(sql, query_params=query_params) or []
        partition_items = [self._table_partition_info(row[0]) for row in rows]
        return {item["partition_id"]: item for item in partition_items}
```
