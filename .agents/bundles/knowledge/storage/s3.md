# Amazon AWS S3 Storage Adapter

The AWS S3 adapter (`src/goe/filesystem/goe_s3.py`) provides staging storage integration for Snowflake and AWS-hosted compute pipelines.

## Key Features

- **Class**: `GOES3` (inherits from `GOEDfs`).
- **Driver / Library**: `boto3`, `botocore`.
- **Scheme**: `s3://` or `s3a://<bucket>/<prefix>/<schema>/<table_name>/part*`.
- **Authentication**:
  1. Explicit access key & secret key (`aws_access_key_id`, `aws_secret_access_key`).
  2. AWS credential profile (`~/.aws/credentials`).
  3. EC2 IAM Instance Profile / STS AssumeRole.
- **Batch Deletion**: Paginated `list_objects_v2` with `ContinuationToken` batching up to 1,000 keys per `delete_objects` call.
